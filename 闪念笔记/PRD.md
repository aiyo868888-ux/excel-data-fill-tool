# 闪念笔记应用 - 产品需求文档（PRD）

## 1. 产品概述

### 1.1 产品定位
一款基于"闪念 → 永久"工作流的知识管理应用，通过手机快速捕获想法和灵感，在电脑端深度加工和连接，构建个人知识网络。

### 1.2 核心价值
- **零摩擦捕获**：悬浮窗 + 剪切板，3秒完成记录
- **心理重构设计**：灵感/启发/待办三种正向类型
- **自然工作流**：手机捕获，电脑加工，无缝同步

### 1.3 目标用户
- 知识工作者（产品经理、程序员、设计师、写作者）
- 学习者（学生、研究者）
- 需要管理大量想法和待办的人群

---

## 2. 产品架构

### 2.1 双端架构
```
手机端（Android）
├─ 核心功能：快速捕获
├─ 悬浮窗：永久存在的快捷入口
├─ 三种类型：灵感、启发、待办
└─ 数据存储：每日 JSON 文件

电脑端（桌面应用）
├─ 核心功能：深度加工
├─ 收件箱：接收手机数据
├─ 编辑器：转永久笔记
└─ 知识库：双向链接 + 知识图谱
```

### 2.2 数据流向
```
手机捕获 → 本地JSON → 云端同步 → 电脑收件箱 → 永久笔记 → 知识图谱
```

## 3. 核心功能需求

### 3.1 手机端功能

#### 3.1.1 悬浮窗（核心入口）

**功能描述：**
永久存在的小窗口，提供快速捕获入口

**状态设计：**
1. **默认态**：小圆形图标（56dp × 56dp），半透明
2. **展开态**：显示三种类型选择（灵感/启发/待办）
3. **激活态**：绿色对勾，表示可粘贴剪切板

**交互流程：**
```
首次点击 → 展开菜单 → 选择类型 → 打开对话框
对话框打开后点击 → 粘贴剪切板内容
双击 → 快速保存（默认类型）
长按 → 显示剪切板历史
```

**非功能需求：**
- 始终置顶，不被其他应用覆盖
- 可拖动到任意位置
- 不遮挡屏幕内容（半透明）
- 动画流畅（< 300ms）

---

#### 3.1.2 三种对话框

**A. 💡 灵感对话框**

**使用场景：**
- 突然想到的点子
- 梦里想到的内容
- 创造性想法

**界面元素：**
- 多行输入框（5-15行）
- 剪切板计数器（📋 N）
- 添加备注按钮（可选）
- 智能提示区

**核心功能：**
- 支持剪切板多次粘贴（自动追加）
- 最大长度：2000字符
- 自动保存草稿

**交互细节：**
- 打开对话框自动聚焦输入框
- 点击悬浮窗粘贴剪切板
- Ctrl+Enter 保存并关闭
- Ctrl+Shift+Enter 保存并继续记录

---

**B. 📖 启发对话框**

**使用场景：**
- 读书时的感悟
- 听播客的收获
- 看文章学到的东西

**界面元素：**
- 来源选择（6个选项）：书籍、播客、网络、对话、课程、其他
- 来源详情输入框
- 多行内容输入框（5-15行）
- 关键词输入（可转为标签）
- 智能提示区

**核心功能：**
- 自动识别剪切板类型：
  - URL → 提示设为"网络"来源
  - 书名号《》→ 提示设为"书籍"来源
  - 超长内容（>500字）→ 提示分段保存
- 关键词推荐（基于内容）
- 最大长度：3000字符

**交互细节：**
- 选择来源后，来源详情输入框自动聚焦
- 占位符根据来源类型动态变化
- 智能提示可一键确认或忽略

---

**C. ⚡ 待办对话框**

**使用场景：**
- 记住要做的事情
- 会议任务记录
- 购物清单

**界面元素：**
- 任务输入框（3-10行）
- 自动识别开关（多行→多任务）
- 时间快速选择：今天/明天/选日期/提醒时间/重复
- 时间详情展示（选中后显示）
- 智能提示区

**核心功能：**
- 自动识别多行内容为多个任务
- 自然语言识别：
  - "记得"、"别忘了" → 建议设为今天
  - "明天下午3点" → 自动提取日期和时间
- 支持重复任务（每天/每周/每月）
- 支持提醒时间
- 最大长度：500字符

**交互细节：**
- 点击"今天"自动展开时间详情
- 支持批量保存确认
- 保留时间设置（方便连续记录）

### 3.2 数据存储

#### 3.2.1 JSON 文件结构

**文件命名：** `YYYY-MM-DD.json`

**存储位置：**
```
/data/data/com.yourapp/files/notes/
├── 2024-01-16.json
├── 2024-01-15.json
└── ...
```

**文件结构：**
```json
{
  "date": "2024-01-16",
  "version": "1.0",
  "statistics": {
    "灵感": 3,
    "启发": 5,
    "待办": 4
  },
  "data": {
    "灵感": [...],
    "启发": [...],
    "待办": [...]
  }
}
```

#### 3.2.2 数据模型

**灵感对象：**
```json
{
  "id": "uuid",
  "type": "灵感",
  "content": "内容",
  "memo": "备注",
  "clipboard_sources": [
    {
      "text": "剪切板内容",
      "timestamp": "ISO 8601",
      "app": "来源应用（可选）"
    }
  ],
  "created_at": "ISO 8601",
  "updated_at": "ISO 8601"
}
```

**启发对象：**
```json
{
  "id": "uuid",
  "type": "启发",
  "source": "书籍|播客|网络|对话|课程|其他",
  "source_detail": "具体来源",
  "content": "内容",
  "keywords": ["关键词1", "关键词2"],
  "memo": "备注",
  "clipboard_sources": [...],
  "created_at": "ISO 8601",
  "updated_at": "ISO 8601"
}
```

**待办对象：**
```json
{
  "id": "uuid",
  "type": "待办",
  "content": "任务内容",
  "due_date": "YYYY-MM-DD 或 null",
  "due_time": "HH:MM 或 null",
  "reminder": true|false,
  "priority": "高|中|低",
  "repeat": {
    "frequency": "daily|weekly|monthly|custom",
    "interval": 1
  },
  "repeat_end": {
    "type": "count|date|never",
    "value": "30 或 2024-02-16"
  },
  "completed": false,
  "completed_at": "ISO 8601 或 null",
  "memo": "备注",
  "clipboard_sources": [...],
  "created_at": "ISO 8601",
  "updated_at": "ISO 8601"
}
```

### 3.3 同步功能

#### 3.3.1 上传策略

**触发条件：**
- 保存新数据后立即上传
- 后台静默同步（不打断用户）

**优先级：**
1. 待办（最高，时间敏感）
2. 启发
3. 灵感

**冲突处理：**
- 以手机为准（闪念优先）
- 电脑端修改后，手机端显示"已处理"状态

---

#### 3.3.2 下载策略

**电脑端：**
- 定时轮询（每5分钟）
- 检查云端新文件
- 自动下载并解析

**API 设计：**
```
POST /api/notes/upload
GET /api/notes/list
GET /api/notes/download?date=YYYY-MM-DD
```

## 4. 用户体验设计

### 4.1 核心用户旅程

#### 旅程1：捕获灵感

```
场景：用户在公交车上突然想到一个点子

步骤：
1. 下拉通知栏，看到悬浮窗
2. 点击悬浮窗 → 展开 → 选择"💡 灵感"
3. 灵感对话框打开
4. 输入："可以做一个知识管理App"
5. 点击"保存并关闭"
6. Toast："已保存到灵感"
7. 对话框关闭，悬浮窗恢复默认态
```

---

#### 旅程2：批量收集网页内容

```
场景：用户在浏览器看到多段有价值的内容

步骤：
1. 复制第一段话
2. 点击悬浮窗 → 选择"📖 启发"
3. 启发对话框打开
4. 点击悬浮窗 → 自动粘贴第一段
5. 复制第二段话
6. 点击悬浮窗 → 追加第二段
7. 复制第三段话
8. 点击悬浮窗 → 追加第三段
9. 选择来源："🌐 网络"
10. 补充感悟
11. 保存
```

---

#### 旅程3：快速记录待办

```
场景：用户在会议中需要记录多个任务

步骤：
1. 复制会议记录中的任务1
2. 点击悬浮窗 → 选择"⚡ 待办"
3. 待办对话框打开
4. 点击悬浮窗 → 粘贴任务1
5. 复制任务2
6. 点击悬浮窗 → 追加任务2
7. 复制任务3
8. 点击悬浮窗 → 追加任务3
9. 系统提示："检测到3个任务，是否生成3条待办？"
10. 点击"是"
11. 统一设置时间："☀️ 今天"
12. 保存
13. Toast："已保存3条待办"
```

## 5. 非功能需求

### 5.1 性能要求

- 对话框打开时间：< 300ms
- JSON 文件写入：< 100ms
- 上传同步：< 3秒（4G网络）
- 搜索响应：< 200ms（本地1000条数据）

---

### 5.2 可用性要求

- 界面简洁，3次点击内完成记录
- 支持单手操作
- 适配不同屏幕尺寸（5-7英寸）
- 支持深色模式

---

### 5.3 兼容性要求

- Android 8.0+（API 26+）
- 支持不同分辨率（720p - 2K）
- 支持不同屏幕比例（16:9, 19:9, 20:9）

---

### 5.4 安全性要求

- 数据本地加密存储
- 传输使用 HTTPS
- 支持用户自定义加密密钥

---

### 5.5 可靠性要求

- 数据不丢失：本地备份 + 云端备份
- 崩溃恢复：自动保存草稿
- 离线可用：无网络时正常使用

## 8. 风险与挑战

### 8.1 技术风险

- **悬浮窗权限**：部分厂商可能限制
  - 缓解方案：提供多种开启方式引导
- **剪切板权限**：Android 12+ 需要用户手动授权
  - 缓解方案：清晰的引导流程

### 8.2 用户体验风险

- **学习成本**：新用户可能不理解三种类型的区别
  - 缓解方案：首次使用引导 + 示例
- **使用习惯**：用户可能习惯于传统笔记应用
  - 缓解方案：突出"快速"和"简单"的核心价值

### 8.3 竞争风险

- **市场竞争**：类似产品众多（Keep、Flomo、Notion）
  - 差异化：专注"闪念 → 永久"工作流，心理重构设计

## 9. 附录

### 9.1 术语表

- **闪念笔记**：快速捕获的临时笔记，不完整、未加工
- **永久笔记**：经过加工、有完整上下文、可链接的知识单元
- **灵感**：从无到有、创造性的想法
- **启发**：从外部吸收、学到的知识
- **待办**：需要完成的任务
