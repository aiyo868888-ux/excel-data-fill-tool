# imageToExcel

图片表格识别并自动填入Excel的Web应用

## ✨ 功能特性

- 🖼️ **图片识别**: 使用PaddleOCR自动识别图片中的表格数据
- 📊 **智能填入**: 自动将识别的数据填入Excel指定列
- 📑 **多图支持**: 支持上传多张图片，自动横向排列
- ✏️ **自定义数据**: 支持JSON格式自定义列内容
- 🎯 **纯图片模式**: 无表格数据时也可单独插入图片
- 🌐 **Web界面**: 简洁友好的网页界面，支持拖拽上传
- 💾 **一键下载**: 处理完成后直接下载生成的Excel文件

## 📋 系统要求

- Python 3.8+
- Windows / macOS / Linux

## 🚀 快速开始

### 方式1: 使用启动脚本（推荐）

**Windows:**
```bash
双击运行 start.bat
```

**Linux/Mac:**
```bash
chmod +x start.sh
./start.sh
```

### 方式2: 手动启动

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动应用
python app.py
```

### 访问应用

打开浏览器访问: **http://localhost:5000**

## 📖 使用说明

### 基本流程

1. **上传Excel模板**
   - 点击上传区域或拖拽文件
   - 支持 `.xlsx` 和 `.xls` 格式

2. **上传图片**
   - 可以上传一张或多张图片
   - 支持 `.png`, `.jpg`, `.jpeg`, `.gif`, `.bmp` 格式

3. **（可选）上传数据文件**
   - 如果已有提取的JSON数据文件
   - 展开可选区域上传

4. **（可选）自定义数据**
   - 展开自定义数据区域
   - 输入JSON格式的数据
   - 示例：
     ```json
     {
       "序号": "10",
       "材料名称": "水泥",
       "规格型号": "P.O 42.5",
       "单位": "吨",
       "数量": "100",
       "备注": "优质水泥"
     }
     ```

5. **点击"开始处理"**
   - 等待处理完成
   - 点击下载按钮获取生成的Excel文件

### 数据列映射

**图片表格列自动映射到Excel列**:
- 序号 → 第1列（A列）
- 品名 → 第4列（D列-材料名称）
- 规格 → 第5列（E列-规格型号）
- 单位 → 第6列（F列）
- 数量 → 第7列（G列）
- 备注 → 第12列（L列）

**自定义数据支持的列名**:
- 序号、进场时间1、进场时间2
- 材料名称、规格型号、单位
- 数量、供货单位、接收人
- 接收时间、工程部位、备注

## ⚠️ 常见问题

### Q: 启动后无法访问？
**A**: 检查防火墙设置，确保5000端口未被占用

### Q: 上传文件后提示"技能不可用"？
**A**: 确保 `image-table-excel` 技能路径正确，检查 `app.py` 中的路径配置

### Q: Excel文件验证失败？
**A**: 可能的原因和解决方案：
1. **文件格式不对** - 确保是真正的Excel文件，不是CSV/TXT改扩展名
2. **文件太旧** - Excel 95及更早版本不支持，请用Excel/WPS打开后"另存为".xlsx"
3. **文件损坏** - 尝试用Excel修复文件或从备份恢复
4. **密码保护** - 先用Excel打开并移除密码保护
5. **CSV文件** - 用Excel打开CSV文件，然后"另存为".xlsx"

### Q: 处理速度慢？
**A**: 这是正常的，PaddleOCR首次运行会下载模型文件（约80MB），后续使用会更快

### Q: 支持哪些Excel格式？
**A**: 支持 `.xlsx` 和 `.xls` 格式（推荐使用.xlsx）

### Q: 可以处理多大的文件？
**A**: 默认最大16MB，可在配置中修改

### Q: 如何测试应用？
**A**: 使用项目中的 `示例模板.xlsx` 进行测试
