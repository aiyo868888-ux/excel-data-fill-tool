# DAN KOE 风格文章结构模板

## 开篇模板（10%篇幅）

### 模板 1：挑战既有观念
```
你可能一直在用错误的方式 [主题]。

不是你的错——每个人都这么教你。但这是错的。

这篇文章不是另一篇 [主流观点] 的废话。我要分享 [数字] 个被忽视的真相，关于 [痛点]，以及 [解决方案]。

读完需要 [时间]。但如果你认真对待，这些想法会改变你对自己 [领域] 的理解。

让我们开始。
```

### 模板 2：反常识开场
```
关于 [主题]，最大的谎言是...

主流叙事告诉你...。但他们错了。

真相是...。而且几乎没人讨论这个问题。

在接下来 [时间] 的阅读中，我将向你展示为什么 [主流观点] 会失败，以及什么真的有效。

我会分解为 [数字] 个核心想法。每个都会挑战你的既有假设。

准备好？让我们深入。
```

### 模板 3：直接挑衅
```
你需要听到这个，即使它会让你不舒服。

[尖锐陈述]

大多数人...。但少数人...。

这两者之间的差异不是 [表面因素]，而是 [深层因素]。

这篇文章是关于那个深层因素的。

我将分享 [数字] 个洞察，从 [理论角度] 到 [实践步骤]。

读完需要投入时间。但这是值得的。

让我们开始。
```

## 主体章节模板（80%篇幅）

### 章节标题格式
```
一、[挑衅性/洞察性标题]
二、[另一个挑衅性标题]
三、...
```

**标题模式：**
- "你被...骗了"
- "...的真相"
- "为什么你的...失败"
- "大多数人误解了..."
- "...的真正含义"

### 单章节内部结构模板

#### 模板 A：诊断 → 原因 → 解决方案
```
### 一、[章节标题：诊断问题]

你可能已经注意到...

[描述现象/症状]

大多数人认为这是 [表面问题]。

但那是错的。

[可选：引用权威]
正如 [权威人物] 所说："[引用内容]"

[揭示深层原因]
真正的问题是...

[用类比解释]
想象...

这不是...的问题。而是...的问题。

[对比论证]
传统方法：...
有效方法：...

[反问句]
但你有没有问过自己为什么...？

[短句强调]
这一点至关重要。

[提供解决方案/新视角]
所以，什么才是...？

答案是...

[继续下一个观点]
...
```

#### 模板 B：理论 → 案例分析 → 启示
```
### 二、[章节标题：理论框架]

首先，理解 [核心概念]。

[理论解释，引用研究]
研究表明...

[类比说明]
想象你的大脑像...

[个人案例]
我在 [时间] 经历了这个。

当时我以为...

结果是...

[案例启示]
从那以后我理解了...

这教会我...

[普遍化观察]
我观察到同样的模式在...

[短句强调]
大多数人忽略了这一点。

[提供可执行洞察]
那么，应用这个...

具体来说...
```

#### 模板 C：误解 → 真相 → 对比
```
### 三、[章节标题：揭示真相]

你可能听说过...

[主流观点]

这是错的。

[为什么误解存在]
原因很简单...

[揭示真相]
真相是...

[用对比强化]
| 误解 | 真相 |
|---|---|
| ... | ... |
| ... | ... |

[具体案例]
例如...

[分析为什么真相被忽视]
没人告诉你这个，因为...

[短句强调]
这改变了一切。

[提供应用]
所以...
```

### 章节间过渡技巧

**技巧 1：回顾连接**
```
还记得上一章我们讨论的 [概念] 吗？

它再次出现在这里。

原因是...
```

**技巧 2：递进深化**
```
现在我们理解了 [概念]，让我们深入...

下一层是...

这将带我们到...
```

**技巧 3：转折对比**
```
但这里有个矛盾。

虽然...，但...

这听起来反直觉。但是...
```

## 结尾模板（10%篇幅）

### 模板 1：行动号召
```
## 总结

我们讨论了很多。

- [核心观点 1]
- [核心观点 2]
- [核心观点 3]

但理解不等于改变。

现在你有了框架。执行取决于你。

选择一个地方开始。不需要完美。只需要开始。

其余的会自然发生。

– [作者名字]
```

### 模板 2：反思性结尾
```
## 最后的想法

如果你只记住一件事，让它是这个：

[最核心的洞察]

但你现在理解了。

这给了你优势。

如何使用这个优势取决于你。

– [作者名字]
```

```

当你开始...，你会注意到...

– [作者名字]
```

## 句式模板库

### 挑衅性开场句
- "你可能一直..."
- "关于...最大的谎言是..."
- "你需要听到这个，即使它会让你不舒服"
- "这不是另一篇..."
- "大多数人都错了"

### 挑战观点句
- "但那是错的"
- "这里有个问题"
- "没人告诉你"
- "你可能没听过"
- "这不是关于...，而是关于..."

### 强调句式
- "这一点至关重要"
- "大多数人忽略了这一点"
- "这改变了一切"
- "让我重复一遍"
- "听我说"

### 反问句
- "但你有没有问过自己...？"
- "为什么会这样？"
- "什么才是真正有效的？"
- "你注意到...了吗？"
- "如果...会怎样？"

### 对比句
- "表面上看...，但实际上是..."
- "传统方法...。真相是..."
- "大多数人...。但..."
- "不是...，而是..."
- "你可能以为...。但实际上..."
