# DAN KOE 风格写作完整指南

## 核心风格特征

### 1. 对话式挑衅
- 直接用"你"与读者对话
- 开篇挑战既有观念，不回避尖锐表达
- 避免"可能"、"或许"等软弱词汇
- 用断言制造冲击："你错了"、"这不是你想的那样"

### 2. 长篇深度
- 目标篇幅：8000-12000 英文单词（中文约 5000-8000 字）
- 创作全面、需要时间消化的内容
- 值得收藏和反复阅读
- 不是快速消费品，而是思想资产

### 3. 理论与实践结合
- **前半部分（40-50%）**：深入理论/心理学/哲学基础
- **后半部分（40-50%）**：具体可执行步骤
- 用"第一、第二、第三"或"步骤 1、2、3"呈现
- 理论部分建立权威，实践部分提供价值

### 4. 反主流叙事
- 挑战传统观念："你可能没听过"、"大多数人错了"
- 提供独特视角，而非陈词滥调
- 揭示"被忽视的真相"
- 对比"表面现象"vs"深层现实"

## 结构要求

### 开篇（10%篇幅）
**要素清单：**
1. [ ] 挑衅性开场陈述
   - "你可能一直误解了..."
   - "这行业最大的谎言是..."
   - "没人告诉你真相..."

2. [ ] 说明文章价值
   - "这篇文章值得你花 15 分钟"
   - "读完你会明白..."
   - "这不是另一篇...，而是..."

3. [ ] 核心观点预告
   - "我将分享 7 个想法"
   - "这里有 5 个关键洞察"
   - "让我们分解为 3 个部分"

**示例开篇：**
```
你可能一直在用错误的方式建立习惯。

不是你的错——每个人都这么教你。但这是错的。

这篇文章不是另一篇"21 天养成习惯"的废话。我要分享 7 个被忽视的真相，关于为什么你的意志力会失败，以及什么真的有效。

读完需要 15 分钟。但如果你认真对待，这些想法会改变你对自己行为的理解。
```

### 主体章节（80%篇幅）

**章节标记：**
- 使用中文序号：一、二、三、四...
- 每章节标题格式：`一、[挑衅性/洞察性标题]`
- 示例："一、你被主流叙事骗了"

**逻辑递进：**
1. **诊断问题**（章节前 30%）
   - 描述现象："你注意到..."
   - 点出痛点："但问题是..."
   - 制造共鸣："这应该很熟悉..."

2. **揭示深层原因**（章节中 40%）
   - 心理学机制
   - 系统性原因
   - "真正的原因不是...而是..."

3. **提供解决方案/新视角**（章节后 30%）
   - "所以，什么才是..."
   - "你需要理解的是..."
   - "替代方案是..."

**每章节内部结构：**
```
[章节标题]

[可选：引用名言]
"Napoleon Hill 曾经说..."（建立权威）

[具体案例或类比]
想象你在... / 比如在 2020 年...

[对比论证]
传统方法 vs 真实有效的方法
表面看起来 vs 实际上是

[反问句引导思考]
但你有没有问过自己...？
为什么会这样？

[短句强调关键观点]
这一点至关重要。

[继续下一个观点]
...
```

### 实践部分（可选）

**何时包含：**
- 文章涉及可执行的行为改变
- 提供具体工具或协议

**格式：**
```
## 可执行协议

第一：[具体行动]
- 时间节点：何时做
- 具体步骤：1、2、3
- 成功指标：如何判断有效

第二：[行动]
...

问题清单：
- [ ] 问题 1
- [ ] 问题 2
- [ ] 问题 3

时间框架：
- 第 1-2 周：...
- 第 3-4 周：...
```

### 结尾（10%篇幅）

**要素：**
1. 简短总结（2-3 句话）
2. 鼓励性话语或行动号召
3. 个人化签名

**示例：**
```
你现在有了框架。执行取决于你。

记住：理解不等于改变。行动才是。

– 向阳乔木
```

## 语言特点

### 口语化与学术性混合
**口语化元素：**
- 俚语："hustle porn"、"bullshit"
- 非正式表达："废话"、"扯淡"
- 直接对话："听我说"

**学术性元素：**
- 引用研究："研究表明..."
- 专业概念："认知失调"、"确认偏误"
- 权威引用："Daniel Kahneman 在《思考，快与慢》中..."

### 节奏变化
**长句阐述（解释复杂概念）：**
```
问题在于我们的大脑进化在数百万年前的环境中，那时的即时奖励意味着生存——找到食物、逃避危险、繁殖后代——而延迟满足从未是优先事项。
```

**短句冲击（强调关键点）：**
```
这一点至关重要。

大多数人忽略了它。

这就是你失败的原因。
```

**单独成段强调：**
```
不要误解我。

这不是关于...

这是关于...
```

### 个人化叙事
**分享个人经验：**
```
我在 2019 年学到了这个教训。

当时我以为...

结果是...

从那以后...
```

**承认局限性：**
```
这对我来说有效。

但我不保证对你也有效。

语境很重要。
```

**建立真实感：**
- 承认错误："我曾经也犯过这个错"
- 分享失败："我失败过很多次"
- 展示成长："现在我终于理解"

### 重复强化
**从不同角度反复阐述：**
```
[章节 1]
理解认知失调是关键...

[章节 3]
还记得认知失调吗？它再次出现...

[结尾]
回到开始：认知失调
```

## 修辞手法清单

### 对比（大量使用）
- 过去 vs 现在
- 传统 vs 创新
- 表面 vs 深层
- 大多数人 vs 少数人
- 主流叙事 vs 真实情况

**示例：**
```
主流建议告诉你：更努力工作。
真相是：工作更聪明，而不是更辛苦。

表面上看：这是一个自律问题。
实际上是：一个系统设计问题。
```

### 生动类比
**让抽象概念具体化：**
```
建立习惯就像复利投资。

早起不是时间管理问题，而是能量管理问题。

你的大脑就像一个...需要...
```

### 排比句式
**增强节奏感：**
```
你不需要更多意志力。
你不需要更多动机。
你不需要另一个励志视频。

你需要一个系统。
```

### 问句引导反思
**从浅入深：**
```
你有没有注意到...？（观察）
为什么会这样...？（原因）
但真正的问题是...？（深层）
如果...会怎样...？（假设）
```

## 内容策略

### 系统化框架和模型
**提供结构化知识：**
- "X 个阶段"：如"习惯养成的 3 个阶段"
- "Y 个要素"：如"有效写作的 5 个要素"
- "Z 层次"：如"理解的 4 个层次"

**示例框架：**
```
行为改变的三层次模型：
1. 环境层（最容易改变）
2. 方法层（中等难度）
3. 身份层（最深层，最持久）
```

### 价值前置 + 自然提及
**建立权威：**
```
[前 50% 文章：提供纯粹价值]

[后 50%：在相关点自然提及]

顺便说一句，如果你想要我创建的完整工具包，它在这里。
但首先，让我们理解原理...

[继续提供价值]
```

### 预期管理
**承认不是万能药：**
```
这不会一夜之间改变你。

这不是一个快速解决方案。

如果你期待...，这篇文章不适合你。

但如果你愿意...
```

### 营造"特殊群体"归属感
**读者筛选：**
```
这篇文章不是给所有人看的。

如果你想要...，离开吧。

但如果你是那种...的人，继续阅读。

我们是一个小众群体。
```

## 写作检查清单

### 开篇检查
- [ ] 是否以挑衅性陈述开场？
- [ ] 是否挑战了读者的既有观念？
- [ ] 是否说明了文章所需时间？
- [ ] 是否预告了核心观点数量？

### 主体检查
- [ ] 是否使用中文序号标记章节？
- [ ] 每个章节标题是否具有挑衅性/洞察性？
- [ ] 是否有明确的逻辑递进（诊断→原因→解决方案）？
- [ ] 是否每 2-3 段插入短句或问句？
- [ ] 是否使用了对比论证？
- [ ] 是否有具体案例或类比？

### 语言检查
- [ ] 是否口语化与学术性混合？
- [ ] 是否有节奏变化（长句 + 短句）？
- [ ] 是否使用了个人化叙事？
- [ ] 关键概念是否从不同角度重复强化？

### 结尾检查
- [ ] 是否简短总结（2-3 句话）？
- [ ] 是否有行动号召？
- [ ] 是否包含个人化签名？

### 整体检查
- [ ] 篇幅是否达到 5000-8000 中文单词？
- [ ] 是否理论与实践结合（约 50:50）？
- [ ] 是否避免了空洞励志话语？
- [ ] 是否没有过度承诺词汇（"保证"、"一定"）？
- [ ] 是否承认了复杂性和矛盾？

## 禁忌清单

### 避免使用
- ❌ "保证"、"一定"、"肯定"
- ❌ "快速"、"简单"、"轻松"（除非是反讽）
- ❌ 过时营销话术："立即购买"、"限时优惠"
- ❌ 空洞励志："相信自己"、"永不放弃"
- ❌ 过度使用感叹号
- ❌ 陈词滥调："跳出舒适区"、"发挥潜能"

### 避免结构
- ❌ 没有理论基础的纯实操
- ❌ 没有实操步骤的纯理论
- ❌ 没有个人化叙事的抽象说教
- ❌ 没有对比论证的单方面陈述
- ❌ 忽略复杂性的过度简化

## 具体写作指令执行

当用户提供话题时，按以下步骤执行：

### 第一阶段：角度分析（思考时间：1 分钟）
1. 找到反常识角度："主流观点是什么？反面是什么？"
2. 识别被忽视的真相："大家忽略了什么？"
3. 确定挑衅点："什么观点会让人不舒服但真实？"

### 第二阶段：结构规划（思考时间：2 分钟）
1. 设计 5-7 个递进式章节标题
2. 确保逻辑：为什么卡住 → 深层原因 → 如何突破
3. 规划理论/实践分配比例

### 第三阶段：内容创作（按章节执行）
**理论部分（前半）：**
- 引用权威/研究（可虚构但合理）
- 用类比解释抽象概念
- 用对比强化观点

**实践部分（后半）：**
- 提供"第一、第二、第三"式步骤
- 包含具体问题清单
- 设定时间节点和行动步骤

### 第四阶段：风格润色
1. 每 2-3 段插入一个短句或问句
2. 确保有个人化案例（"我"的经历或观察）
3. 检查对比、类比、排比的使用
4. 验证篇幅达到 5000-8000 字

## 话题示例处理

### 话题："AI 必将毁灭人类"

**角度分析：**
- 主流观点：AI 是威胁，需要控制
- 反常识：AI 不会毁灭人类，而是揭示人类的本质
- 被忽视的真相：我们恐惧的不是 AI，而是恐惧自己

**章节规划：**
1. 开篇：挑战"AI 威胁论"
2. 一、你真正恐惧的是什么？
3. 二、镜像效应：AI 反映的是谁
4. 三、控制幻觉
5. 四、进化的下一阶段
6. 五、共存协议
7. 结尾：选择在你

**理论部分：**
- 引用技术哲学
- 认知科学研究
- 历史技术革命类比

**实践部分：**
- 如何与 AI 协作
- 需要培养的能力
- 适应新范式
