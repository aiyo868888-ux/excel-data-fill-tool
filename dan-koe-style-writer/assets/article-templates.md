# 文章框架模板

本文件提供完整的 DAN KOE 风格文章框架，可以直接填充内容使用。

## 完整文章框架

```
[开篇 - 10%篇幅]

# [挑衅性标题]

[挑衅性开场陈述]
你可能一直在用错误的方式 [主题]。

[挑战既有观念]
不是你的错——每个人都这么教你。但这是错的。

[说明文章价值]
这篇文章不是另一篇 [主流观点] 的废话。我要分享 [数字] 个被忽视的真相，关于 [核心痛点]，以及什么真的有效。

[时间投入和回报]
读完需要 [时间] 投入。但如果你认真对待，这些想法会改变你对 [领域] 的理解。

[核心观点预告]

1. [观点 1]
2. [观点 2]
3. [观点 3]

[提供框架]
```

## 章节数量选择指南

2. 诊断问题 + 揭示真相（25%）
3. 系统框架（25%）
4. 可执行方案（25%）
5. 结尾（15%）

## 快速填充检查清单

写作时确保填充：

### 开篇部分
- [ ] 挑衅性开场陈述（1-2 句）
- [ ] 挑战既有观念（1 段）
- [ ] 说明文章价值（1-2 句）
- [ ] 核心观点数量预告（具体数字）

### 每个章节
- [ ] 挑衅性标题
- [ ] 描述现象/问题
- [ ] 揭示深层原因
- [ ] 提供/解决方案
- [ ] 对比论证
- [ ] 至少 1 个反问句
- [ ] 至少 1 个短句强调
- [ ] 过渡到下一章节

### 实践部分（如适用）
- [ ] 第一、第二、第三式步骤
- [ ] 问题清单
- [ ] 时间框架/阶段

### 结尾部分
- [ ] 简短总结（2-3 句话）
- [ ] 行动号召
- [ ] 个人化签名

### 整体检查
- [ ] 篇幅 5000-8000 中文单词
- [ ] 理论与实践约 50:50 分配
- [ ] 至少 1 个个人化叙事
- [ ] 核心概念重复 2-3 次
- [ ] 开篇和结尾呼应
