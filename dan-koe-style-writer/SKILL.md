# DAN KOE 风格写作

快速生成 DAN KOE 风格的长篇深度文章。

## 核心风格特征

**对话式挑衅** - 直接挑战读者既有观念，不回避尖锐表达
**长篇深度** - 5000-8000 中文单词，值得反复阅读
**理论实践结合** - 前半理论基础，后半具体可执行步骤
**反主流叙事** - 揭示被忽视的真相，提供独特视角

## 快速开始

### 最简用法

```
用户：用 DAN KOE 风格写一篇关于 AI 的文章

你：
1. 确定反常识角度："AI 不会毁灭人类，而是揭示人类本质"
2. 规划 5-7 个递进章节（诊断→原因→突破）
3. 开篇：挑战"AI 威胁论"
4. 主体：理论 50% + 实践 50%
5. 结尾：行动号召 + 个人签名
```

### 完整工作流

#### 步骤 1：角度分析（1 分钟思考）

找到反常识角度和挑衅点：

```
- 主流观点是什么？反面是什么？
- 大家忽略了什么？
- 什么观点会让人不舒服但真实？
```

#### 步骤 2：结构规划（2 分钟）

设计 5-7 个递进章节：

```
一、挑衅性标题（诊断问题）
二、挑衅性标题（揭示真相）
三、挑衅性标题（系统框架）
四、挑衅性标题（可执行方案）
五、挑衅性标题（常见陷阱）
六、挑衅性标题（长远视角）
七、挑衅性标题（...）

确保逻辑：为什么卡住 → 深层原因 → 如何突破
```

#### 步骤 3：内容创作

**开篇（10%）**
- 挑衅性开场："你可能一直在用错误的方式..."
- 挑战观念："不是你的错，但这是错的"
- 价值说明："我将分享 N 个真相"
- 时间投入："读完需要 X 分钟"

**主体章节（80%）**
- 中文序号：一、二、三...
- 每章节：
  * 诊断问题 → 揭示原因 → 提供方案
  * 对比论证（传统 vs 真实有效）
  * 至少 1 个反问句
  * 短句强调关键观点

**实践部分（可选）**
- "第一、第二、第三"式步骤
- 问题清单
- 时间框架/阶段

**结尾（10%）**
- 简短总结（2-3 句）
- 行动号召："选择一个地方开始"
- 个人签名："– [作者名字]"

## 写作检查清单

### 开篇检查
- [ ] 挑衅性开场陈述
- [ ] 挑战既有观念
- [ ] 说明所需时间
- [ ] 预告核心观点数量

### 主体检查
- [ ] 中文序号标记章节
- [ ] 挑衅性/洞察性标题
- [ ] 逻辑递进（诊断→原因→方案）
- [ ] 每 2-3 段插入短句或问句
- [ ] 对比论证
- [ ] 具体案例或类比

### 语言检查
- [ ] 口语化与学术性混合
- [ ] 节奏变化（长句 + 短句）
- [ ] 个人化叙事
- [ ] 关键概念重复强化

### 结尾检查
- [ ] 简短总结（2-3 句）
- [ ] 行动号召
- [ ] 个人化签名

### 整体检查
- [ ] 篇幅 5000-8000 字
- [ ] 理论实践约 50:50
- [ ] 避免"保证""一定"
- [ ] 承认复杂性和矛盾

## 核心禁忌

**避免使用：**
- ❌ "保证"、"一定"、"肯定"
- ❌ "快速"、"简单"、"轻松"（除非反讽）
- ❌ 过时营销话术
- ❌ 空洞励志："相信自己"、"永不放弃"
- ❌ 过度使用感叹号

**避免结构：**
- ❌ 无理论基础的纯实操
- ❌ 无实操步骤的纯理论
- ❌ 无个人叙事的抽象说教
- ❌ 无对比论证的单方面陈述
- ❌ 忽略复杂性的过度简化

## 关键句式

**挑衅性开场：**
- "你可能一直误解了..."
- "关于...最大的谎言是..."
- "这不是另一篇..."

**挑战观点：**
- "但那是错的"
- "没人告诉你..."
- "这不是关于...，而是关于..."

**强调关键点：**
- "这一点至关重要"
- "大多数人忽略了这一点"
- "这改变了一切"

**反问引导：**
- "但你有没有问过自己...？"
- "为什么会这样？"
- "如果...会怎样？"
