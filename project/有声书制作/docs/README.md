# 音效生成工具

## 📖 项目简介

这是一个基于 Web 的音效生成工具，能够使用 Python 算法实时生成各种环境音效（雨声、风声、白噪声等），无需任何外部音频素材。

### ✨ 核心特性

- ✅ **实时生成** - 使用算法生成音效，无需下载素材
- ✅ **8种音效类型** - 白噪声、粉红噪声、布朗噪声、雨声、风声、雷声、海浪、森林环境
- ✅ **参数可调** - 时长、音量、频率、淡入淡出等参数自由调节
- ✅ **批量生成** - 一次生成多个不同音效
- ✅ **音效混合** - 将多个音效混合成一个文件
- ✅ **图形界面** - 美观的紫色渐变设计
- ✅ **实时预览** - 生成后可立即试听
- ✅ **完全免费** - 本地运行，无需联网

## 📚 使用方法

### 1. 生成单个音效

1. 选择音效类型（如"雨声"）
2. 调节参数：
   - **时长**：1-300秒
   - **音量**：0-100%
   - **强度/速度/频率**：特定音效参数
   - **淡入/淡出**：0-5秒
3. 点击"生成音效"
4. 等待生成完成
5. 点击"下载"保存文件，或点击"试听"在线播放

### 2. 批量生成

1. 在右侧"批量生成"区域
2. 选择音效类型，点击"+ 添加"
3. 重复步骤2添加多个音效
4. 点击"批量生成"
5. 等待所有音效生成完成

### 3. 音效混合

1. 生成或导入多个音效
2. 在"音效混合"区域自动显示已生成的文件
3. 调整每个音轨的音量（0-100%）
4. 点击"混合并下载"
5. 获得混合后的WAV文件

## 🔧 技术实现

### 音效生成算法

**白噪声**：高斯随机噪声
```python
audio = numpy.random.normal(0, 1, samples)
```

**粉红噪声**：Voss-McCartney 算法（1/f 噪声）

**布朗噪声**：白噪声的积分（低频更强）

**雨声**：白噪声 + 高通滤波（1000-4000Hz）

**风声**：粉红噪声 + 低频调制（0.05-0.2Hz）

**海浪**：粉红噪声 + 低频振荡（0.1Hz）

**雷声**：布朗噪声 + 频率扫描（100Hz → 5Hz）

**森林环境**：风声背景 + 正弦波鸟鸣

### 技术栈

- **后端**：Flask + NumPy + SciPy + soundfile
- **前端**：HTML + Tailwind CSS + JavaScript
- **音频格式**：WAV（16-bit, 44100Hz, 单声道）

## ⚙️ 参数说明

### 通用参数

| 参数 | 范围 | 说明 |
|-----|------|------|
| 时长 | 1-300秒 | 音效持续时间 |
| 音量 | 0-100% | 输出音量大小 |
| 淡入 | 0-5秒 | 音效开始渐入时间 |
| 淡出 | 0-5秒 | 音效结束渐出时间 |

### 特定音效参数

**雨声强度**：0-100%
- 控制雨滴的密集程度
- 影响高频成分的多少

**风速度**：0.5-2.0倍
- 风的吹动速度
- 影响调制频率

**海浪频率**：0.05-0.2Hz
- 海浪的起伏频率
- 数值越大波浪越快

## 🐛 常见问题

**Q: 为什么生成速度慢？**
A: 首次生成可能需要加载 NumPy/SciPy 库，后续生成会快很多。

**Q: 可以生成 MP3 格式吗？**
A: 当前只支持 WAV 格式（无损），可使用其他工具转换为 MP3。

**Q: 生成的音效可以用作商业用途吗？**
A: 可以，这些音效完全由算法生成，无版权限制。

**Q: 为什么试听没有声音？**
A: 请检查系统音量，或先下载文件使用播放器播放。
