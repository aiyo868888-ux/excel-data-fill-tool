## 💡 后续说明

### 如果需要更换图片：

1. **准备新图片**
   - 建议尺寸：轮播图 750x300px，商品图 400x400px
   - 建议格式：JPG（照片）、PNG（图标）

2. **替换文件**
   ```
   # 直接替换对应的文件
   miniprogram/images/banners/banner1.jpg  (换成你的新图)
   miniprogram/images/products/product-1.jpg
   miniprogram/images/categories/category-1.png
   ```

3. **刷新小程序**
   - 在微信开发者工具点击"编译"
   - 新图片立即显示

### 如果需要添加更多商品：

编辑 `mock/data.js`，添加新的商品数据：

```javascript
{
  _id: 'product_009',
  name: '新商品名称',
  categoryId: 'category_001',
  images: ['/images/products/new-product.jpg'],
  price: 199,
  // ... 其他字段
}
```
