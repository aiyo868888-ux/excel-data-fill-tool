# 云函数部署指南 - 解决体验版图片不显示问题

## 问题诊断

**症状**: 体验版用户看不到云存储图片，一直空白

**根本原因**:
1. 免费版云存储权限: `"read": "auth.openId != null"` (仅创建者可见)
2. 客户端 `wx.cloud.getTempFileURL` API 在体验版可能因权限不足失败
3. 3秒超时后降级到原始 `cloud://` 链接，体验用户仍然看不到

## 解决方案：云函数代理

**核心思路**: 使用云函数在**服务端**生成临时链接，绕过客户端权限限制

```
客户端（体验用户）
  ↓ 调用云函数
云函数（服务端，有完整权限）
  ↓ 调用 getTempFileURL
云存储（返回临时链接）
  ↓ 返回 https:// 链接
客户端（显示图片）✅
```

## 部署步骤

### 1. 打开云开发控制台

1. 微信开发者工具 → 点击工具栏 **"云开发"** 按钮
2. 进入云开发控制台

### 2. 部署 getImageURL 云函数

**方式一：通过开发者工具部署（推荐）**

1. 在开发者工具中，找到 `cloudfunctions/getImageURL` 文件夹
2. **右键点击** `getImageURL` 文件夹
3. 选择 **"上传并部署：云端安装依赖"**
4. 等待部署完成（约30秒）

**方式二：通过云开发控制台部署**

1. 云开发控制台 → **云函数**
2. 点击 **"新建"** 按钮
3. 函数名称: `getImageURL`
4. 运行环境: Node.js 16
5. 将以下代码复制到编辑器:

```javascript
// 云函数：获取云存储图片临时链接
// 解决免费版云存储权限限制问题

const cloud = require('wx-server-sdk')
cloud.init({ env: cloud.DYNAMIC_CURRENT_ENV })

exports.main = async (event, context) => {
  const { fileIds } = event

  console.log('getImageURL 云函数被调用', event)

  if (!fileIds || fileIds.length === 0) {
    return {
      code: 400,
      error: 'fileIds 参数不能为空'
    }
  }

  try {
    const result = await cloud.getTempFileURL({
      fileList: fileIds.map(id => ({ fileID: id }))
    })

    console.log('获取临时链接成功:', result)

    return {
      code: 200,
      data: result.fileList
    }
  } catch (err) {
    console.error('获取临时链接失败', err)
    return {
      code: 500,
      error: err.message
    }
  }
}
```

6. 点击 **"保存并安装依赖"**
7. 等待部署完成

## 常见问题

### Q1: 云函数调用失败 "cloud function does not exist"

**原因**: 云函数未部署或部署失败

**解决**:
1. 检查云函数是否已部署: 云开发控制台 → 云函数 → 查看 `getImageURL` 是否存在
2. 重新部署云函数
3. 确认云环境ID正确: `app.json` 或 `project.config.json` 中的 `cloudfunctionRoot`

### Q2: 云函数部署成功但体验版仍看不到图片

**可能原因**:
1. 云函数权限配置问题
2. 云环境ID不一致（开发版 vs 体验版）

**排查步骤**:
```javascript
// 1. 检查云环境ID
console.log('云环境ID:', cloud.DYNAMIC_CURRENT_ENV);

// 2. 在云函数中添加日志
exports.main = async (event, context) => {
  console.log('云环境:', cloud.DYNAMIC_CURRENT_ENV);
  console.log('接收参数:', event);

  const result = await cloud.getTempFileURL({...});
  console.log('云存储响应:', result);

  return result;
};

// 3. 查看云函数日志
云开发控制台 → 云函数 → getImageURL → 日志
```

### Q3: 云函数调用超时

**原因**: 批量转换图片太多（超过50张）

**解决**:
- 云函数已限制单次最多50张
- 如需更多，分批调用:
```javascript
const chunks = [];
for (let i = 0; i < fileIds.length; i += 50) {
  chunks.push(fileIds.slice(i, i + 50));
}

const results = await Promise.all(
  chunks.map(chunk => wx.cloud.callFunction({
    name: 'getImageURL',
    data: { fileIds: chunk }
  }))
);
```

### Q4: 临时链接有效期多长？

**答案**: 2小时

**说明**:
- 临时链接包含签名，有效期2小时
- `CloudImageUtil` 已实现缓存机制（2小时）
- 过期后自动重新转换

## 技术原理

### 为什么云函数可以绕过权限限制？

**客户端调用**:
```javascript
wx.cloud.getTempFileURL()
  ↓
❌ 失败: 体验用户没有读取权限
```

**云函数调用**:
```javascript
wx.cloud.callFunction({ name: 'getImageURL' })
  ↓
云函数（服务端，具有管理员权限）
  ↓
cloud.getTempFileURL() // ✅ 成功: 云函数有完整权限
  ↓
返回临时链接给客户端
```

### 权限对比

| 调用方式 | 权限 | 体验版可用性 |
|---------|------|------------|
| 客户端 `wx.cloud.getTempFileURL` | 用户权限（受限） | ❌ 失败 |
| 云函数 `cloud.getTempFileURL` | 管理员权限（完整） | ✅ 成功 |
