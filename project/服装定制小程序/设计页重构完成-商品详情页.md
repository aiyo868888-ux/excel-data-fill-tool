设计页已重构为**商品详情页**风格，包含以下部分：

### 1️⃣ 商品图片区（顶部）
```
┌─────────────────────────────────────┐
│                                     │
│         [商品图片]                   │
```

**显示内容：**
- 价格（红色大字）

## 🎨 页面布局详解

### 商品图片区
- **高度**：750rpx
- **设计元素**：绝对定位覆盖在图片上
- **选中状态**：红色虚线边框

### 商品信息区
- **价格行**：价格左对齐（48rpx红色），销量右对齐
- **名称**：32rpx粗体
- **规格**：3列等宽，图标+标签+值

### 商品详情区
- **标题**：32rpx粗体
- **内容**：28rpx灰色，行高1.8

### 底部操作栏
- **固定定位**：bottom: 0
- **3个按钮**：上传（灰色）、文字（灰色）、完成（红色）
- **按钮样式**：图标+文字竖向排列

## 🧪 测试步骤

### 1. 编译项目
点击"编译"按钮

### 2. 查看设计页
1. 在首页点击任意商品
2. 跳转到设计页
3. 应该看到完整的商品详情页布局

### 3. 测试功能

#### 上传图片
1. 点击"上传图片"按钮
2. 选择本地图片
3. 图片应该出现在商品图片上

#### 添加文字
1. 点击"添加文字"按钮
2. 输入文字内容
3. 文字应该出现在商品图片上

#### 删除元素
1. 点击设计元素（选中，红色边框）
2. 再次点击同一元素
3. 弹出确认删除对话框

#### 完成设计
1. 点击"完成设计"按钮
2. 提示保存成功
3. 返回上一页
