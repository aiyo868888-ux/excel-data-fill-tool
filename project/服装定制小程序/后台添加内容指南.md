## 📖 方式1：云开发控制台手动添加

### 步骤详解

#### 1. 打开云开发控制台
```
微信开发者工具 → 点击"云开发"按钮 ☁️
```

#### 2. 进入数据库
```
左侧菜单 → 点击"数据库"
```

#### 3. 添加分类数据

**3.1 选择 categories 集合**
```
数据库 → 找到 "categories" → 点击进入
```

**3.2 点击"添加记录"按钮**

**3.3 复制粘贴以下数据**

```json
{
  "_id": "category_001",
  "name": "2025秋冬款",
  "parentId": "",
  "icon": "/images/category-1.png",
  "sortOrder": 1
}
```

**3.4 点击"确定"**

**3.5 重复添加更多分类**
- 冲锋衣系列
- 圆领T恤
- 马甲
- 卫衣系列
- 等...

#### 4. 添加商品数据

**4.1 选择 products 集合**
```
数据库 → 找到 "products" → 点击进入
```

**4.2 添加商品记录**

```json
{
  "_id": "product_001",
  "name": "1618三合一冲锋衣",
  "categoryId": "category_002",
  "images": ["/images/product-1.jpg"],
  "type": "三合一",
  "material": "100%聚酯纤维",
  "style": "通款",
  "price": 299,
  "sales": 100,
  "status": 1,
  "description": "专业户外三合一冲锋衣，防风防水"
}
```

**字段说明：**
- `_id`: 唯一标识（自动生成或手动指定）
- `name`: 商品名称
- `categoryId`: 所属分类ID
- `images`: 图片数组（云存储路径）
- `type`: 版型（三合一、圆领等）
- `material`: 材质
- `style`: 款式（通款、修身等）
- `price`: 价格（数字）
- `sales`: 销量（数字）
- `status`: 状态（1=上架，0=下架）
- `description`: 商品描述

## 🚀 方式2：云函数批量导入

### 步骤详解

#### 1. 创建云函数

**1.1 在开发者工具中**
```
右键 cloudfunctions 文件夹
→ 新建Node.js云函数
→ 名称: importData
```

**1.2 复制代码**

打开 `cloudfunctions/importData/index.js`，将 `scripts/importData.js` 的内容复制进去。

**1.3 创建 package.json**

```json
{
  "name": "importData",
  "version": "1.0.0",
  "description": "批量导入数据云函数",
  "main": "index.js",
  "dependencies": {
    "wx-server-sdk": "~2.6.3"
  }
}
```

#### 2. 部署云函数

```
右键 cloudfunctions/importData 文件夹
→ 上传并部署：云端安装依赖
```

#### 3. 调用云函数导入数据

**方法1：在云开发控制台测试**
```
云开发控制台 → 云函数 → importData
→ 点击"云端测试"标签
→ 输入测试参数：
   {
     "type": "categories"
   }
→ 点击"测试"按钮
```

**方法2：在小程序中调用**

在任意页面的 JS 文件中添加：

```javascript
const cloudService = require('../../utils/cloud.js');

// 导入分类
async function importCategories() {
  const res = await cloudService.callFunction('importData', {
    type: 'categories'
  });
  console.log(res);
}

// 导入商品
async function importProducts() {
  const res = await cloudService.callFunction('importData', {
    type: 'products'
  });
  console.log(res);
}
```
