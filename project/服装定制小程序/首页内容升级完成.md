## 🔄 如何自定义首页内容

### 修改热门推荐数量

编辑 [pages/index/index.js](miniprogram/pages/index/index.js:27)：

```javascript
// 热门商品（销量前4）
const hotProducts = [...allProducts]
  .sort((a, b) => b.sales - a.sales)
  .slice(0, 4);  // 改成你想显示的数量
```

### 修改新品上市数量

编辑 [pages/index/index.js](miniprogram/pages/index/index.js:32)：

```javascript
// 新品（取后4个）
const newProducts = allProducts.slice(-4);  // 改成你想显示的数量
```

### 修改服务优势

编辑 [pages/index/index.wxml](miniprogram/pages/index/index.wxml:77-99)：

```xml
<view class="services-section">
  <view class="service-item">
    <image class="service-icon" src="/images/icon-quality.png" />
    <text class="service-title">品质保证</text>
    <text class="service-desc">100%正品保证</text>
  </view>
  <!-- 添加更多服务... -->
</view>
```
