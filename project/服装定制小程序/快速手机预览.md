# 📱 快速手机预览步骤

## 🚀 2分钟就能在手机上看到小程序！

### 步骤1：打开项目
```
1. 打开微信开发者工具
2. 导入项目（如果还没导入）
   目录：d:\claude code -11\project\服装定制小程序
```

### 步骤2：点击预览
```
在微信开发者工具顶部工具栏：
找到并点击 👤 "预览" 按钮
```

### 步骤3：扫码预览
```
1. 屏幕上会出现一个二维码
2. 打开手机微信
3. 点击右上角 "扫一扫"
4. 扫描电脑屏幕上的二维码
```

### 步骤4：打开小程序
```
扫码后，小程序会自动在手机上打开！
就可以在手机上测试所有功能了！
```

## 💡 小技巧

### 预览方式
1. **预览** - 普通版本（推荐给客户看）
2. **真机调试** - 开发版本（可以看日志）

### 如何更新
修改代码后：
1. 保存文件（Ctrl+S）
2. 点击"编译"
3. 重新点击"预览"
4. 重新扫码（或刷新小程序）

### 保存到手机
在小程序中：
1. 点击右上角 "..."
2. 点击 "添加到我的小程序"
3. 以后在微信首页就能快速打开
