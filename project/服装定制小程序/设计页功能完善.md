## 🎨 设计页结构

根据你提供的截图，设计页包含以下主要部分：

### 1️⃣ 顶部导航栏
```
┌─────────────────────────────────────┐
│  [款式] [新建] [?] [保存]            │
│  [模板👕] [分享➚]                   │
└─────────────────────────────────────┘
```

**功能按钮：**
- **款式** - 选择不同商品款式
- **新建** - 清空当前设计
- **?** - 显示使用帮助
- **保存** - 保存当前设计
- **模板👕** - 选择设计模板（开发中）
- **分享➚** - 分享设计（开发中）

### 2️⃣ 中间预览区域（80%屏幕高度）
```
┌─────────────────────────────────────┐
│                                      │
│    [商品图片 + 设计元素]             │
│                                      │
│         [+ 放大按钮]                 │
│                                      │
└─────────────────────────────────────┘
```

**功能：**
- 显示选中的商品图片作为背景
- 可以添加图片和文字元素
- 点击元素选中，可拖拽移动
- 右上角放大按钮可缩放画布

### 3️⃣ 底部工具栏（黑色背景）
```
┌─────────────────────────────────────┐
│  [🖼素材] [📤上传] [T文字] [✓完成]  │
└─────────────────────────────────────┘
```

**功能按钮：**
- **🖼素材** - 添加装饰素材（开发中）
- **📤上传** - 上传本地图片到画布
- **T文字** - 添加文字到画布
- **✓完成** - 完成设计并保存

## 💡 核心功能说明

### 1. 商品图片显示
```javascript
// design.js
this.setData({
  productImage: product.images[0]  // 商品第一张图片作为画布背景
});
```

### 2. 画布缩放
```javascript
// design.js
onZoomIn() {
  let zoom = this.data.zoom + 0.1;
  if (zoom > 2) zoom = 2;
  this.setData({ zoom });
}
```

```html
<!-- design.wxml -->
<view class="design-canvas" style="transform: scale({{zoom}});">
```

### 3. 元素渲染
- 图片元素：显示上传的图片
- 文字元素：显示添加的文字
- 选中状态：蓝色边框标识
