## 🎨 如何使用

### 浏览商品
1. 打开首页，查看分类
2. 点击分类进入分类页
3. 浏览商品列表

### 设计定制
1. 点击任意商品进入设计页
2. 点击"上传"添加图片
3. 点击"文字"添加文字
4. 点击"保存"保存设计

### 查看设计
1. 点击底部"我"标签
2. 点击"我的设计"
3. 查看所有保存的设计

## 🔄 切换到云开发模式

如果以后想切换到云开发，只需：

1. **恢复 app.js**
   ```javascript
   wx.cloud.init({
     env: 'your-env-id'
   });
   ```

2. **恢复页面文件**
   - 使用git恢复旧的代码
   - 或手动替换回云开发调用

3. **开通云开发**
   - 在微信开发者工具点击"云开发"
   - 按提示开通即可

## 🐛 常见问题

### Q1: 图片不显示？
**原因：** 图片路径引用但文件不存在
**解决：**
- 暂时忽略，不影响功能测试
- 或自行添加图片到 `/images/` 目录

### Q2: 保存的设计在哪？
**位置：** 小程序本地存储
**查看方式：**
- 在"我的"页面查看
- 或使用开发者工具调试工具查看 Storage

### Q3: 如何添加更多商品？
**方式：** 编辑 `mock/data.js`
```javascript
products: [
  {
    _id: 'product_009',
    name: '新商品',
    categoryId: 'category_001',
    price: 199,
    // ... 更多字段
  }
]
```
