# 📷 图片显示配置指南

## ✅ 已完成：使用在线图片服务

我已经将所有图片改为**在线图片服务**，现在可以直接显示！

### 使用的图片服务
1. **Picsum Photos** - 随机照片（用于轮播图和商品图）
   - 地址：`https://picsum.photos`
   - 示例：`https://picsum.photos/400/400?random=101`

2. **Placeholder** - 带文字的占位图（用于分类图标）
   - 地址：`https://via.placeholder.com`
   - 示例：`https://via.placeholder.com/100/FF6B6B/FFFFFF?text=秋冬`

## 🎨 当前图片配置

### 轮播图（首页）
```javascript
banners: [
  {
    image: 'https://picsum.photos/750/300?random=1'
  }
]
```
- **尺寸**：750x300px
- **数量**：3张
- **效果**：随机风景/人物照片

### 分类图标
```javascript
{
  icon: 'https://via.placeholder.com/100/FF6B6B/FFFFFF?text=秋冬'
}
```
- **尺寸**：100x100px
- **颜色**：每个分类不同颜色
- **文字**：显示分类名称

### 商品图片
```javascript
{
  images: ['https://picsum.photos/400/400?random=101']
}
```
- **尺寸**：400x400px
- **数量**：8个商品各1张
- **效果**：随机商品图

### 设计模板
```javascript
templateUrl: 'https://via.placeholder.com/750x1000/FFFFFF/000000?text=T恤设计模板'
```
- **尺寸**：750x1000px
- **颜色**：白色背景，黑色文字
- **用途**：设计页画布背景

## 🔄 如何更换为真实图片

### 方案1：使用本地图片文件

**步骤1：准备图片**
```
miniprogram/images/
├── banners/         # 放3张轮播图
│   ├── banner1.jpg
│   ├── banner2.jpg
│   └── banner3.jpg
├── categories/     # 放分类图标
│   ├── category-1.png
│   └── ...
└── products/       # 放商品图片
    ├── product-1.jpg
    └── ...
```

**步骤2：修改 mock/data.js**
```javascript
// 把网络URL改为本地路径
banners: [
  {
    image: '/images/banners/banner1.jpg'  // 改这里
  }
]

categories: [
  {
    icon: '/images/categories/category-1.png'  // 改这里
  }
]

products: [
  {
    images: ['/images/products/product-1.jpg']  // 改这里
  }
]
```

---

### 方案2：使用云存储（推荐上线时）

**步骤1：上传图片到云存储**
- 微信云开发控制台 → 存储
- 创建目录：banners/, categories/, products/
- 上传图片

**步骤2：获取云存储URL**
```javascript
// 云存储URL格式
cloud://xxx.banners/banner1.jpg

// 或使用CDN域名
https://xxx.tcb.qcloud.la/banners/banner1.jpg
```

**步骤3：修改 mock/data.js**
```javascript
banners: [
  {
    image: 'cloud://xxx.banners/banner1.jpg'
  }
]
```

---

### 方案3：使用图床服务

推荐免费图床：
1. **SM.MS** - https://sm.ms/
2. **图壳** - https://imgkr.com/
3. **GitHub** (作为图床)

**使用步骤：**
1. 上传图片到图床
2. 获取图片URL
3. 修改 mock/data.js 中的图片地址
