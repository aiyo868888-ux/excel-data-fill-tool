# 微信云开发配置指南

## 📋 开通云开发完整步骤

### Step 1: 从微信开发者工具进入云开发

1. **打开微信开发者工具**
2. **打开你的项目**（服装定制小程序）
3. **点击顶部工具栏的"云开发"按钮**
   - 位置：顶部工具栏，云朵图标 ☁️
   - 如果没看到，确保已登录微信账号

### Step 2: 开通云开发服务

#### 首次开通：
```
1. 点击"开通"按钮
2. 阅读服务协议
3. 选择计费方式：
   - 推荐：按量付费（有免费额度）
   - 套餐包：适合流量较大的项目
4. 确认开通
```

#### 免费额度说明（按量付费）：
| 资源 | 免费额度 |
|------|---------|
| 云数据库 | 2GB存储 + 5万次读/天 |
| 云存储 | 5GB存储 + 5万次下载/天 |
| 云函数 | 4万次GB/s + 1万次调用/天 |

**MVP阶段完全够用！**

### Step 3: 创建环境

```
环境配置建议：
┌─────────────────────────────────┐
│ 环境名称：ding-sheng-dev         │
│ 说明：开发测试环境                │
│                                  │
│ 环境ID：cloud1-xxxxxxx           │
│ （自动生成，请记录！）            │
│                                  │
│ 基础库版本：2.28.1（最新）       │
└─────────────────────────────────┘
```

**创建步骤**：
1. 点击"新建环境"
2. 填写环境名称
3. 选择基础库版本
4. 点击"创建"

### Step 4: 记录环境ID

## ⚙️ 配置项目

### 配置1: 修改 app.js

打开文件：`miniprogram/app.js`

**找到第10-12行，修改为：**
```javascript
wx.cloud.init({
  env: 'cloud1-7gxxx0a', // 替换为你的环境ID
  traceUser: true
});
```

**完整代码：**
```javascript
// app.js
App({
  onLaunch() {
    console.log('小程序启动');

    // 初始化云开发
    if (!wx.cloud) {
      console.error('请使用 2.2.3 或以上的基础库以使用云能力');
    } else {
      wx.cloud.init({
        env: 'cloud1-7gxxx0a', // ⚠️ 替换为你的环境ID
        traceUser: true
      });
      console.log('云开发初始化成功');
    }

    // 获取用户信息
    this.getUserInfo();
  },

  getUserInfo() {
    wx.getSetting({
      success: res => {
        if (res.authSetting['scope.userInfo']) {
          wx.getUserInfo({
            success: res => {
              this.globalData.userInfo = res.userInfo;
              console.log('用户信息获取成功', res.userInfo);
            }
          });
        }
      }
    });
  },

  globalData: {
    userInfo: null,
    openid: null
  }
});
```

### 配置2: 在开发者工具中测试

1. **保存文件**
2. **点击"编译"按钮**
3. **查看控制台输出**
   - 应该看到："云开发初始化成功"
   - 如果报错，检查环境ID是否正确

## 🗄️ 创建数据库集合

### 步骤：

1. **进入云开发控制台**
   - 在开发者工具中点击"云开发"按钮

2. **进入"数据库"标签**
   - 左侧菜单找到"数据库"

3. **创建集合（Collection）**

   点击"添加集合"，创建以下集合：

   ```
   集合名称: products
   说明: 商品信息
   权限: 仅创建者可读写

   集合名称: categories
   说明: 分类信息
   权限: 所有用户可读

   集合名称: designs
   说明: 设计数据
   权限: 仅创建者可读写

   集合名称: templates
   说明: 设计模板
   权限: 所有用户可读

   集合名称: users
   说明: 用户信息
   权限: 仅创建者可读写
   ```

### 设置权限规则：

**方法一：创建时选择**
- 创建集合时，选择权限模板

**方法二：创建后修改**
1. 点击集合名称
2. 点击"权限设置"
3. 选择权限模板或自定义

## 📁 创建云存储目录

### 步骤：

1. **进入"存储"标签**
   - 在云开发控制台左侧菜单

2. **创建目录**

   点击"新建文件夹"，创建以下目录：

   ```
   文件夹名: products
   说明: 存放商品图片

   文件夹名: designs
   说明: 存放用户设计稿

   文件夹名: templates
   说明: 存放模板图片

   文件夹名: avatars
   说明: 存放用户头像
   ```

3. **设置存储权限**
   - 进入"设置" -> "权限设置"
   - 选择："所有用户可读，仅创建者可写"

## ☁️ 上传云函数

### 步骤：

1. **在开发者工具中找到云函数目录**
   ```
   cloudfunctions/
   ├── getProducts/
   ├── saveDesign/
   ├── getMyDesigns/
   └── getCategories/
   ```

2. **右键云函数文件夹**
   - 例如：右键 `getProducts` 文件夹
   - 选择："上传并部署：云端安装依赖"

3. **等待上传完成**
   - 控制台会显示上传进度
   - 上传成功后会显示绿色✅

4. **对所有云函数重复此操作**
   - `getProducts`
   - `saveDesign`
   - `getMyDesigns`
   - `getCategories`

## ✅ 验证配置

### 测试步骤：

1. **保存所有文件**
   - 在开发者工具中按 `Ctrl+S` (Windows) 或 `Cmd+S` (Mac)

2. **点击"编译"**
   - 顶部工具栏的编译按钮

3. **查看控制台**
   - 底部的"调试器" -> "Console" 标签
   - 应该看到："小程序启动" 和 "云开发初始化成功"

4. **测试云函数**
   - 打开任意页面（如首页）
   - 在控制台查看是否有错误

### 常见错误排查：

**错误1：`Cloud function not found`**
```
原因：云函数未上传
解决：检查云函数是否已上传部署
```

**错误2：`Environment not found`**
```
原因：环境ID配置错误
解决：检查 app.js 中的环境ID是否正确
```

**错误3：`Permission denied`**
```
原因：数据库权限未设置
解决：检查数据库集合的权限设置
```

## 🆘 需要帮助？

### 常见问题：

**Q1: 找不到"云开发"按钮？**
```
A: 确保使用微信开发者工具，并且已登录微信账号
```

**Q2: 开通云开发需要收费吗？**
```
A: 按量付费模式有免费额度，MVP阶段完全免费
```

**Q3: 可以创建多个环境吗？**
```
A: 可以，建议创建开发环境和生产环境
```

**Q4: 云函数上传失败怎么办？**
```
A: 检查网络连接，确保 node_modules 已正确安装
```
