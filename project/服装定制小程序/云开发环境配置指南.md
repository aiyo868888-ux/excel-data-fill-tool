# 🚀 云开发环境配置完整指南

## 📋 配置概览

你需要完成以下3个步骤：

```
步骤1：获取环境ID（2分钟）
步骤2：创建数据库集合（5分钟）
步骤3：添加测试数据（10分钟）
```

---

## 步骤1：获取并配置环境ID ⭐最重要

### 1.1 查找环境ID

**方法1：从云开发控制台获取**
```
1. 打开云开发控制台（你已经在看的页面）
2. 查看左上角，环境名称后面有一串字符
   例如：cloud1-7g0d3f2a、cloud1-xxx

3. 或者查看浏览器地址栏URL：
   https://console.cloud.tencent.com/tcb/env?envId=cloud1-7g0d3f2a
   └───────────────────────────────────────┘
   这部分就是你的环境ID
```

**方法2：从微信开发者工具获取**
```
1. 打开微信开发者工具
2. 点击顶部"云开发"按钮
3. 在弹出的窗口中查看"环境ID"
```

### 1.2 更新 app.js 配置

**找到文件：** `miniprogram/app.js`

**修改第11行：**

```javascript
// 修改前（注释状态）
// env: 'your-env-id', // 请替换为你的云开发环境ID

// 修改后（取消注释并替换为你的环境ID）
env: 'cloud1-7g0d3f2a', // 替换为你的实际环境ID
```

**完整的配置示例：**

```javascript
// miniprogram/app.js
App({
  onLaunch() {
    console.log('小程序启动');

    // 初始化云开发
    if (!wx.cloud) {
      console.error('请使用 2.2.3 或以上的基础库以使用云能力');
    } else {
      wx.cloud.init({
        env: 'cloud1-7g0d3f2a', // ⬅️ 替换为你的环境ID
        traceUser: true
      });
      console.log('云开发初始化成功');
    }

    // 获取用户信息
    this.getUserInfo();
  },

  getUserInfo() {
    wx.getSetting({
      success: res => {
        if (res.authSetting['scope.userInfo']) {
          wx.getUserInfo({
            success: res => {
              this.globalData.userInfo = res.userInfo;
              console.log('用户信息获取成功', res.userInfo);
            }
          });
        }
      }
    });
  },

  globalData: {
    userInfo: null,
    openid: null
  }
});
```

### 1.3 保存并重新编译

```
1. 保存文件（Ctrl+S）
2. 在微信开发者工具中点击"编译"按钮
3. 查看控制台，应该看到：云开发初始化成功
```

## 步骤2：创建数据库集合

### 2.1 打开数据库管理

```
云开发控制台 → 左侧菜单 → 点击"数据库"
```

### 2.2 创建5个集合

点击"添加集合"按钮，依次创建以下集合：

| 集合名称 | 用途 | 权限设置 |
|---------|------|---------|
| **products** | 商品数据 | 所有用户可读，仅创建者可写 |
| **categories** | 分类数据 | 所有用户可读，仅创建者可写 |
| **designs** | 用户设计 | 仅创建者可读写 |
| **templates** | 设计模板 | 所有用户可读，仅创建者可写 |
| **users** | 用户信息 | 仅创建者可读写 |

### 2.3 设置集合权限

**对于 products 和 categories（公开数据）：**
```json
{
  "read": true,
  "write": false
}
```

**对于 designs 和 users（私有数据）：**
```json
{
  "read": "auth.openid == doc._openid",
  "write": "auth.openid == doc._openid"
}
```

```
数据库 → 点击"categories"集合 → 点击"添加记录"
```

### 方法B：使用云函数批量导入（推荐快速）🚀

如果你已经配置好环境ID，可以使用云函数批量导入。

#### 3.1 部署导入云函数

```
1. 在微信开发者工具中
2. 右键 cloudfunctions 文件夹
3. 选择"新建Node.js云函数"
4. 名称：importData
5. 将 scripts/importData.js 的内容复制到 cloudfunctions/importData/index.js
6. 右键 cloudfunctions/importData 文件夹
7. 选择"上传并部署：云端安装依赖"
```

#### 3.2 调用云函数导入数据

**在云开发控制台测试：**
```
云开发控制台 → 云函数 → 找到 importData → 点击"云端测试"

测试参数：
{
  "type": "categories"
}

点击"测试"按钮 → 等待结果 → 再测试：
{
  "type": "products"
}
```

## 🐛 常见问题

### Q1: 找不到环境ID怎么办？
```
A: 在云开发控制台，查看环境列表，每个环境都有一个唯一的环境ID
   格式通常是：cloud1-xxxxxxxx
```

### Q2: 配置后还是报错 -601034？
```
A: 检查以下几点：
   1. 环境ID是否正确（注意大小写）
   2. 是否保存了 app.js
   3. 是否重新编译了小程序
   4. 云开发环境是否正常状态（不是欠费或冻结）
```

### Q3: 数据库添加数据后，小程序中看不到？
```
A: 检查数据库权限设置：
   - products 和 categories 应该设置为"所有用户可读"
   - 在控制台 → 数据库 → 点击集合名称 → 权限设置
```

### Q4: 图片显示不出来？
```
A: 这是正常的，因为本地图片文件还没有创建。
   你可以：
   1. 暂时忽略图片错误，先测试功能
   2. 或者使用云存储上传真实图片
```
