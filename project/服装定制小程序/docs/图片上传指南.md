# 服装定制小程序 - 图片上传指南

> 本文档详细说明小程序各板块的图片结构、上传位置和配置方法

---

## 📂 目录结构总览

```
miniprogram/images/
├── banners/          # 🎠 首页轮播图（顶部大图）
├── categories/       # 📁 分类图标（首页网格中的小图）
├── products/         # 🛍️ 商品主图（商品列表、详情页顶部轮播）
└── details/          # 📄 商品详情图（详情页底部的长图）
```

---

## 📊 各板块详细说明

### 1️⃣ 首页轮播图 (`banners/`)

**显示位置**：首页最顶部的自动轮播区域

**图片规格**：
- 尺寸：750 × 360 rpx（宽高比 2:1）
- 格式：JPG / PNG
- 数量：建议 3-5 张
- 用途：活动宣传、新品推广

**数据配置**：`miniprogram/mock/data.js`

```javascript
banners: [
  {
    id: 1,
    image: '/images/banners/banner1.jpg',  // ← 图片路径
    title: '2025春夏新款上市'
  },
  {
    id: 2,
    image: '/images/banners/banner2.jpg',
    title: '定制专属你的风格'
  },
  {
    id: 3,
    image: '/images/banners/banner3.jpg',
    title: '限时优惠活动'
  }
]
```

**上传步骤**：
1. 将图片放到 `miniprogram/images/banners/` 目录
2. 命名为 `banner1.jpg`、`banner2.jpg` 等
3. 在 `mock/data.js` 的 `banners` 数组中添加对应配置

**命名规范**：
```
banner-{序号}.jpg

示例：
banner-1.jpg  (第一张轮播图)
banner-2.jpg  (第二张轮播图)
banner-3.jpg  (第三张轮播图)
```

---

### 2️⃣ 分类图标 (`categories/`)

**显示位置**：首页"商品分类"网格中的圆形/方形小图

**图片规格**：
- 尺寸：128 × 128 rpx（正方形）
- 格式：PNG（透明背景）或 JPG
- 数量：对应每个分类
- 用途：代表每个分类的图标

**数据配置**：`miniprogram/mock/data.js`

```javascript
categories: [
  {
    _id: 'category_001',
    name: '2025秋冬款',
    icon: '/images/categories/category-1.png',  // ← 图标路径
    parentId: '',
    sortOrder: 1
  },
  {
    _id: 'category_002',
    name: '冲锋衣系列',
    icon: '/images/categories/category-2.png',
    parentId: '',
    sortOrder: 2
  }
]
```

**上传步骤**：
1. 将分类图标放到 `miniprogram/images/categories/` 目录
2. 命名为 `category-1.png`、`category-2.png` 等
3. 在 `mock/data.js` 的 `categories` 数组中配置对应分类

**命名规范**：
```
category-{序号}.png

示例：
category-1.png  (2025秋冬款)
category-2.png  (冲锋衣系列)
category-3.png  (翻领短袖)
```

### 3️⃣ 商品主图 (`products/`)

**显示位置**：
- 首页商品列表
- 分类页商品列表
- 商品详情页顶部轮播

**图片规格**：
- 尺寸：750 × 750 rpx（1:1 正方形）
- 格式：JPG / PNG
- 数量：每个商品 1-5 张（支持轮播）
- 用途：展示商品整体外观

**数据配置**：`miniprogram/mock/data.js`

```javascript
products: [
  {
    _id: 'product_001',
    name: '1618三合一冲锋衣',
    categoryId: 'category_002',              // ← 所属分类
    images: [                                // ← 商品主图数组
      '/images/products/product-1.jpg',      // 第一张图（封面）
      '/images/products/product-1-back.jpg', // 第二张图（背面）
      '/images/products/product-1-side.jpg'  // 第三张图（侧面）
    ],
    type: '三合一',
    material: '100%聚酯纤维',
    style: '通款',
    price: 299,
    sales: 100,
    status: 1,  // 1=上架，0=下架
    description: '专业户外三合一冲锋衣，防风防水透气'
  }
]
```

**上传步骤**：
1. 将商品图片放到 `miniprogram/images/products/` 目录
2. 命名为 `product-{序号}.jpg`
3. 在 `mock/data.js` 的 `products` 数组中添加商品配置
4. **重要**：设置正确的 `categoryId` 来关联到对应分类

**命名规范**：
```
product-{序号}.jpg          // 正面图（必须）
product-{序号}-back.jpg     // 背面图（可选）
product-{序号}-side.jpg     // 侧面图（可选）
product-{序号}-detail.jpg   // 细节图（可选）

示例：
product-1.jpg        (商品1正面图)
product-1-back.jpg   (商品1背面图)
product-2.jpg        (商品2正面图)
```

### 4️⃣ 商品详情图 (`details/`)

**显示位置**：商品详情页底部"商品详情"区域

**图片规格**：
- 尺寸：宽度 750 rpx（高度自适应）
- 格式：JPG / PNG
- 数量：每个商品多张
- 用途：展示商品细节、材质、尺寸等信息

**数据配置**：`miniprogram/mock/data.js`

```javascript
products: [
  {
    _id: 'product_001',
    name: '1618三合一冲锋衣',
    categoryId: 'category_002',
    images: ['/images/products/product-1.jpg'],
    detailImages: [                         // ← 详情图数组
      '/images/details/244ae4366a6a5e8c25d5503f5c5a8005.jpg',
      '/images/details/5b307b82bee0b70c3dfc94f12c560194.jpg',
      '/images/details/6510047d2a6afa723ecad5d310b8729b.jpg',
      '/images/details/6513b381972df7dd7520f201e403e3aa.jpg',
      '/images/details/6b9b8345e561fd4976f6d33e716c3cd6.jpg',
      '/images/details/84f5acba93f4b369891dda2f11448036.jpg',
      '/images/details/8e34f8da3ed64542c8486eced2de3145.jpg'
    ],
    // ... 其他字段
  }
]
```

**上传步骤**：
1. 将详情图片放到 `miniprogram/images/details/` 目录
2. 命名建议：
   - 方案A：`detail-{商品序号}-{序号}.jpg`
   - 方案B：使用原始文件名
3. 在商品配置的 `detailImages` 数组中添加图片路径

**命名规范**：
```
detail-{商品序号}-{序号}.jpg

示例：
detail-1-1.jpg  (商品1的第1张详情图)
detail-1-2.jpg  (商品1的第2张详情图)
detail-1-3.jpg  (商品1的第3张详情图)
```

## 🎨 实际操作示例

### 场景：为"2025秋冬款"添加新商品

#### 第一步：准备图片

假设您有以下图片：
```
photo_front.jpg  (商品正面图)
photo_back.jpg   (商品背面图)
detail_1.jpg     (详情图1)
detail_2.jpg     (详情图2)
```

#### 第二步：复制到对应目录

```bash
# 复制商品主图
cp photo_front.jpg miniprogram/images/products/product-12.jpg
cp photo_back.jpg miniprogram/images/products/product-12-back.jpg

# 复制详情图
cp detail_1.jpg miniprogram/images/details/detail-12-1.jpg
cp detail_2.jpg miniprogram/images/details/detail-12-2.jpg
```

#### 第三步：在 mock/data.js 中添加商品

```javascript
products: [
  // ... 前面的商品

  {
    _id: 'product_012',                        // 唯一ID
    name: '加绒加厚卫衣',                       // 商品名称
    categoryId: 'category_001',                // ← 2025秋冬款
    images: [                                  // 商品主图
      '/images/products/product-12.jpg',       // 正面
      '/images/products/product-12-back.jpg'   // 背面
    ],
    detailImages: [                            // 商品详情图
      '/images/details/detail-12-1.jpg',
      '/images/details/detail-12-2.jpg'
    ],
    type: '卫衣',
    material: '棉',
    style: '宽松款',
    price: 199,
    sales: 0,
    status: 1,
    description: '加绒加厚，保暖舒适'
  }
]
```

#### 第四步：保存并编译

1. 保存 `mock/data.js` (Ctrl+S)
2. 在微信开发者工具中点击"编译"
3. 切换到"分类"页面
4. 点击"2025秋冬款"
5. ✅ 看到新商品！

## ⚠️ 常见错误与注意事项

### ❌ 错误示例

#### 1. 图片路径错误
```javascript
// ❌ 错误：缺少开头的 /
images: ['images/product-1.jpg']

// ✅ 正确
images: ['/images/products/product-1.jpg']
```

#### 2. 分类ID错误
```javascript
// ❌ 错误：ID不完整
categoryId: '001'

// ✅ 正确
categoryId: 'category_001'
```

#### 3. 忘记添加 status 字段
```javascript
// ❌ 错误：商品不会显示
{
  name: '测试商品',
  // ... 其他字段
  // 缺少 status: 1
}

// ✅ 正确
{
  name: '测试商品',
  status: 1,  // 1=上架，0=下架
  // ... 其他字段
}
```

#### 4. 图片不是数组
```javascript
// ❌ 错误：应该是数组
images: '/images/products/product-1.jpg'

// ✅ 正确
images: ['/images/products/product-1.jpg']
```

#### 5. detailImages 回退逻辑错误
```javascript
// ❌ 错误：没有回退逻辑
const detailImages = product.detailImages;

// ✅ 正确：有回退逻辑
const detailImages = product.detailImages || product.images || [];
```

## 💡 专业提示

### 1. 图片优化
- 使用 TinyPNG 等工具压缩图片
- 商品主图建议控制在 200KB 以内
- 详情图建议控制在 500KB 以内

### 2. 命名建议
- 使用英文和数字，避免中文
- 使用连字符 `-` 分隔，不要用空格
- 保持命名一致性

### 3. 数据管理
- 定期备份 `mock/data.js`
- 建立商品ID和图片的对应关系表
- 使用 Excel 等工具管理商品信息

### 4. 批量操作
如果需要添加大量商品：
1. 使用脚本批量重命名图片
2. 使用 Excel 生成 JSON 配置
3. 使用代码编辑器的批量替换功能
