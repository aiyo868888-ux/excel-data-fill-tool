## 问题描述

### 现象

**体验用户无法看到云存储图片**，具体表现为：
- 首页轮播图空白
- 商品图片无法显示
- 分类图标不显示
- 开发者（创建者）可以正常看到

### 环境

- **小程序**: 服装定制小程序
- **AppID**: wx7ca3c8748e1fdf6e
- **云环境**: cloud1-2g7e3gch6d0592e5
- **云开发版本**: 免费版

## 问题诊断

### 根本原因

**免费版云存储权限限制**：
```json
{
  "read": "auth.openId != null",
  "write": "auth.openId != null"
}
```

**权限解析**：
- 只有文件的**创建者**（匹配 `openid`）可以读取
- 体验用户的 `openid` 与开发者不同
- 因此体验用户无法访问 `cloud://` 链接

### 诊断过程

#### 1. 初步排查

**现象对比**：
- ✅ 开发版：图片正常显示
- ❌ 体验版：图片全部空白

**初步判断**：可能是权限问题

#### 2. 权限配置检查

**云存储权限规则**：
```
读取权限：仅创建者可读
写入权限：仅创建者可写
```

**确认**：免费版**无法设置公共读权限** `"read": true`

#### 3. API 测试

**测试客户端 API**：
```javascript
wx.cloud.getTempFileURL({
  fileList: [{ fileID: 'cloud://...' }]
})
```

**结果**：
- 开发版：成功返回临时链接
- 体验版：调用失败（权限不足）

#### 4. 解决方案探索

**临时链接方案**：
- `wx.cloud.getTempFileURL` 可生成临时 HTTPS 链接
- 临时链接包含签名，所有用户可访问
- 有效期2小时

**问题**：客户端 API 在体验版因权限失败

**最终方案**：**云函数代理**

## 实施步骤

### 第一步：创建云函数

**文件**: `cloudfunctions/getImageURL/index.js`

```javascript
const cloud = require('wx-server-sdk')
cloud.init({ env: cloud.DYNAMIC_CURRENT_ENV })

exports.main = async (event, context) => {
  const { fileIds } = event

  if (!fileIds || fileIds.length === 0) {
    return {
      code: 400,
      error: 'fileIds 参数不能为空'
    }
  }

  try {
    const result = await cloud.getTempFileURL({
      fileList: fileIds.map(id => ({
        fileID: id,
        maxAge: 7200 // 2小时有效期
      }))
    })

    return {
      code: 200,
      data: result.fileList
    }
  } catch (err) {
    return {
      code: 500,
      error: err.message || err.errMsg
    }
  }
}
```

## 代码实现

### 完整的 simple-image-loader.js

```javascript
/**
 * 简化版图片加载器
 * 直接使用云函数获取临时链接
 */
const CLOUD_FUNCTION_NAME = 'getImageURL';

/**
 * 批量加载对象的图片
 */
async function loadImages(items, imageField = 'image') {
  if (!items) return items;

  if (Array.isArray(items)) {
    // 判断第一个元素是否有 images 数组（商品对象）
    if (items.length > 0 && items[0].images && Array.isArray(items[0].images)) {
      // 商品数组
      const promises = items.map(item => loadProductImages(item));
      return await Promise.all(promises);
    } else {
      // 普通对象数组（banners, categories）
      const promises = items.map(item => loadSingleImageField(item, imageField));
      return await Promise.all(promises);
    }
  }

  // 单个对象
  if (items.images && Array.isArray(items.images)) {
    return await loadProductImages(items);
  } else {
    return await loadSingleImageField(items, imageField);
  }
}

/**
 * 加载商品详情（包括 images 数组）
 */
async function loadProductImages(product) {
  if (!product) return product;
  let loadedProduct = { ...product };

  // 加载 images 数组
  if (loadedProduct.images && Array.isArray(loadedProduct.images)) {
    const cloudImages = loadedProduct.images.filter(img =>
      typeof img === 'string' && img.startsWith('cloud://')
    );

    if (cloudImages.length > 0) {
      const result = await wx.cloud.callFunction({
        name: CLOUD_FUNCTION_NAME,
        data: { fileIds: cloudImages }
      });

      if (result.result && result.result.code === 200 && result.result.data) {
        const tempURLs = result.result.data.map(f => f.tempFileURL || cloudImages[0]);

        loadedProduct.images = loadedProduct.images.map(img => {
          if (typeof img === 'string' && img.startsWith('cloud://')) {
            const index = cloudImages.indexOf(img);
            return tempURLs[index] || img;
          }
          return img;
        });
      }
    }
  }

  // 加载 detailImages 数组（逻辑同上）
  // ... (代码省略)

  return loadedProduct;
}

/**
 * 加载单个图片字段
 */
async function loadSingleImageField(item, imageField) {
  if (!item || !item[imageField]) return item;

  const imageUrl = item[imageField];

  if (Array.isArray(imageUrl) ||
      typeof imageUrl !== 'string' ||
      !imageUrl.startsWith('cloud://')) {
    return item;
  }

  try {
    const result = await wx.cloud.callFunction({
      name: CLOUD_FUNCTION_NAME,
      data: { fileIds: [imageUrl] }
    });

    if (result.result && result.result.code === 200 && result.result.data[0]) {
      const tempURL = result.result.data[0].tempFileURL;
      if (tempURL) {
        return { ...item, [imageField]: tempURL };
      }
    }
  } catch (err) {
    console.warn(`[SimpleImageLoader] ${imageField} 加载失败:`, err);
  }

  return item;
}

module.exports = {
  loadImages,
  loadProductImages
};
```

## 技术原理

### 1. 云存储临时链接机制

**生成过程**：
```javascript
cloud.getTempFileURL({
  fileList: [{
    fileID: 'cloud://xxx',
    maxAge: 7200  // 2小时（单位：秒）
  }]
})
```

**返回结果**：
```json
{
  "fileID": "cloud://xxx",
  "tempFileURL": "https://636c-cloud1-xxx.tcb.qcloud.la/path/file.png?sign=xxx&t=xxx",
  "status": 0,
  "errMsg": "getTempFileURL:ok"
}
```

**URL 解析**：
- **协议**: HTTPS（可公开访问）
- **签名**: `sign=xxx`（验证身份）
- **时间戳**: `t=xxx`（过期时间）
- **有效期**: 2小时

### 2. 权限对比

| 调用方式 | 权限 | 体验版可用性 |
|---------|------|------------|
| 客户端 `wx.cloud.getTempFileURL` | 用户权限（受限） | ❌ 失败 |
| 云函数 `cloud.getTempFileURL` | 管理员权限（完整） | ✅ 成功 |

### 3. 为什么云函数可以绕过限制？

**关键点**：
- 云函数运行在服务端
- 云函数使用的是**服务端的权限**
- 服务端有完整的云存储访问权限
- 不受 `auth.openId` 限制

## FAQ

### Q1: 为什么不使用公共读权限？

**A**: 免费版不支持公共读权限。只有付费版才能设置 `"read": true`。

### Q2: 临时链接会过期吗？

**A**: 会的。有效期2小时。但对于页面加载来说足够了。

### Q3: 云函数有免费额度吗？

**A**: 有的。免费版每月有一定的免费调用次数，对于小程序来说足够使用。

### Q4: 如果图片很多会影响性能吗？

**A**: 会有影响。可以：
- 批量加载（一次最多50张）
- 分批处理（超过50张时）
- 懒加载（只加载可见区域的图片）

### Q5: 可以缓存临时链接吗？

**A**: 可以的。临时链接2小时有效，可以缓存在本地存储中，减少重复调用。

### Q6: 体验版和正式版有区别吗？

**A**: 没有区别。这个方案对体验版和正式版都有效。

### Q7: 需要修改云存储权限配置吗？

**A**: 不需要。保持默认权限即可。云函数会自动处理权限问题。

### Q8: 如果云函数调用失败怎么办？

**A**: 代码中有降级处理，会使用原始的 `cloud://` 链接。虽然体验用户看不到，但页面不会崩溃。
