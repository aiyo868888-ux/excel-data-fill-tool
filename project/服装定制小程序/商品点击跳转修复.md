# ✅ 商品点击跳转修复完成

## 🔧 问题原因

设计页在 `tabBar` 中，不能使用 `wx.navigateTo` 跳转（只能跳转到非 tabBar 页面）。

对于 tabBar 页面，必须使用 `wx.switchTab`，但 `switchTab` 无法传递 URL 参数。

## 💡 解决方案

使用 `globalData` 传递商品ID：

```
首页/分类页
    ↓
点击商品 → 保存 productId 到 globalData
    ↓
wx.switchTab 跳转到设计页
    ↓
设计页从 globalData 读取 productId
    ↓
加载对应的商品信息
```

## 📝 修改的文件

### 1. [app.js](miniprogram/app.js:10-14)
添加 `selectedProductId` 到 globalData

```javascript
globalData: {
  userInfo: null,
  version: '1.0.0-local',
  selectedProductId: null  // 用于传递选中的商品ID
}
```

### 2. [pages/index/index.js](miniprogram/pages/index/index.js:73-103)
修改 `onProductTap` 方法

```javascript
onProductTap(e) {
  const id = e.currentTarget.dataset.id;

  // 保存到 globalData
  const app = getApp();
  app.globalData.selectedProductId = id;

  // 使用 switchTab 跳转
  wx.switchTab({
    url: '/pages/design/design'
  });
}
```

### 3. [pages/category/category.js](miniprogram/pages/category/category.js:93-123)
同样的修改

### 4. [pages/design/design.js](miniprogram/pages/design/design.js:15-73)
修改 `onLoad` 和添加 `onShow` 方法

```javascript
onLoad(options) {
  // 从 globalData 获取商品ID
  const app = getApp();
  const productId = app.globalData.selectedProductId || options.productId;

  if (productId) {
    const product = mockData.products.find(p => p._id === productId);
    // 加载商品...
  }
},

onShow() {
  // 每次显示时检查是否有新的商品选择
  const app = getApp();
  if (app.globalData.selectedProductId) {
    // 加载新商品...
  }
}
```

## 📊 调试日志说明

所有调试日志都以 `===` 开头，很容易识别：

- `=== onProductTap 被调用 ===` - 首页/分类页点击事件
- `=== 分类页 onProductTap 被调用 ===` - 分类页点击事件

如果看到这些日志，说明点击事件被触发了。
如果没有看到，说明 `bindtap` 没有正确绑定。
