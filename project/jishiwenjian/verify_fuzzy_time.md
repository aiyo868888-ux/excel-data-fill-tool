# 模糊时间功能验证清单

## 编译和运行

### 1. 编译项目
```bash
cd project/jishiwenjian
./gradlew assembleDebug
```

### 2. 安装到设备
```bash
./gradlew installDebug
```

### 3. 运行单元测试
```bash
./gradlew test --tests FuzzyTimeParserTest
```
