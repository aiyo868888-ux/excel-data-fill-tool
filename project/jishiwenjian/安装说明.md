## 手动安装步骤

### 方法 1：使用 Android Studio
1. 打开 Android Studio
2. 打开项目：`d:\claude code -11\project\jishiwenjian`
3. 连接 Android 设备（启用 USB 调试）
4. 点击运行按钮（▶️）或按 `Shift + F10`

### 方法 2：使用命令行
1. 打开命令提示符（CMD）或 PowerShell
2. 进入目录：
   ```cmd
   cd "d:\claude code -11\project\jishiwenjian"
   ```
3. 检查设备连接：
   ```cmd
   adb devices
   ```
4. 安装 APK：
   ```cmd
   adb install -r app\build\outputs\apk\debug\app-debug.apk
   ```

### 方法 3：直接复制到手机
1. 将 `app-debug.apk` 复制到手机存储
2. 在手机文件管理器中找到 APK 文件
3. 点击安装（可能需要允许"未知来源"安装）
