# 🔍 保存内容不显示 - 诊断指南

## 问题现象
保存内容后，在灵感/启发/待办界面看不到内容

---

## 📋 诊断步骤

### 步骤 1：安装调试版本

1. **等待构建完成**  
   当前正在后台构建调试版本，等待窗口显示"✅ 安装成功"

2. **重启应用**  
   完全关闭应用，然后重新打开

---

### 步骤 2：修复默认标签

1. 打开应用
2. 进入"**设置**"页面
3. 点击"**🔧 修复默认标签**"按钮
4. 看到"✅ 默认标签已修复"

---

### 步骤 3：启动日志监控

1. **双击运行**：`view_debug_log.bat`
2. 窗口会显示实时日志
3. **保持窗口打开**

---

### 步骤 4：测试保存功能并观察日志

#### 在手机上操作：
1. 回到"**灵感**"页面
2. 点击右下角 **➕** 按钮
3. 输入内容："测试内容 123"
4. 确认"**灵感**"标签已选中（蓝色）
5. 点击"**保存**"按钮

#### 在电脑日志窗口观察：

**应该看到以下日志**：

## 🚨 可能的问题场景

### 场景 A：标签 ID 为 null

**日志显示**：
```
UnifiedContentRepository: ⚠️ 灵感标签 ID 未初始化，返回空 Flow
```

**原因**：默认标签未创建或初始化失败

**解决方法**：
1. 重新点击"修复默认标签"按钮
2. 完全关闭应用并重启
3. 检查日志是否显示"创建默认标签: 灵感"

---

### 场景 B：保存时标签列表为空

**日志显示**：
```
ClipboardEdit: 标签列表: []
```

**原因**：对话框中的标签未被选中

**解决方法**：
1. 打开对话框后，**手动点击**"灵感"标签确保选中
2. 选中的标签应显示为**蓝色背景**
3. 再点击保存

---

### 场景 C：数据保存成功但未触发更新

**日志显示**：
```
ClipboardEdit: 保存成功！返回 ID: 5
```
但没有看到 `InspirationFragment: 灵感数据更新`

**原因**：Flow 订阅未生效或数据库查询失败

**解决方法**：
1. 切换到其他页面（如启发）
2. 再切回灵感页面
3. 检查是否显示

---

### 场景 D：标签关联未创建

**日志显示**：
```
ClipboardRepository: 保存剪贴板成功: id=5, 标签数=0
```

**原因**：标签筛选逻辑出错，标签未关联到剪贴板

**解决方法**：
需要检查 `ClipboardRepository.attachTagsToClipboard()` 方法
