# 支持的时间模式

本文档列出了所有支持的时间表达模式。

## 1. 绝对时间

### 完整日期格式

| 模式 | 示例 | 解析结果 |
|------|------|----------|
| `YYYY年MM月DD日` | 2025年1月20日 | 2025-01-20 00:00:00 |
| `YYYY年M月D日` | 2025年1月5日 | 2025-01-05 00:00:00 |
| `YYYY/MM/DD` | 2025/01/20 | 2025-01-20 00:00:00 |
| `YYYY/M/D` | 2025/1/5 | 2025-01-05 00:00:00 |
| `MM/DD/YYYY` | 1/20/2025 | 2025-01-20 00:00:00 |
| `M/D/YYYY` | 1/5/2025 | 2025-01-05 00:00:00 |

### 简短日期格式

| 模式 | 示例 | 解析结果 |
|------|------|----------|
| `MM月DD日` | 1月20日 | 当年 01-20 00:00:00 |
| `M月D日` | 1月5日 | 当年 01-05 00:00:00 |
| `M月D号` | 1月20号 | 当年 01-20 00:00:00 |

### 时间点格式

| 模式 | 示例 | 解析结果 |
|------|------|----------|
| `H点` | 3点 | 当日 03:00:00 |
| `H点m分` | 3点15分 | 当日 03:15:00 |
| `H:m` | 3:15 | 当日 03:15:00 |
| `HH:mm` | 15:30 | 当日 15:30:00 |
| `上午H点` | 上午9点 | 当日 09:00:00 |
| `下午H点` | 下午3点 | 当日 15:00:00 |
| `早上H点` | 早上8点 | 当日 08:00:00 |
| `晚上H点` | 晚上7点 | 当日 19:00:00 |
| `凌晨H点` | 凌晨2点 | 当日 02:00:00 |
| `半夜H点` | 半夜11点 | 当日 23:00:00 |

### 日期 + 时间组合

| 模式 | 示例 | 解析结果 |
|------|------|----------|
| `MM月DD日H点` | 1月20日3点 | 01-20 03:00:00 |
| `YYYY年MM月DD日H点` | 2025年1月20日下午3点 | 2025-01-20 15:00:00 |
| `MM月DD日HH:mm` | 1月20日15:30 | 01-20 15:30:00 |

## 4. 优先级关键词

### 高优先级

| 关键词 | 示例 | 优先级 |
|--------|------|--------|
| `紧急` | 紧急处理bug | high |
| `重要` | 重要会议 | high |
| `急` | 急事 | high |
| `!!!` | 重要!!! | high |
| `今天` | 今天完成 | high |
| `马上` | 马上处理 | high |
| `立即` | 立即执行 | high |
| `尽快` | 尽快完成 | high |

### 中等优先级

| 关键词 | 示例 | 优先级 |
|--------|------|--------|

| `!!` | 任务!! | medium |

| `可以延后` | 可以延后处理 | low |

## 5. 标签格式

### 标签语法

| 格式 | 示例 | 提取标签 |
|------|------|----------|
| `#标签` | 明天开会 #工作 | ["工作"] |
| `#标签1 #标签2` | 任务 #工作 #重要 | ["工作", "重要"] |
| `#中文标签` | 提交报告 #文档 | ["文档"] |
| `#EnglishTag` | Meeting #work | ["work"] |

### 标签和任务混合

| 输入 | 任务 | 标签 |
|------|------|------|
| `明天开会 #工作` | 开会 | ["工作"] |
| `下午3点开会 #工作 准备PPT` | 开会，准备PPT | ["工作"] |
| `#重要 明天交报告` | 交报告 | ["重要"] |

## 7. 不支持的模式

以下模式**暂不支持**（可能在未来版本添加）：

- ❌ 条件时间："完成X后3天内"
- ❌ 口语化表达："过两天"、"近期"
- ❌ 节假日："春节前"、"国庆后"
- ❌ 工作日："下个工作日"
- ❌ 月份范围："1-3月期间"

## 8. 扩展支持

### 添加自定义模式

```python
from smart_todo_parser.config.patterns import TIME_PATTERNS

# 添加自定义时间模式
TIME_PATTERNS['custom'] = [
    r'大后天',  # 3天后
    r'下下个星期',  # 2周后
]

parser = TodoParser()
result = parser.parse("大后天开会")
```

### 添加自定义优先级关键词

```python
from smart_todo_parser.config.patterns import PRIORITY_KEYWORDS

# 添加自定义关键词
PRIORITY_KEYWORDS['high'].extend(['加急', '特急'])

parser = TodoParser()
result = parser.parse("明天加急处理")
# result["priority"] == "high"
```

## 9. 最佳实践

### 明确时间表达

**推荐：**
- ✅ 明天下午3点开会
- ✅ 2025年1月20日提交
- ✅ 3天后完成

**避免：**
- ❌ 过两天（不明确）
- ❌ 近期（模糊）
- ❌ 不久的将来（无意义）

### 优先级标注

**推荐：**
- ✅ 明天紧急处理bug
- ✅ 下周重要会议
- ✅ 有空时整理文档

**避免：**
- ❌ 明天！！！（过度强调）
- ❌ 超级重要任务（非标准关键词）

### 标签使用

**推荐：**
- ✅ 明天开会 #工作
- ✅ 提交报告 #重要 #文档
- ✅ 周末聚会 #个人

**避免：**
- ❌ #很长的标签名称不推荐
- ❌ #多个#连续#标签
- ❌ 标签在句中（应放在句末）
