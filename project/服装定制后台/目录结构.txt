服装定制后台/
│
├── README.md                  # 项目说明文档
├── 启动指南.md                # 详细启动说明
├── 一键安装.bat               # Windows 一键安装脚本
├── 启动服务.bat               # Windows 启动服务脚本
│
├── server/                    # 后端服务目录
│   ├── .env                   # 环境变量配置文件 ⭐需要配置环境ID
│   ├── .env.example           # 环境变量示例文件
│   ├── app.js                 # Express 服务器主文件
│   ├── package.json           # 后端依赖配置
│   │
│   ├── config/                # 配置目录
│   │   └── cloud.js           # 云开发初始化配置
│   │
│   └── routes/                # API 路由目录
│       ├── products.js        # 商品管理 API
│       ├── categories.js      # 分类管理 API
│       ├── cloud.js           # 云开发状态 API
│       └── upload.js          # 文件上传 API
│
└── admin/                     # 前端管理界面目录
    ├── package.json           # 前端依赖配置
    ├── vite.config.js         # Vite 构建配置
    ├── index.html             # HTML 入口文件
    │
    └── src/                   # 源代码目录
        ├── main.js            # Vue 应用入口
        ├── App.vue            # 根组件
        │
        ├── router/            # 路由配置
        │   └── index.js       # 路由定义
        │
        └── views/             # 页面组件
            ├── Dashboard.vue  # 数据概览页面
            ├── Products.vue   # 商品管理页面
            └── Categories.vue # 分类管理页面

============================================================

快速启动步骤：
1. 双击运行 "一键安装.bat"
2. 输入云开发环境ID
3. 等待安装完成
4. 双击运行 "启动服务.bat"
5. 访问 http://localhost:3000

============================================================

重要文件说明：
⭐ server/.env - 必须配置！填写你的云开发环境ID
