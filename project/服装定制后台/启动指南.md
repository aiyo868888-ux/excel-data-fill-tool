# 🚀 后台管理系统启动指南

## 📋 系统概述

这是一个为**服装定制小程序**打造的本地后台管理系统，可以方便地管理商品、分类、设计模板等数据。

**特点：**
- ✅ 本地运行，无需部署服务器
- ✅ 直接连接云开发数据库
- ✅ 可视化管理界面
- ✅ 支持商品和分类的增删改查

---

## 🔧 安装步骤（5分钟）

### 步骤1：配置环境ID

**打开文件：** `server/.env`

如果该文件不存在，先复制示例文件：

```bash
cd server
cp .env.example .env
```

**编辑 .env 文件：**

```env
# 云开发环境配置
CLOUD_ENV_ID=cloud1-xxx  # ⬅️ 替换为你的环境ID

# 服务器配置
PORT=3000
```

**如何获取环境ID：**
- 打开云开发控制台
- 查看环境名称旁边的ID
- 或查看URL中的 `envId=cloud1-xxx` 部分

---

### 步骤2：安装后端依赖

```bash
cd server
npm install
```

如果安装失败，尝试使用淘宝镜像：

```bash
npm install --registry=https://registry.npmmirror.com
```

---

### 步骤3：安装前端依赖

```bash
cd ../admin
npm install
```

同样，如果安装失败，使用淘宝镜像：

```bash
npm install --registry=https://registry.npmmirror.com
```

---

### 步骤4：启动服务

**方式1：生产模式（推荐）**

先构建前端：

```bash
cd admin
npm run build
```

然后启动后端：

```bash
cd ../server
npm start
```

**访问地址：** http://localhost:3000

---

**方式2：开发模式**

**终端1 - 启动后端：**

```bash
cd server
npm start
```

**终端2 - 启动前端（需要另外打开一个终端）：**

```bash
cd admin
npm run dev
```

**后端地址：** http://localhost:3000
**前端地址：** http://localhost:8080

## ✅ 验证安装成功

### 1. 检查后端服务

打开浏览器访问：http://localhost:3000/api/health

应该看到：

```json
{
  "status": "ok",
  "message": "后台服务运行正常"
```

## 📖 使用指南

### 添加分类

1. 点击左侧菜单 **"分类管理"**
2. 点击 **"添加分类"** 按钮
3. 填写分类信息：
   - 分类名称：如 "冲锋衣系列"
   - 父级ID：留空则为顶级分类
   - 排序：数字越小越靠前
   - 图标路径：如 `/images/category-1.png`
4. 点击 **"确定"** 保存

### 添加商品

1. 点击左侧菜单 **"商品管理"**
2. 点击 **"添加商品"** 按钮
3. 填写商品信息：
   - 商品名称：如 "1618三合一冲锋衣"
   - 分类ID：输入上面创建的分类ID
   - 类型：如 "三合一"
   - 材质：如 "100%聚酯纤维"
   - 款式：如 "通款"
   - 价格：如 299
   - 状态：上架/下架
   - 描述：商品详细描述
4. 点击 **"确定"** 保存

## 🐛 常见问题

### Q1: npm install 安装失败

**解决方案：**

```bash
# 使用淘宝镜像
npm install --registry=https://registry.npmmirror.com

# 或使用 cnpm
npm install -g cnpm --registry=https://registry.npmmirror.com
cnpm install
```

---

### Q2: 启动后报错 "Cannot find module"

**原因：** 依赖未安装完整

**解决方案：**

```bash
# 重新安装依赖
cd server
npm install

cd ../admin
npm install
```

---

### Q3: 点击"检查云开发连接"失败

**原因：** 环境ID配置错误

**解决方案：**

1. 检查 `server/.env` 文件中的 `CLOUD_ENV_ID`
2. 确保环境ID正确（格式：cloud1-xxx）
3. 确保云开发环境已开通且状态正常
4. 修改后需要重启服务

---

### Q4: 前端页面空白

**原因：** 前端未构建或构建失败

**解决方案：**

```bash
cd admin

# 方式1：开发模式（自动刷新）
npm run dev

# 方式2：生产模式（需要构建）
npm run build
cd ../server
npm start
```

---

### Q5: 端口被占用

**错误提示：** `Error: listen EADDRINUSE: address already in use :::3000`

**解决方案：**

**修改端口：**

编辑 `server/.env` 文件：

```env
PORT=3001  # 改为其他端口
```

或者关闭占用端口的程序：

```bash
# Windows
netstat -ano | findstr :3000
taskkill /PID <进程ID> /F

# Mac/Linux
lsof -ti:3000 | xargs kill -9
```
