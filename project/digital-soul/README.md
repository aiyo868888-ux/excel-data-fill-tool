# Digital Soul - 个人数字分身系统

一个能够从日常 AI 交互中持续学习并动态更新的个人记忆系统。

## 🎯 项目目标

构建一个"活"的数字分身系统，能够：
- 🧠 从对话中提取价值观、性格特征、思维模式
- 🔄 动态更新个人画像（持续进化）
- 🎭 模拟用户决策风格
- 💡 提供个性化建议和提示词生成

## 🛠 技术栈

- **桌面框架**: Electron 40 + Vue 3
- **UI 组件**: Element Plus 2.3
- **状态管理**: Pinia
- **数据库**: SQLite (better-sqlite3)
- **构建工具**: Vite 5
- **类型检查**: TypeScript 5.3

## 📁 项目结构

```
digital-soul/
├── electron/          # Electron 主进程
│   ├── main.ts       # 主进程入口
│   └── database/     # 数据库管理
├── src/              # Vue 前端代码
│   ├── core/         # 核心业务逻辑
│   ├── components/   # Vue 组件
│   ├── stores/       # Pinia 状态管理
│   └── views/        # 页面视图
├── build/            # 构建配置
└── tests/            # 测试文件
```

## 🚀 快速开始

### 安装依赖

```bash
cd project/digital-soul
npm install
```

### 开发模式

```bash
npm run dev
```

### 构建

```bash
npm run build
```
