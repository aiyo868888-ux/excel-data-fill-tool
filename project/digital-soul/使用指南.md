# Digital Soul 使用指南

## 🚀 快速开始

### 1. 启动应用

应用已经在运行中，访问地址：

```
http://localhost:5177
```

### 2. 主要功能

#### 📝 对话功能 (`/home`)
- **位置**: 点击左侧菜单"对话"或访问 http://localhost:5177/#/home
- **功能**:
  - 创建新对话：点击"新对话"按钮
  - 发送消息：在底部输入框输入内容，点击"发送"或按 Ctrl+Enter
  - 查看历史：所有消息会显示在对话区域
  - 自动回复：系统会模拟 AI 回复（MVP 版本）

**使用步骤：**
1. 打开对话页面
2. 在输入框中输入你的问题或想法
3. 点击"发送"按钮
4. 等待 AI 回复（约1秒）

#### 👤 分身画像 (`/soul`)
- **位置**: 点击左侧菜单"分身画像"或访问 http://localhost:5177/#/soul
- **功能**: 查看和管理你的数字分身画像

**包含内容：**
1. **价值观** - 展示你的核心价值观（字体大小表示重要程度）
2. **性格特质** - 五大人格特质的评分
3. **关注方向** - 当前关注的话题和趋势
4. **评估指标** - 分身的稳定性、一致性、完整性、准确性

**操作：**
- 点击"刷新"按钮重新加载数据
- 切换标签页查看不同维度

#### 🎯 决策模拟 (`/decision`)
- **位置**: 点击左侧菜单"决策模拟"
- **状态**: 开发中

#### 🛠️ 工具箱 (`/tools`)
- **位置**: 点击左侧菜单"工具箱"
- **状态**: 开发中

#### 📊 数据分析 (`/analytics`)
- **位置**: 点击左侧菜单"数据分析"
- **状态**: 开发中

#### ⚙️ 设置 (`/settings`)
- **位置**: 点击左侧菜单"设置"或访问 http://localhost:5177/#/settings
- **功能**: 系统设置和配置

## 🔧 开发者模式

当前运行在**浏览器模式**：
- ✅ 所有前端功能正常
- ✅ 使用模拟数据
- ✅ 完整的 UI 交互
- ⚠️ 数据不会持久化（刷新后重置）

### 完整功能（需要 Electron）
要使用完整功能（包括数据持久化），需要：
1. 安装 Visual Studio Build Tools
2. 重新安装依赖：`npm install`
3. 运行：`npm run dev`

## ❓ 常见问题

**Q: 为什么数据是空的？**
A: 当前是浏览器模式，使用模拟数据。完整版本需要 Electron 环境。

**Q: 发送消息后没有回复？**
A: MVP 版本使用固定的模拟回复。AI 集成功能正在开发中。

**Q: 如何保存数据？**
A: 浏览器模式数据不持久化。需要 Electron 版本才能保存。

**Q: 页面显示异常怎么办？**
A: 刷新浏览器（Ctrl+R 或 F5）

## 📞 技术支持

如遇到问题，检查：
1. 开发服务器是否运行（http://localhost:5177）
2. 浏览器控制台是否有错误（F12）
3. 网络连接是否正常
