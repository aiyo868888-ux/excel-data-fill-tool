【快速开始】

1. 双击"启动工具.bat"
2. 浏览器会自动打开 http://localhost:5000
3. 按照页面提示操作即可

【系统要求】

✅ Windows 10/11 (64位)
✅ 约 100MB 可用磁盘空间
✅ 无需安装 Python
✅ 完全离线运行

【版本说明】

本版本为完全离线的绿色版：
✅ 包含便携版 Python 3.11.9
✅ 包含所有依赖包（Flask、pandas、openpyxl、xlrd）
✅ 无需安装任何东西
✅ 复制即用，双击启动
✅ 不修改系统注册表
✅ 卸载时直接删除文件夹即可

【使用流程】

步骤1：上传报表
  - 点击"选择报表文件"
  - 选择 Excel 报表（.xlsx 或 .xls）
  - 输入密码（默认为 1）
  - 点击"上传报表"

步骤2：上传送货商文件
  - 点击列范围按钮（如 AC-AH）
  - 选择送货商的 Excel 文件
  - 选择要填充的日期
  - 点击"粘贴数据"

步骤3：生成文档（可选）
  - 填写表首表尾配置
  - 点击"生成交接单"或"生成入库单"
  - 下载生成的文件

【常见问题】

Q: 双击启动脚本没反应？
A: 检查是否有安全软件拦截，允许运行即可

Q: 提示缺少依赖包？
A: 本绿色版已包含所有依赖，如有问题请联系开发者

Q: 端口 5000 被占用？
A: 关闭占用 5000 端口的程序，或修改 web_app.py 的端口号

Q: 如何卸载？
A: 直接删除整个文件夹即可，不留任何痕迹

【文件说明】

启动工具.bat          : 启动程序（双击这个）
测试环境.bat          : 测试 Python 环境
web_app.py            : Web 应用主程序
数据填充工具.py       : 数据处理核心
suppliers_config.json : 供应商配置文件
templates/            : HTML 页面模板
python/               : 便携版 Python（含所有依赖）

【注意事项】

1. 不要删除 python 文件夹内的任何文件
2. 不要删除 web_app.py 和 数据填充工具.py
3. 重要数据请及时备份
4. 关闭程序前保存所有重要数据

【技术支持】

如有问题：
1. 运行"测试环境.bat"检查环境
2. 检查防火墙是否允许 Python 访问网络
3. 确保磁盘空间充足
