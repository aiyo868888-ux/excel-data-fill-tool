## 问题修复

### 问题1: "Unexpected token '<', '<!doctype '... is not valid JSON"
- **原因**: 服务器返回 HTML 错误页面而不是 JSON
- **影响**: 点击"菜1"等送货单按钮时报错
- **解决**: 添加 Content-Type 检查

### 问题2: 生成入库单失败
- **原因**: 合并单元格的 value 属性只读
- **影响**: 步骤4生成入库单时报错
- **解决**: 跳过 MergedCell 类型的单元格

### 问题3: 字体太小
- **影响**: 页面文字不易阅读
- **解决**: 调整基础字体为 15px，表格字体为 14px
