    便携版 Python 下载指南
═══════════════════════════════════════════════════════════

【自动下载 - 推荐】

如果当前电脑有网络和 PowerShell，请运行：

  powershell -ExecutionPolicy Bypass -File 下载Python.ps1

脚本会自动下载并解压 Embeddable Python。

【手动下载】

如果自动下载失败，请按以下步骤手动下载：

1. 访问 Python 官网下载页面：
   https://www.python.org/downloads/windows/

2. 向下滚动到 "Files" 部分

3. 找到 "Windows embeddable package (64-bit)"
   - 文件名类似：python-3.11.x-embed-amd64.zip
   - 大小约 25-26 MB

4. 下载完成后，解压到以下位置：
   d:\claude code -11\数据填充工具-离线便携版\python\

   解压后的目录结构应该是：
   python\
   ├── python.exe
   ├── python311.dll
   ├── python311._pth  ← 需要修改这个文件
   └── Lib\

5. 修改 python311._pth 文件：

   用记事本打开 python\python311._pth，

   原始内容：
   ```
   python311.zip
   .

   # Uncomment to run site.main() automatically
   #import site
   ```

   修改为（添加两行）：
   ```
   python311.zip
   .
   Lib/site-packages

   # 启用 site-packages
   import site
   ```

   保存文件。

【验证下载】

下载完成后，运行验证脚本：
  验证Python.bat

应该看到：
  ✅ Python 版本：3.11.x

【如果遇到问题】

问题1：下载速度慢
解决：使用国内镜像
  https://mirrors.huaweicloud.com/python/

问题2：找不到对应版本
解决：下载 3.11.x 系列的最新版本即可

问题3：解压后找不到文件
解决：确保解压到正确的目录
