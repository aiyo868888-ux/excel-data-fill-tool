# Excel 数据填充工具 - 完全离线绿色版 v2.0

## 🎉 欢迎使用

这是一个**完全离线的绿色版** Excel 数据填充工具，无需安装 Python 或任何依赖。

## ✨ 主要特点

- ✅ **完全离线**：无需联网下载
- ✅ **无需安装**：包含便携版 Python
- ✅ **复制即用**：双击启动脚本
- ✅ **绿色软件**：不修改系统，删除即卸载
- ✅ **一键启动**：自动打开浏览器

## 🚀 快速开始

### 方法1：直接运行（推荐）

1. 双击 `启动工具.bat`
2. 浏览器自动打开 http://localhost:5000
3. 开始使用！

### 方法2：测试环境

1. 双击 `测试环境.bat`
2. 确认所有依赖正常
3. 再双击 `启动工具.bat`

## 📋 系统要求

- **操作系统**：Windows 10/11 (64位)
- **磁盘空间**：约 100MB
- **内存**：建议 2GB 以上
- **网络**：不需要（完全离线）

## 💡 使用流程

### 1. 上传报表
- 点击"选择报表文件"
- 选择 Excel 报表
- 输入密码（默认：1）
- 点击"上传报表"

### 2. 上传送货商文件
- 点击对应的列范围按钮
- 选择送货商的 Excel 文件
- 选择日期
- 点击"粘贴数据"

### 3. 生成文档
- 填写表首表尾（可选）
- 点击"生成交接单"或"生成入库单"
- 下载文件

## 🛠️ 故障排除

### 问题：双击没反应
**解决**：
- 检查是否有杀毒软件拦截
- 允许运行 .bat 文件

### 问题：端口被占用
**解决**：
```batch
# 查看占用端口的程序
netstat -ano | findstr :5000

# 结束进程
taskkill /F /PID [进程ID]
```

### 问题：依赖包缺失
**解决**：
- 运行 `测试环境.bat` 检查
- 如果提示缺失，说明绿色版不完整
- 请重新下载完整版
