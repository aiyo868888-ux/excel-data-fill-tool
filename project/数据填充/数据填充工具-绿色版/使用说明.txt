# 数据填充工具 - 绿色版使用说明

## 📋 系统要求

- Windows 7/8/10/11
- Python 3.7 或更高版本

## 🚀 快速开始

### 方法一：自动启动（推荐）

双击 `启动工具.bat` 即可自动：
1. 检查Python环境
2. 安装缺失的依赖包
3. 启动Web服务器
4. 打开浏览器访问 http://localhost:8888

### 方法二：手动安装依赖

1. 安装Python（如未安装）
   - 访问 https://www.python.org/downloads/
   - 下载并安装Python 3.7+
   - ⚠️ 安装时务必勾选 "Add Python to PATH"

2. 安装依赖包
   - 双击 `安装依赖.bat`
   - 或在命令行运行：
     ```
     pip install flask openpyxl pandas psutil
     ```

3. 启动工具
   - 双击 `启动工具.bat`

## 📁 文件说明

- `启动工具.bat` - 启动服务器（推荐使用）
- `安装依赖.bat` - 手动安装Python依赖包
- `停止服务器.bat` - 停止所有占用8888端口的进程
- `web_app.py` - Web应用程序主文件
- `数据填充工具.py` - 核心业务逻辑
- `suppliers_config.json` - 供应商配置文件

## 🎯 使用方法

1. 启动工具后，浏览器会自动打开
2. 上传Excel报表文件
3. 选择需要生成的单据类型（交接单、入库单、需求单等）
4. 点击生成并下载

## ⚙️ 常见问题

### Q1: 提示"未检测到Python环境"？
**A**: 请先安装Python并确保添加到PATH环境变量

### Q2: 依赖安装失败？
**A**: 尝试手动运行 `pip install flask openpyxl pandas psutil`

### Q3: 端口8888被占用？
**A**: 双击 `停止服务器.bat` 清理端口

### Q4: 如何停止服务器？
**A**: 在命令行窗口按 Ctrl+C，或运行 `停止服务器.bat`

## 📞 技术支持

如遇问题，请检查：
1. Python版本是否为3.7+
2. 依赖包是否正确安装
3. 防火墙是否允许Python运行
