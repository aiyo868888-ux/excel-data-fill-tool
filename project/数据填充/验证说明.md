### `get_all_numeric_sheets()` 方法
```python
def get_all_numeric_sheets(self):
    """获取所有名称为数字的工作表"""
    numeric_sheets = []
    for sheet_name in self.wb.sheetnames:
        if sheet_name.isdigit():  # ← 关键：只选择数字名称
            numeric_sheets.append((int(sheet_name), sheet_name))

    numeric_sheets.sort()
    return [name for num, name in numeric_sheets]
```
