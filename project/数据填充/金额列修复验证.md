## 技术细节

### 修复前的问题
原代码错误地将 `row_offset == 1` 当作表头行，导致：
- `row_offset=0`：被认为是"送货商信息行"（错误）
- `row_offset=1`：被认为是"表头行"（错误，实际是第1个数据行）
- 金额列从第3行开始计算，导致错位

### 修复后的逻辑
```python
is_header_row = (row_offset == 0)           # 第1行（表头）
is_last_row = (row_offset == num_rows - 1)  # 最后一行（合计）
is_data_row = not (is_header_row or is_last_row)  # 其他所有行（数据）
```

### 金额列处理
- **表头行**：填 `"金额"`
- **数据行**：生成公式 `={qty_col}{row}*{price_col}{row}`
- **合计行**：生成公式 `=SUM({amount_col}{start}:{amount_col}{end})`
