# 修复总结：数字格式和居中对齐

## 修复时间
2026年1月13日

## 问题描述

用户反馈两个问题：
1. **数字被识别为文本类型**：从送货单复制到报表后，单价和数量列被Excel识别为文本，而不是数字
2. **需要居中对齐**：交接单和入库单的内容需要居中排列

## 问题分析

### 根本原因

1. **源数据问题**：检查发现源数据（供应商列）中的数字（数量、单价）存储为 **`str` 类型**（文本），而不是 `int` 或 `float`
   - 例如：`557` 是字符串 `"557"`，`4.5` 是字符串 `"4.5"`

2. **原代码直接复制**：原代码直接复制值，没有类型转换
   ```python
   target_cell.value = source_cell.value  # 直接复制，保留了字符串类型
   ```

3. **对齐方式被复制**：原代码直接复制源数据的对齐方式，没有强制居中

## 修复方案

### 修改文件
`数据填充工具.py` (行 1818-1846)

### 核心修改

#### 1. 数字类型转换

```python
# 其他列：复制值，但将文本数字转换为数值类型
source_value = source_cell.value

# 尝试将文本数字转换为数值
if isinstance(source_value, str):
    # 尝试转换为整数或浮点数
    try:
        if '.' in source_value:
            target_cell.value = float(source_value)  # 带小数点的转换为浮点数
        else:
            target_cell.value = int(source_value)    # 整数转换为整数
    except (ValueError, TypeError):
        # 转换失败，保持原文本
        target_cell.value = source_value
else:
    # 不是文本，直接复制
    target_cell.value = source_value
```

**逻辑**：
- 检查值是否为字符串类型
- 如果是字符串，尝试转换：
  - 包含小数点 `.` → 转换为 `float`
  - 不包含小数点 → 转换为 `int`
  - 转换失败 → 保持原文本
- 非字符串类型 → 直接复制

#### 2. 强制居中对齐

```python
# 复制格式并强制居中对齐
if source_cell.has_style:
    if source_cell.font:
        target_cell.font = source_cell.font.copy()
    if source_cell.border:
        target_cell.border = source_cell.border.copy()

    # 对齐设置：强制居中（覆盖源数据的对齐方式）
    from openpyxl.styles import Alignment
    target_cell.alignment = Alignment(horizontal='center', vertical='center')
```

**逻辑**：
- 复制字体和边框样式
- **覆盖**对齐方式为 `center/center`（水平居中 + 垂直居中）
- 不再复制源数据的对齐方式
