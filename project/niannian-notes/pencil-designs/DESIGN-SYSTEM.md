# 闪念笔记 - 设计系统文档

## 📐 设计原则

### 极简主义
- **留白充足**：最小 16px 边距，给内容呼吸空间
- **聚焦核心**：去除一切不必要的装饰
- **层次清晰**：通过字体大小和颜色建立视觉层级

### Material Design 3
- **现代感**：采用 Material Design 3 设计语言
- **圆角友好**：统一使用 12-24px 圆角
- **动态反馈**：所有交互都有视觉反馈

### 颜色系统
- **低饱和度**：避免过度鲜艳的颜色
- **功能区分**：三种类型用不同颜色标识
- **深色模式支持**：预留深色主题方案

## 🎨 配色方案

### 主色调
```css
--primary: #6200EE;        /* 深紫 - 主要操作 */
--primary-light: #7C4DFF;  /* 浅紫 - 次要操作 */
--primary-dark: #3700B3;   /* 深紫 - 按压状态 */
```

### 类型配色
```css
/* 灵感 */
--inspiration: #FF6B6B;    /* 红色 */
--inspiration-bg: #FFE5E5; /* 浅红背景 */

/* 启发 */
--insight: #4ECDC4;        /* 青色 */
--insight-bg: #E6F9F7;     /* 浅青背景 */

/* 待办 */
--todo: #FFE66D;           /* 黄色 */
--todo-bg: #FFF9E6;        /* 浅黄背景 */
```

### 中性色
```css
--background: #FAFAFA;     /* 浅灰背景 */
--surface: #FFFFFF;        /* 白色表面 */
--surface-variant: #F5F5F5; /* 变体表面 */

--text-primary: #000000;   /* 主要文字 */
--text-secondary: #666666; /* 次要文字 */
--text-tertiary: #999999;  /* 辅助文字 */

--divider: #E8E8E8;        /* 分割线 */
```

## 📏 间距系统

基于 4px 基础网格：

```css
--space-xs: 4px;    /* 极小间距 */
--space-sm: 8px;    /* 小间距 */
--space-md: 12px;   /* 中间距 */
--space-lg: 16px;   /* 大间距 */
--space-xl: 24px;   /* 超大间距 */
--space-2xl: 32px;  /* 特大间距 */
--space-3xl: 48px;  /* 巨大间距 */
```

### 应用场景
- **卡片内部**：16px（左右边距）
- **卡片之间**：20px（垂直间距）
- **页面边距**：16px（左右）
- **元素组间距**：24px

## 🎭 动画规范

### 缓动函数
```css
--ease-standard: cubic-bezier(0.4, 0, 0.2, 1);
--ease-decelerate: cubic-bezier(0, 0, 0.2, 1);
--ease-accelerate: cubic-bezier(0.4, 0, 1, 1);
```

### 时长
- **快速**：150ms（按钮反馈）
- **标准**：250ms（页面切换）
- **缓慢**：350ms（复杂动画）

### 常用动画

#### 淡入（页面切换）
```css
@keyframes fadeIn {
  from {
    opacity: 0;
    transform: translateY(8px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}
```

#### 滑入（对话框）
```css
@keyframes slideUp {
  from {
    transform: translateY(100%);
  }
  to {
    transform: translateY(0);
  }
}
```

#### 按钮反馈
```css
/* 悬停 */
transform: scale(1.05);
transition: transform 150ms;

/* 按压 */
transform: scale(0.95);
transition: transform 150ms;
```
