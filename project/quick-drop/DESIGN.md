# 闪念笔记 - 设计文档

## 应用概述
一个极简的闪念笔记手机应用，支持三个分类：闪念、启发、待办

## 页面结构

### 1. 标签选择页 (启动页/悬浮窗入口)
**用途**: 用户点击悬浮窗后首先看到的页面
**布局**:
- 标题: "闪念笔记" (顶部居中, 大号字体)
- 三个大卡片按钮 (垂直排列):
  - ⚡ 闪念 - 蓝色光晕
    - 标题: "闪念"
    - 描述: "快速记录瞬间的想法"
  - 💡 启发 - 紫色光晕
    - 标题: "启发"
    - 描述: "捕捉灵感的火花"
  - ✓ 待办 - 绿色光晕
    - 标题: "待办"
    - 描述: "规划要完成的任务"

**交互**: 点击任一卡片 → 进入对应的输入页面

### 2. 输入页 (三个分类共用)
**用途**: 输入笔记内容
**布局**:
- 顶部栏:
  - ← 返回按钮 (左侧)
  - 分类标题 (居中, 如 "⚡ 闪念")
- 主体:
  - 大文本输入框 (占满剩余空间)
    - 提示: "在这里输入..."
- 底部:
  - 保存按钮 (渐变色, 全宽)

**交互**:
- 点击返回 → 回到标签选择页
- 点击保存 → 保存到对应分类 → 跳转到该分类的列表页

### 3. 列表页 (三个分类各自独立)
**用途**: 展示某个分类的所有笔记
**布局**:
- 顶部栏:
  - ← 返回按钮 (左侧)
  - 分类标题 (居中, 如 "⚡ 闪念")
  - 占位 (右侧, 保持平衡)
- 主体:
  - 笔记卡片列表 (垂直滚动)
    - 每个卡片显示:
      - 笔记内容
      - 时间戳 (底部, 小号, 灰色)
- 底部导航栏:
  - ⚡ 闪念 (左)
  - 💡 启发 (中)
  - ✓ 待办 (右)
  - 当前选中的分类高亮显示

**交互**:
- 点击返回 → 回到标签选择页
- 点击底部导航 → 切换到其他分类的列表

## 视觉设计

### 配色方案 (暗黑科技风)
- 背景色: #0a0a0f (极深蓝黑)
- 卡片背景: linear-gradient(145deg, #1a1a2e 0%, #161625 100%)
- 文字: #ffffff (主), #9ca3af (次要)
- 闪念蓝: #3b82f6
- 启发紫: #a855f7
- 待办绿: #22c55e
- 渐变按钮: linear-gradient(135deg, #3b82f6 0%, #8b5cf6 100%)

### 光晕效果
- 蓝色光晕: box-shadow: 0 0 20px rgba(59, 130, 246, 0.5)
- 紫色光晕: box-shadow: 0 0 20px rgba(168, 85, 247, 0.5)
- 绿色光晕: box-shadow: 0 0 20px rgba(34, 197, 94, 0.5)

### 字体
- 标题: 24px / 1.5rem, Bold
- 正文: 16px / 1rem, Regular
- 次要: 12px / 0.75rem, Regular (灰色)

### 间距
- 卡片间距: 12px
- 页面边距: 16px
- 卡片内边距: 16px

### 圆角
- 卡片: 16px
- 按钮: 16px
- 输入框: 16px

### 动画
- 悬停放大: hover:scale-105 (标签选择页卡片)
- 按压反馈: active:scale-95
- 过渡: transition-transform duration-200

## 数据结构

### 笔记对象
```javascript
{
  id: number,           // 时间戳
  content: string,      // 笔记内容
  timestamp: string,    // 格式化的时间字符串
  type: 'flash' | 'insight' | 'todo'  // 分类类型
}
```

### 存储方案
- localStorage: `notes_flash`, `notes_insight`, `notes_todo`
- 每个分类独立存储数组
- 新笔记添加到数组开头 (unshift)

## 用户流程

### 快速记录流程
1. 用户点击桌面悬浮窗
2. 打开标签选择页
3. 点击对应分类 (如 "闪念")
4. 进入输入页
5. 输入内容
6. 点击保存
7. 自动跳转到该分类的列表页
8. 可以通过底部导航切换到其他分类

### 查看流程
1. 用户打开应用
2. 显示标签选择页 (或直接显示上次访问的分类列表)
3. 点击分类卡片进入列表
4. 查看该分类的所有笔记
5. 通过底部导航切换分类

## 技术实现

### 前端框架
- React + TypeScript
- Tailwind CSS (样式)
- Vite (构建工具)

### 核心功能
- 路由: 页面切换 (标签选择/输入/列表)
- 状态管理: 当前分类、笔记数据
- 本地存储: localStorage API
- 响应式: 移动端优先设计
