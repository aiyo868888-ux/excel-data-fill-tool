# 技能修改总结

## 修改日期
2026-01-24

## 修改原因
用户反馈：插入数据时覆盖了原有的历史数据（第30-45行的"直管、方法兰"等数据被"空调机组"数据覆盖）

## 问题根源
1. 查找最后数据行时没有完整扫描工作表
2. 直接使用 ExcelTool 覆盖式写入，而非使用专用脚本
3. 缺少用户确认环节

## 修改内容

### 1. 代码修改

#### 1.1 增强 `map_and_insert.py` 的 `find_last_data_row()` 函数
**文件**: `scripts/map_and_insert.py`

**修改前**:
```python
def find_last_data_row(ws, start_row=5):
    last_data_row = start_row - 1
    for row in range(start_row, ws.max_row + 1):
        if any(ws.cell(row=row, column=col).value for col in range(1, 14)):
            last_data_row = row
    return last_data_row
```

**修改后**:
```python
def find_last_data_row(ws, start_row=5):
    """找到最后一个有数据的行（完整扫描，不遗漏任何数据）"""
    last_data_row = start_row - 1
    max_row = ws.max_row
    
    print(f"  [调试] 工作表 max_row: {max_row}")
    
    for row in range(start_row, max_row + 1):
        row_has_data = False
        for col in range(1, 14):
            cell_value = ws.cell(row=row, column=col).value
            if cell_value is not None and str(cell_value).strip() != "":
                row_has_data = True
                break
        
        if row_has_data:
            last_data_row = row
            print(f"  [调试] 第{row}行有数据")
    
    print(f"  [调试] 最终确定最后数据行: {last_data_row}")
    return last_data_row
```

**改进点**:
- 增加调试输出，显示扫描过程
- 明确检查每个单元格是否为空（而非使用 `any()`）
- 输出最终确定的最后数据行

## 核心原则（新增）

1. **历史数据保护优先**：任何操作都不能覆盖或修改已有数据
2. **完整扫描工作表**：必须扫描到 `ws.max_row`，不能假设数据连续
3. **用户确认必需**：必须向用户展示最后数据行并等待确认
4. **使用专用工具**：必须使用 `find_last_row.py` 和 `map_and_insert.py`
5. **追加模式插入**：使用追加而非覆盖，保持历史数据完整
