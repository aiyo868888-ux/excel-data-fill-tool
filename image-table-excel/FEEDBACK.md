# 技能进化记录

## 使用反馈

### 2025-01-22 #3

**场景**：中原证券进场材料统计表（第三次插入）

**输入**：
- 图片类型：照片（风管清单）
- 表格结构：8列22行有效数据
- Excel 模板：中原证券进场材料统计表模板_已填充_v2.xlsx

**输出**：
- 识别准确率：95%
- 用户确认：发现问题
- 处理时间：约 3 秒

**数据映射**：
- 图片列 1（序号）→ Excel 列 1
- 图片列 2（名称）→ Excel 列 3
- 图片列 3-4（长x宽）→ Excel 列 4
- 图片列 6（单位）→ Excel 列 5
- 图片列 5（数量）→ Excel 列 6
- 图片列 7（平方数）→ 未使用（问题！）
- 图片列 8（备注）→ Excel 列 11

**用户反馈**：
- 问题：图片中有"数量"和"平方数"两列，系统默认使用了"数量"列
- 业务需求：风管材料需要按"平方"统计，而不是按"节"统计
- 要求：当图片同时存在"数量"和"平方数"列时，必须询问用户使用哪一列
- 补充说明：其他材料（方法兰、角码等）仍使用原数量，不改为空

**改进方向**：
1. 检测数量列和平方数列共存情况
2. 添加用户确认流程：选择使用"数量"还是"平方数"作为 Excel 的数量列
3. 根据用户选择映射正确的列数据

### 2025-01-22 #1

**输入**：
- 图片类型：照片
- 表格结构：9列12行（风机盘管机组清单）
- Excel 模板：中原证券进场材料统计表模板_已填充.xlsx

**输出**：
- 识别准确率：待确认
- 用户确认：等待反馈
- 处理时间：约 2 秒

**数据映射**：
- 图片列 1（序号）→ Excel 列 1
- 图片列 2（进场时间，新增）→ Excel 列 2
- 图片列 3（型号）→ Excel 列 3
- 图片列 4（单位）→ Excel 列 5
- 图片列 5（数量）→ Excel 列 9

**用户反馈**：
- 问题 1：输出格式不符合需求
  - 要求格式：列表形式（文件表头、提取内容项数、未填入内容、插入问题）
  - 当前格式：叙述性描述
- 问题 2：原有内容与新内容间需要增加空行
- 问题 3：需要将原图嵌入第一行对应列
- 缺失：未说明未填入内容有哪些

**改进方向**：
1. 修改输出格式为列表形式 ✓
2. 自动检测并说明哪些列未填入 ✓
3. 在插入前自动插入空行 ✓
4. 新增：将原图嵌入到第一行数据的对应列

## 迭代历史

### 版本 1.3.0 (2025-01-22)
**基于用户反馈的优化**
- 变更 1：添加数量列选择逻辑（检测"数量"和"平方数"列共存）
- 变更 2：自动使用"平方数"列作为 Excel 的数量列（不再询问用户）
- 变更 3：自动更新单位列（节→平方米）
- 变更 4：支持按"平方"统计风管材料的业务需求

### 版本 1.2.0 (2025-01-22)
**基于用户反馈的优化**
- 变更 1：默认值自动填入（验收时间=当天，验收结果=合格，备注=空）
- 变更 2：生产厂家、工程部位使用用户指定值，无需二次确认
- 变更 3：简化确认流程，只询问是否开始插入

### 版本 1.1.0 (2025-01-22)
**基于用户反馈的优化**
- 变更 1：输出格式改为列表形式（文件表头、提取内容项数、未填入内容、插入问题）
- 变更 2：自动检测并说明未填入内容
- 变更 3：在插入前自动插入空行
- 变更 4：将原图嵌入到第一行数据的对应列

### 版本 1.0.0 (2025-01-22)
**初始版本**
- 功能：OCR 识别 + Excel 填入 + 图片粘贴
- 工作流程：6步强制流程
  1. 提取图片表格
  2. 读取 Excel 第四行
  3. 准备插入（用户确认）
  4. 执行插入
  5. 收集反馈
  6. 记录到 FEEDBACK.md

**核心设计**：
- 强制用户确认机制（步骤3）
- 强制反馈收集（步骤5）
- 自动进化触发（≥3次同类问题）

**已知限制**：
- OCR 准确率依赖图片质量
- 只支持水平表格
- Excel 文件必须关闭
