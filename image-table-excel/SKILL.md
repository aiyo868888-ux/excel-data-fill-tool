# 图片表格识别并填入Excel

## ⚠️ 重要文档

- **[USAGE.md](USAGE.md)** - 正确使用流程示例（必读！）
- **[ISSUES.md](ISSUES.md)** - 问题记录与修复方案
- **[FEEDBACK.md](FEEDBACK.md)** - 用户反馈记录

## 核心原则

1. **历史数据保护优先**：任何操作都不能覆盖或修改已有数据
2. **完整扫描工作表**：必须扫描到 `ws.max_row`，不能假设数据连续
3. **用户确认必需**：必须向用户展示最后数据行并等待确认
4. **使用专用工具**：必须使用 `find_last_row.py` 和 `map_and_insert.py`
5. **追加模式插入**：使用追加而非覆盖，保持历史数据完整

## 标准工作流程（严格执行）

**强制执行**：每次使用技能时，必须按以下顺序执行：

**⚠️ 关键安全检查**：
在插入数据前，**必须**使用 `find_last_row.py` 工具准确定位最后数据行，避免覆盖现有数据！

### 1. 提取图片表格内容

```python
# 使用 OCR 识别图片中的表格
from paddleocr import PaddleOCR
ocr = PaddleOCR(use_angle_cls=True, lang='ch')
result = ocr.ocr(image_path)

# 解析表格结构
table_data = parse_table(result)
```

**输出给用户**：
- 识别到的表格结构（列数、行数）
- 前三行示例数据
- 识别置信度

### 2. 读取 Excel 工作表第四行并查找最后数据行

**⚠️ 必须使用专用工具准确定位**：

```bash
# 使用 find_last_row.py 工具扫描整个工作表
python scripts/find_last_row.py <excel_path> 5
```

**工具会输出**：
- 所有有数据的行号和内容预览
- 最后数据行号
- 建议插入位置
- 最后一行的完整内容

```python
# 或者在代码中调用
from scripts.find_last_row import find_last_data_row_safe

result = find_last_data_row_safe(excel_path, start_row=5)
last_row = result['last_row']
insert_row = result['insert_row']
last_content = result['last_row_content']
```

**必须输出给用户确认**：
- 第四行内容（表头）
- 工作表名称
- **最后数据行号及其内容**（关键！）
- **新数据插入位置**（最后数据行 + 2）

**示例输出**：
```
工作表: Sheet1
表头（第4行）: 当前时间 | 材料名称 | 规格 | 型号/参数 | 单位 | 数量 | ...

最后数据行: 第49行
内容: 2026.1.4 | 卡条 | - | - | 个 | 500

新数据将插入到: 第51行（第50行为空行分隔）
历史内容（第49行及之前）完全不受影响

请确认最后数据行是否正确！
```

**⚠️ 重要警告**：
- 必须完整扫描工作表到 `ws.max_row`
- 不能假设数据是连续的，中间可能有空行
- **必须向用户展示最后数据行内容并等待确认**
- 如果用户指出最后行不对，必须重新扫描或手动指定

### 3. 准备插入内容（用户确认）

**⚠️ 关键步骤：必须向用户展示最后数据行的内容，让用户确认**

**最后数据行内容**（第 XX 行）：

**重要提示**：
```

请确认最后数据行是否正确！
如果不正确，请告知正确的最后数据行号。
```

**重要：数量列和单位列自动处理逻辑**

当图片表格中同时存在"数量"和"平方数"（或类似）列时：
- **自动使用"平方数"列**作为 Excel 的数量列
- **自动更新单位**：如果原单位是"节"，改为"平方米"
- 示例场景：风管材料按"平方"统计，而不是按"节"统计
- 特殊处理：对于非平方统计的材料（如方法兰、角码等），保留原数量和单位

**必须以列表形式显示**：

**文件表头**（Excel 第 4 行）：
- 列 1: 序号
- 列 2: 进场时间
- 列 3: 材料名称/规格型号
- 列 4: 供应厂商/品牌

- 列 7: 见证材料
- 列 8: 累计已进数量
- 列 9: 本次进场数量
- 列 10: 备注

**提取内容**（共 XX 项）：
- 项 1: 序号（图片列 1）
- 项 2: 型号（图片列 3）
- 项 3: 单位（图片列 4）
- 项 4: 数量（图片列 9）

**默认填充值**（自动填入）：

- 见证材料

**插入位置**：第 X 行开始

**插入问题**：

### 4. 执行插入

```python
# 用户确认后执行
- 在指定位置追加数据（不修改历史内容）
- **原有内容与新内容间保留 1 个空行**（强制）
- **将原图嵌入到第一行数据的对应列**（强制）
- 保存文件
```

**历史内容保护机制**（重要）：
- **采用追加模式**：新数据直接写入到最后数据行之后，不使用插入行功能
- **历史内容不受影响**：已有数据的行号、格式、内容完全保持不变
- **空行分隔规则**：在最后数据行和新数据之间自动保留 1 个空行作为分隔
- **示例**：如果最后数据在第 10 行，则第 11 行为空行，第 12 行开始写入新数据

**图片嵌入规则**：
- **标准Excel格式**：使用 openpyxl 的 Image 对象插入图片
- **WPS兼容性问题**：
  - ⚠️ **重要警告**：如果Excel文件由WPS创建并包含图片，使用openpyxl打开并保存后，**原有的WPS图片可能无法在标准Excel中显示**
  - ⚠️ WPS使用 `DISPIMG()` 函数嵌入图片，这是WPS专有格式
  - ⚠️ openpyxl 会保留 `DISPIMG()` 公式，但图片数据库引用可能失效
  - ⚠️ 原有图片在WPS中仍可显示，但在标准Excel中显示为公式文本
  - ✅ **解决方案1**：接受限制，用WPS查看原图，用Excel查看新图
  - ✅ **解决方案2**：在WPS中导出所有原图，用标准方式重新插入
  - ✅ **解决方案3**：使用 `data_only=False, keep_vba=True` 参数打开文件，尽量保留原有内容
- **插入位置**：第一行新数据的M列（第13列）
- **图片处理**：
  - 读取原图文件
  - **智能调整尺寸**：
    - 数据行数 ≥ 6行 → 图片高度 = 6行（约180像素）
    - 数据行数 < 6行 → 图片高度 = 3行（约90像素）
    - 宽度固定为M列宽度（约150像素）
    - 保持宽高比，使用高质量缩放算法
  - 设置行高以适应图片
  - 锚定到指定单元格（M列第一行新数据）

**图片插入限制**（重要）：
- ❌ ExcelTool 不支持图片插入
- ✅ 必须使用 openpyxl 库的 `add_image()` 方法
- ✅ 必须使用 `map_and_insert.py` 脚本（包含图片插入功能）
- ⚠️ 如果无法安装 openpyxl，图片需要手动插入
- ⚠️ **如果原文件包含WPS图片，建议手动插入新图片，避免影响原有图片**
