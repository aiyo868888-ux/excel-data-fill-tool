```
┌─────────────────────────────────────────────────────────┐
│  ⚠️  插入数据前必须完成以下所有步骤                      │
├─────────────────────────────────────────────────────────┤

│  2. ✓ 向用户展示最后数据行内容                          │
│  3. ✓ 等待用户确认插入位置                              │
│  4. ✓ 使用 map_and_insert.py（不是 ExcelTool）         │

└─────────────────────────────────────────────────────────┘
```

## 📋 标准命令

### 1. 查找最后数据行
```bash
python scripts/find_last_row.py "路径\到\excel.xlsx" 5
```

### 2. 执行插入
```bash
python scripts/map_and_insert.py \
  --excel "路径\到\excel.xlsx" \
  --data data.json \
  --image image.jpg \
  --custom '{"生产厂家":"约克","用于工程部位":"汪洋"}'
```

## 🔍 问题排查

### 问题：数据被覆盖
**原因**：
- ❌ 没有使用 `find_last_row.py`
- ❌ 直接使用了 ExcelTool
- ❌ 没有完整扫描工作表

**解决**：
- ✅ 使用 `find_last_row.py` 工具
- ✅ 使用 `map_and_insert.py` 脚本
- ✅ 扫描到 `ws.max_row`

### 问题：最后数据行不准确
**原因**：
- ❌ 只扫描了部分行
- ❌ 假设数据是连续的

**解决**：
- ✅ 扫描范围：`range(5, ws.max_row + 1)`
- ✅ 不因空行中断扫描

### 问题：插入位置错误
**原因**：
- ❌ 硬编码插入位置
- ❌ 没有用户确认

**解决**：
- ✅ 动态计算：`last_row + 2`
- ✅ 向用户展示并确认

## 🎯 核心原则

```
┌─────────────────────────────────────────────────────────┐
│  1. 历史数据保护优先 - 任何操作都不能覆盖已有数据        │
│  2. 完整扫描工作表 - 必须扫描到 ws.max_row               │
│  3. 用户确认必需 - 必须展示最后数据行并等待确认          │
│  4. 使用专用工具 - find_last_row.py + map_and_insert.py │
│  5. 追加模式插入 - 使用追加而非覆盖                      │
└─────────────────────────────────────────────────────────┘
```

## 🛠️ 工具说明

### find_last_row.py
**功能**：安全查找最后数据行
**输入**：Excel文件路径、起始行号
**输出**：
- 所有有数据的行号
- 最后数据行内容
- 建议插入位置

### map_and_insert.py
**功能**：映射并插入数据
**输入**：Excel文件、数据文件、图片、自定义内容
**输出**：填充后的Excel文件
**特点**：
- 自动调用 `find_last_data_row()`
- 使用追加模式
- 保护历史数据

## ⚡ 快速示例

### 完整流程（3步）
