## 🐛 Bug 修复验证

### Bug #1: None 排序错误

**问题描述**:
```
TypeError: '<' not supported between instances of 'str' and 'NoneType'
```

**问题位置**: `fill_all()` 方法

**根本原因**:
- `self.supplier_data.keys()` 中包含 `None` 键
- 当执行 `sorted(self.supplier_data.keys())` 时无法比较字符串和 None

**修复方案**:
```python
# Before
for date_str in sorted(self.supplier_data.keys()):

# After
valid_dates = [d for d in self.supplier_data.keys() if d is not None]
valid_dates_sorted = sorted(valid_dates, key=lambda x: (x is None, x))
for date_str in valid_dates_sorted:
```

**修复验证**: ✅ 通过
