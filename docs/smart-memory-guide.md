# Smart Memory - 智能自动记录系统

> **产品哲学**：自动识别有价值的内容，减少手动记录

---

| 特性 | Simple Memory | Smart Memory |
|------|--------------|--------------|
| **记录方式** | 手动说"记录一下" | 自动识别并提示 |
| **适用场景** | 完全控制 | 智能辅助 |
| **记录准确率** | 100% | 85-90% |
| **使用便利性** | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ |

## 📋 智能检测规则

### 自动记录的内容（置信度 ≥ 3）

#### 1. Bug 修复
```
✅ "修复了登录超时的 bug"
✅ "解决了数据库连接问题"
✅ "fix: token 验证错误"

关键词: 修复了、解决了、bug、错误、问题
置信度: ⭐⭐⭐⭐⭐ (10/5)
```

#### 2. 技术决策
```
✅ "决定使用 PostgreSQL"
✅ "选择 React 而不是 Vue"
✅ "采用 JWT 认证方案"

关键词: 决定、选择、采用、使用
置信度: ⭐⭐⭐⭐ (8/5)
```

#### 3. 新功能
```
✅ "实现了用户认证功能"
✅ "添加了数据导出功能"
✅ "完成了支付模块"

关键词: 实现、添加、新增、完成
置信度: ⭐⭐⭐ (6/5)
```

#### 4. 发现/学习
```
✅ "发现原来 timeout 设置太短了"
✅ "注意到这个函数有内存泄漏"
✅ "原来需要先初始化"

关键词: 发现、原来、注意到
置信度: ⭐⭐ (4/5)
```

### 自动忽略的内容

```
❌ "帮我写个函数"
❌ "怎么配置？"
❌ "好的"
❌ "谢谢"
❌ 任何问句（what、how、why...）

原因: 这些是临时对话，不值得记录
```

## 🎛️ 配置

编辑 `.memory-config.json`:

```json
{
  "autoDetect": {
    "enabled": true,           // 是否启用智能检测
    "confidenceThreshold": 3,  // 置信度阈值（1-5）
    "autoConfirm": false,      // 是否自动确认（true=无提示直接记录）
    "ignorePatterns": [        // 自定义忽略模式
      "^help",
      "^谢谢"
    ]
  }
}
```

### 置信度阈值说明

- **5+**: 高价值，强烈建议记录（Bug 修复、技术决策）
- **3-4**: 中等价值，可以记录（新功能、重构）
- **1-2**: 低价值，不记录（临时对话）

### 误报情况

```
误报（不该记录但记录了）:
- "这个决定很重要" → 误判为 decision
- "发现了一个好工具" → 误判为 discovery

漏报（该记录但没记录）:
- "改动了一点配置" → 置信度太低
- "调优了性能" → 关键词不匹配
```
