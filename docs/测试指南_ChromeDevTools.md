### 方法2：使用 Playwright MCP（Chrome DevTools）

如果您已配置 Chrome DevTools MCP，可以通过编程方式控制浏览器。

**示例代码**:
```javascript
// 在支持 MCP 的环境中使用
const { chromium } = require('playwright-browsers');

(async () => {
  const browser = await chromium.launch({ headless: false });
  const page = await browser.newPage();

  // 访问 Web 应用
  await page.goto('http://localhost:5000');

  // 上传报表
  await page.setInputFiles('#report-file', 'd:\\claude code -11\\自动化数据\\金融岛报表.xlsx');
  await page.fill('#password', '1');
  await page.click('button:has-text("上传报表")');

  // 等待并观察结果
  await page.waitForTimeout(5000);

  // ... 继续其他测试步骤

  await browser.close();
})();
```

## 🐛 常见问题

### Q1: Web 应用无法访问

**症状**: 无法打开 http://localhost:5000

**解决**:
```bash
# 检查进程
netstat -ano | findstr :5000

# 如果没有运行，启动
python web_app.py
```

### Q2: 文件上传失败

**症状**: 上传后没有反应

**检查**:
- 文件路径是否正确
- 文件格式是否支持（.xlsx, .xls）
- 文件大小是否合理

### Q3: 数据填充卡住

**症状**: 点击填充后一直显示"处理中"

**解决**:
- 打开浏览器开发者工具（F12）
- 查看 Console 和 Network 标签
- 查看错误信息
