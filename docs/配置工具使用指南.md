# 系统协调人配置工具使用指南

## 📋 概述

这是一个交互式配置管理工具，让您可以轻松自定义系统协调人的对话格式和行为。

**配置位置**：`.claude/user_config.json`
**配置工具**：`.claude/config_tool.py`

---

## 🚀 快速开始

### 步骤1：打开终端

在项目根目录打开终端/命令行

### 步骤2：运行配置工具

```bash
cd .claude
python config_tool.py
```

### 步骤3：使用交互菜单

根据提示选择配置选项

---

## 📖 功能说明

### 1️⃣ 查看当前配置

显示所有当前的配置项：

```
============================================================
📋 当前配置
============================================================

🎯 对话配置:
  第一行格式: 🤖 我是系统协调人，正在{task}，使用{tools}
  启用第一行: True
  显示工具: True
  最多显示工具数: 3
  工具分隔符: '、'

🎨 界面配置:
  标记符号: 🤖
  高亮样式: emoji
  可用样式: emoji, brackets, arrow, color

⚙️ 功能配置:
  自动跟踪进度: True
  显示执行时间: False
  详细工具使用: False
```

---

### 2️⃣ 修改第一行格式

自定义对话开头的显示格式。

**可用变量**：
- `{task}` - 当前正在执行的任务
- `{tools}` - 使用的工具列表
- `{agent}` - 调用的Agent名称

**预设模板**：
1. `🤖 我是系统协调人，正在{task}，使用{tools}` (默认)
2. `【系统协调人】正在{task}，使用{tools}`
3. `>>> 我是系统协调人 | {task} | {tools}`
4. 自定义格式

**示例效果**：
```
输入：1
结果：🤖 我是系统协调人，正在分析数据，使用 Read、Grep 工具
```

---

### 3️⃣ 修改高亮样式

选择第一行的视觉标记方式。

| 样式 | 标记 | 示例效果 |
|------|------|----------|
| **emoji** | 🤖 | `🤖 我是系统协调人，正在...` |
| **brackets** | 【】 | `【系统协调人】正在...` |
| **arrow** | >>> | `>>> 我是系统协调人 | 正在...` |
| **color** | 颜色 | (需要终端支持ANSI颜色) |

**推荐**：使用 **emoji** 样式，在所有终端中都能正常显示。

---

### 4️⃣ 切换功能开关

启用或禁用特定功能。

**可用开关**：

1. **自动跟踪进度** (`auto_track_progress`)
   - 启用：自动创建和管理待办事项
   - 禁用：手动管理进度

2. **显示执行时间** (`show_execution_time`)
   - 启用：在回复中显示任务耗时
   - 禁用：不显示时间信息

3. **详细工具使用** (`verbose_tool_usage`)
   - 启用：显示详细的工具调用信息
   - 禁用：仅显示工具名称

4. **启用第一行** (`header_enabled`)
   - 启用：在每次回复开头显示声明
   - 禁用：不显示声明

5. **显示工具列表** (`show_tools`)
   - 启用：显示使用的工具
   - 禁用：不显示工具列表

## 💾 保存配置

### 自动保存
- 修改后选择 "5. 💾 保存并退出"
- 配置立即写入 `.claude/user_config.json`

### 手动编辑
您也可以直接编辑 JSON 文件：

```json
{
  "conversation": {
    "header_format": "🤖 我是系统协调人，正在{task}，使用{tools}",
    "header_enabled": true,
    "show_tools": true,
    "max_tools_display": 3,
    "tools_separator": "、"
  },
  "ui": {
    "header_marker": "🤖",
    "highlight_style": "emoji"
  }
}
```

## 🎯 配置示例

## 🔧 故障排除

### 问题1：配置没有生效

**原因**：配置文件格式错误

**解决**：
1. 检查 JSON 格式是否正确
2. 使用配置工具重新保存
3. 查看错误日志

---

### 问题2：emoji 显示为乱码

**原因**：终端不支持 emoji 字符

**解决**：
1. 切换到 `brackets` 或 `arrow` 样式
2. 更新终端版本
3. 使用 Windows Terminal 或 VSCode 集成终端

---

### 问题3：修改后丢失配置

**原因**：选择了 "6. 🚪 退出不保存"

**解决**：
1. 下次记得选择 "5. 💾 保存并退出"
2. 或者直接编辑 `.claude/user_config.json`

---

## 📚 高级用法

### 批量修改配置

创建多个配置文件，按需切换：

```bash
# 备份当前配置
cp .claude/user_config.json .claude/user_config.json.backup

# 应用新配置
cp .claude/configs/minimal.json .claude/user_config.json

# 恢复配置
cp .claude/user_config.json.backup .claude/user_config.json
```

---

### 配置模板

创建配置模板目录：

```
.claude/
├── configs/
│   ├── minimal.json      # 简洁模式
│   ├── detailed.json     # 详细模式
│   ├── professional.json # 专业模式
│   └── debug.json        # 调试模式
└── user_config.json      # 当前配置
```
