# 价值观分析系统使用指南

## 🎯 系统功能

通过对话内容，自动分析一个人的价值观特征。

---

## 📋 支持的价值观维度

### 1️⃣ 产品哲学

**极简主义**
- 关键词：极简、简单、专注单点、做减法、少即是多
- 特征：追求简单，专注核心功能

**功能主义**
- 关键词：功能全面、做加法、丰富功能
- 特征：追求功能完善，满足所有需求

**用户体验**
- 关键词：用户体验、用户至上、体验优先
- 特征：用户体验第一

**商业价值**
- 关键词：商业化、盈利、商业价值、付费
- 特征：重视商业回报

### 2️⃣ 决策风格

**数据驱动**
- 关键词：数据驱动、数据分析、a/b测试
- 特征：相信数据，用数据说话

**直觉决策**
- 关键词：直觉、经验判断、感觉
- 特征：相信经验和直觉

**用户反馈**
- 关键词：用户反馈、用户声音、用户调研
- 特征：重视用户意见

**快速试错**
- 关键词：快速试错、迭代、小步快跑
- 特征：快速尝试，不断调整

**谨慎决策**
- 关键词：谨慎、充分调研、风险评估
- 特征：三思而后行

### 3️⃣ 工作态度

**完美主义**
- 关键词：完美、精益求精、追求极致
- 特征：质量第一

**快速交付**
- 关键词：快速、效率优先、先上线再优化
- 特征：速度优先

**稳定优先**
- 关键词：稳定、可靠、不出错
- 特征：稳定性第一

**创新优先**
- 关键词：创新、突破、不墨守成规
- 特征：追求创新

### 4️⃣ 技术观点

**技术驱动**
- 关键词：技术驱动、技术优先、技术壁垒
- 特征：技术是核心竞争力

**业务优先**
- 关键词：业务优先、技术服务业务、解决问题
- 特征：技术为业务服务

**技术保守**
- 关键词：成熟技术、稳定优先、不追新
- 特征：使用成熟技术

**技术激进**
- 关键词：新技术、前沿技术、尝鲜
- 特征：追求新技术

### 5️⃣ 团队观念

**个人英雄**
- 关键词：个人英雄、独狼、独立完成
- 特征：依赖个人能力

**团队协作**
- 关键词：团队协作、团队合作、沟通
- 特征：重视团队合作

**透明开放**
- 关键词：透明、开放、信息共享
- 特征：开放透明

**层级管理**
- 关键词：层级、流程、规范、审批
- 特征：层级化管理

### 6️⃣ 风险态度

**风险偏好**
- 关键词：大胆、敢于尝试、不怕失败
- 特征：拥抱风险

**风险厌恶**
- 关键词：稳健、保守、风险控制
- 特征：避免风险

**风险平衡**
- 关键词：平衡、适度、可控风险
- 特征：平衡风险

## 🚀 使用方法

### 方法 1：命令行测试

```bash
# 测试单句话
cd skills/simple-values
node -e "
const ValuesDetector = require('./values-detector.js');
const detector = new ValuesDetector();
const results = detector.detect('我认为产品应该专注单点，做减法');
console.log(JSON.stringify(results, null, 2));
"
```

### 方法 2：批量分析对话

```javascript
const ValuesDetector = require('./values-detector.js');
const detector = new ValuesDetector();

// 对话记录
const conversations = [
  '我们要专注单点，做到极致',
  '数据驱动决策',
  '快速迭代'
];

// 分析所有对话
const allRecords = [];
conversations.forEach(conv => {
  const results = detector.detect(conv);
  allRecords.push(...results);
});

// 生成画像
const profile = detector.generateProfile(allRecords);
const analysis = detector.analyze(profile);

console.log('价值观画像:', profile);
console.log('分析:', analysis.summary);
```

### 方法 3：集成到记忆系统

在记录对话时，同时分析价值观：

```javascript
const SmartMemory = require('./simple-memory/smart-memory.js');
const ValuesDetector = require('./simple-values/values-detector.js');

const memory = new SmartMemory();
const detector = new ValuesDetector();

// 对话内容
const content = '我认为产品应该专注单点';

// 1. 记录到记忆
memory.add(content, 'conversation');

// 2. 分析价值观
const values = detector.detect(content);
console.log('价值观:', values);
```

## 💡 使用场景

### 场景 1：了解产品经理

```
对话内容：
"我认为产品应该专注单点，做到极致"
"用户体验是第一位的"

分析结果：
- 产品哲学：极简主义、用户体验
- 决策风格：数据驱动
- 总结：典型的用户导向产品经理
```

```
对话内容：
"我喜欢快速迭代，先上线再优化"
"要敢于尝试新东西"
"技术要服务于业务"

分析结果：
- 工作态度：快速交付
- 风险态度：风险偏好
- 技术观点：业务优先
- 总结：适合创业公司的快速开发型人才
```

### 场景 3：团队协作分析

```
对话内容：
"团队协作很重要，要多沟通"
"信息要透明共享"
"不要个人英雄主义"

分析结果：
- 团队观念：团队协作、透明开放
- 总结：重视团队合作的管理者
```

## ⚠️ 注意事项

### 准确率限制

- ✅ 关键词明确：准确率高（90%+）
- ⚠️ 间接表达：可能漏掉（70%）
- ❌ 反话讽刺：无法识别（0%）

### 建议

1. **多次对话**：至少 10+ 句有意义的话
2. **不同场景**：工作、讨论、决策等
3. **结合上下文**：不要单句判断
4. **人工验证**：结果仅供参考

## 🎯 最佳实践

### 分析产品经理价值观

```
关注维度：
1. 产品哲学（极简 vs 功能全面）
2. 决策风格（数据驱动 vs 直觉）
3. 用户观点（用户体验 vs 商业价值）

典型画像：
- 用户导向：极简主义 + 用户体验 + 用户反馈
- 商业导向：功能主义 + 商业价值 + 数据驱动
- 平衡型：介于两者之间
```

### 分析技术负责人价值观

```
关注维度：
1. 技术观点（技术驱动 vs 业务优先）
2. 工作态度（完美主义 vs 快速交付）
3. 风险态度（激进 vs 保守）

典型画像：
- 技术专家：技术驱动 + 完美主义 + 风险厌恶
- 创业型：业务优先 + 快速交付 + 风险偏好
- 稳健型：业务优先 + 稳定优先 + 风险平衡
```
