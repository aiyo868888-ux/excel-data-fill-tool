## 方式1：源码分发

### 适用场景
- ✅ 用户有 Python 环境
- ✅ 需要频繁修改代码
- ✅ 技术团队使用

### 分发步骤

#### 1. 准备文件清单

```

├── 使用指南.md               # 详细文档

    └── 送货商文件/

#### 2. 创建依赖清单

**文件**: `requirements.txt`

```txt
pandas>=1.3.0
openpyxl>=3.0.0
msoffcrypto>=5.0.0
Flask>=2.0.0
Werkzeug>=2.0.0
```

#### 3. 创建使用说明

**文件**: `README.md`

```markdown
# 数据填充工具使用指南

## 快速开始

### 1. 安装 Python

下载并安装 Python 3.8 或更高版本：
https://www.python.org/downloads/

**重要**: 安装时勾选 "Add Python to PATH"

### 2. 安装依赖

打开命令行（CMD/PowerShell），进入工具目录：

```bash
cd 数据填充工具
pip install -r requirements.txt
```

### 3. 运行程序

**方式A：命令行模式**

```bash
# 基本使用
python 数据填充工具.py --report 报表.xlsx --supplier-folder ./数据

# 带密码的报表
python 数据填充工具.py --report 报表.xlsx --supplier-folder ./数据 --password 密码

# 查看帮助
python 数据填充工具.py --help
```

**方式B：Web 界面模式**

```bash
python web_app.py
```

然后在浏览器打开：http://localhost:5000

## 功能说明

- 自动读取送货商 Excel 文件
- 智能填充到汇总报表
- 支持密码保护的报表
- 保留所有格式（边框、字体、对齐）

## 文件格式

- 报表文件：.xlsx 格式
- 送货商文件：.xlsx 或 .xls 格式
- 输出文件：自动生成，格式为 "报表名_已填充_时间戳.xlsx"

## 问题排查

### 常见错误

**错误1：'python' 不是内部或外部命令**

原因：Python 未安装或未添加到 PATH

解决：
1. 重新安装 Python
2. 安装时勾选 "Add Python to PATH"

**错误2：No module named 'pandas'**

原因：依赖未安装

解决：运行 `pip install -r requirements.txt`

**错误3：文件不存在**

原因：文件路径错误

解决：使用绝对路径或确保文件在当前目录

## 技术支持

如有问题，请联系：
- 邮箱：your-email@example.com
- 文档：查看 `使用指南.md`

## 方式2：打包为可执行文件

### 适用场景
- ✅ 普通用户使用
- ✅ 无需 Python 环境
- ✅ 独立运行

### 使用 PyInstaller 打包

#### 1. 安装 PyInstaller

```bash
pip install pyinstaller
```

#### 2. 创建打包脚本

**文件**: `build_exe.py`

```python
import PyInstaller.__main__
import os

# 打包配置
app_name = "数据填充工具"
script = "数据填充工具.py"
icon = None  # 如果有图标文件，指定路径

# PyInstaller 参数
PyInstaller.__main__.run([
    script,
    '--name=' + app_name,
    '--onefile',           # 打包为单个文件
    '--console',           # 显示控制台窗口
    '--clean',             # 清理临时文件
    '--noconfirm',         # 覆盖输出
    # '--icon=' + icon,    # 图标（可选）
    '--add-data=README.md:.',  # 添加说明文件
])
```

#### 3. 执行打包

```bash
# 方式1：使用脚本
python build_exe.py

# 方式2：直接使用命令
pyinstaller --onefile --console 数据填充工具.py
```

#### 4. 打包结果

```
数据填充工具/
├── build/                  # 构建临时文件（可删除）
├── dist/                   # 输出目录
│   └── 数据填充工具.exe    # ✅ 可执行文件
└── 数据填充工具.spec       # 打包配置
```

#### 5. 分发文件

**分发给用户的内容**：

```
数据填充工具 v0.4/
├── 数据填充工具.exe        # 主程序
├── README.md               # 使用说明
├── 使用指南.md              # 详细文档
└── 示例数据/
    ├── 报表.xlsx
    └── 送货商文件/
```

### 高级打包选项

#### 添加图标

```bash
# 准备 .ico 图标文件
pyinstaller --onefile --console --icon=app.ico 数据填充工具.py
```

#### 隐藏控制台（GUI 模式）

```bash
# 不显示控制台窗口
pyinstaller --onefile --windowed 数据填充工具.py
```

#### 添加数据文件

```bash
# 包含额外文件
pyinstaller --onefile --add-data "README.md:." 数据填充工具.py
```

### 优点
- ✅ 用户无需安装 Python
- ✅ 双击即可运行
- ✅ 用户体验好

### 缺点
- ❌ 文件较大（~50-100MB）
- ❌ 杀毒软件可能误报
- ❌ 更新需要重新打包

## 方式3：Web 应用部署

### 适用场景
- ✅ 多用户同时使用
- ✅ 远程访问
- ✅ 集中管理

### 部署方式

#### 方式A：本地网络部署

##### 1. 修改 Web 应用配置

**文件**: `web_app.py`

```python
# 修改允许的主机
if __name__ == '__main__':
    app.run(
        host='0.0.0.0',  # 允许外部访问
        port=5000,
        debug=True
    )
```

##### 2. 启动服务

```bash
python web_app.py
```

##### 3. 用户访问

```
http://localhost:5000           # 本机
http://192.168.1.100:5000       # 局域网（替换为实际IP）
```

#### 方式B：云服务器部署

##### 1. 使用 Gunicorn（生产环境）

```bash
# 安装 Gunicorn
pip install gunicorn

# 启动服务
gunicorn -w 4 -b 0.0.0.0:5000 web_app:app
```

##### 2. 使用 Nginx 反向代理

**配置文件**: `/etc/nginx/sites-available/data-filler`

```nginx
server {
    listen 80;
    server_name your-domain.com;

    location / {
        proxy_pass http://127.0.0.1:5000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

##### 3. 使用 Docker（推荐）

**文件**: `Dockerfile`

```dockerfile
FROM python:3.9-slim

WORKDIR /app

COPY requirements.txt .
RUN pip install -r requirements.txt

COPY . .

EXPOSE 5000

CMD ["gunicorn", "-w", "4", "-b", "0.0.0.0:5000", "web_app:app"]
```

**文件**: `docker-compose.yml`

```yaml
version: '3.8'

services:
  web:
    build: .
    ports:
      - "5000:5000"
    volumes:
      - ./data:/app/data
    restart: always
```

**启动**：

```bash
docker-compose up -d
```

### 优点
- ✅ 多用户同时使用
- ✅ 集中管理
- ✅ 远程访问
- ✅ 易于更新

### 缺点
- ❌ 需要服务器
- ❌ 需要网络连接
- ❌ 配置较复杂

## 常见问题

### 安装问题

#### Q1: Python 安装后无法使用

**症状**：运行 `python` 命令提示"不是内部或外部命令"

**原因**：Python 未添加到系统 PATH

**解决**：
1. 重新安装 Python
2. 安装时勾选 "Add Python to PATH"
3. 或手动添加到环境变量

#### Q2: pip 安装依赖失败

**症状**：运行 `pip install` 报错

**原因**：网络问题或权限问题

**解决**：
```bash
# 使用国内镜像
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 使用管理员权限（Windows）
以管理员身份运行 CMD
pip install -r requirements.txt
```

### 使用问题

#### Q3: 提示文件不存在

**症状**：`❌ 报表文件不存在`

**原因**：路径错误或文件确实不存在

**解决**：
```bash
# 使用绝对路径
python 数据填充工具.py --report "C:\Users\用户名\Documents\报表.xlsx" --supplier-folder "C:\Users\用户名\Documents\数据"

# 或确认文件在当前目录
dir  # 查看当前目录文件
```

#### Q4: 密码错误

**症状**：`❌ 解密失败（密码错误）`

**原因**：密码不正确

**解决**：
1. 确认密码正确
2. 检查是否有多余空格
3. 尝试不使用密码参数（如果文件未加密）

#### Q5: 内存不足

**症状**：处理大文件时程序崩溃

**原因**：文件太大，超出内存限制

**解决**：
1. 分批处理文件
2. 关闭其他程序释放内存
3. 使用 64 位 Python

### 分发问题

#### Q6: 可执行文件被杀毒软件拦截

**症状**：运行 .exe 文件被杀毒软件删除

**原因**：PyInstaller 打包的文件可能被误报

**解决**：
1. 添加到杀毒软件白名单
2. 使用代码签名（购买证书）
3. 提供源码供用户自行打包

#### Q7: Web 应用无法访问

**症状**：局域网其他电脑无法访问

**原因**：防火墙阻止或绑定地址错误

**解决**：
```python
# 修改 web_app.py
app.run(host='0.0.0.0', port=5000)  # 允许外部访问

# Windows 防火墙
允许 Python 通过防火墙

# 查看本机 IP
ipconfig  # Windows
ifconfig  # Linux/Mac
```
