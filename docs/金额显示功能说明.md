# 金额显示功能说明

## 📊 功能概述

数据填充工具现在支持在前端进度追踪表格中显示每个送货商每天的**合计金额**。

## ✅ 实现的功能

### 1. 智能粘贴逻辑

**位置**: `tests/数据填充工具.py:1125-1325`

**功能**:
- 第1行：保持原样，复制所有6列
- 第2行（表头）：A-D列复制，E列填"金额"，F列填"备注"
- 中间数据行：A-D列复制数据（名称、单位、数量、单价），E列填充乘法公式 `=数量×单价`，F列复制备注
- 倒数第三行（合计）：A-D列复制，E列填充求和公式 `=SUM(所有金额)`，F列复制
- 倒数第二行：空行（跳过）
- 最后一行：复制所有6列（送货人、时间）

**示例公式**:
```excel
// 数据行
=E3*F3  // =数量×单价

// 合计行
=SUM(E3:E7)  // =SUM(所有金额)
```

### 2. 金额提取功能

**位置**: `tests/数据填充工具.py:233-434`

**方法**: `count_supplier_data_in_columns(suppliers_list, dates=None)`

**功能**:
- 自动提取每个送货商每天的合计金额（倒数第三行的金额列）
- 支持Excel公式的解析和计算
- 支持字符串和数字类型的自动转换
- 返回嵌套字典结构

**返回格式**:
```python
{
    "AC-AH": {
        "9": 4100.0,
        "10": 3200.0,
        "11": 5500.0
    },
    "AI-AN": {
        "9": 1500.0
    }
}
```

**提取逻辑**:
1. 检查倒数第三行（合计行）
2. 读取金额列（第5列，即`col_start_idx + 4`）
3. 如果是公式 `=SUM(...)`，解析并手动计算
4. 从数量列（第3列）和单价列（第4列）读取值
5. 计算每行的金额：`数量 × 单价`
6. 返回总金额

### 3. 前端显示

**位置**: `templates/index.html:383-427`

**显示格式**:
```
¥4,100.00  // 带千位分隔符和2位小数
```

**显示规则**:
- 有金额：显示格式化的金额（如 `¥4,100.00`）
- 无金额：显示空白单元格
- 金额为0：不显示

## 📋 使用示例

### Python API

```python
from tests.数据填充工具 import DataFiller

# 1. 加载报表（自动处理密码）
filler = DataFiller('report.xlsx', password='123456')
filler.load_report()

# 2. 提取所有供应商的金额
suppliers_list = [
    {"name": "万邦蔬菜", "start_column": "AC", "end_column": "AH"},
    {"name": "海鲜水产", "start_column": "AI", "end_column": "AN"}
]
amounts = filler.count_supplier_data_in_columns(suppliers_list)

# 3. 查看结果
for column_range, data in amounts.items():
    print(f"{column_range}:")
    for date, amount in data.items():
        print(f"  {date}日: ¥{amount:.2f}")
```

3. 查看进度表格中的金额
4. 上传送货商文件

## 🎯 技术细节

### 公式解析

**乘法公式**（如 `=AE3*AF3`）:
1. 解析单元格引用（AE3, AF3）
2. 读取数量列和单价列的值
3. 相乘得到金额

**求和公式**（如 `=SUM(E3:E7)`）:
1. 解析范围（E3:E7）
2. 遍历范围内的每一行
3. 如果是乘法公式，递归计算
4. 如果是数字，直接相加
5. 返回总计

### 数据类型转换

```python
# 自动处理字符串和数字
if isinstance(cell.value, (int, float)):
    value = cell.value
else:
    try:
        value = float(str(cell.value).strip())
    except:
        value = None
```

## 📝 注意事项

1. **公式计算**: openpyxl不会自动计算公式，需要手动解析
2. **性能优化**: 大量数据时建议分批处理
3. **错误处理**: 解密失败会自动降级为直接加载
4. **兼容性**: 支持.xls和.xlsx格式
