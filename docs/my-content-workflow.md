# 个人内容生产工作流系统

> 基于 Dan Koe 方法论，适配混合型内容创作的模块化工作流

---

## 系统架构

```
想法收集 ──► 想法验证 ──► 素材整理 ──► 框架拆解 ──► 两阶段生成 ──► 多平台分发
   │            │           │           │              │              │
   └─────── 想法库 ─────┘           │           │              │              │
                                 └─── 素材库 ──┘              │              │
                                                            └── 框架库 ─────┘
```

---

## 核心模块

### 模块 1: 想法捕获与验证系统

**工具**: `Thought-Capturer.md`

**流程**:
1. 每日想法快速记录到 Twitter/备忘录（280字限制）
2. 每周回顾：选出表现最好的想法
3. 标记可扩展的内容类型：推文/长文/视频

**输出**:
- 经过验证的想法清单
- 每个想法标注：[推文] [长文] [视频] [混合]

---

### 模块 2: AI 素材整理器

**Prompt**: `Material-Organizer.md`

**输入**:
- 视频 URL / 文章 / 书籍笔记 / 之前的内容

**AI 任务**:
1. 提取核心观点（3-6小时视频 → 1000字要点）
2. 找出与当前主题相关的素材
3. 标注可引用的金句和数据

**输出**:
- 结构化素材卡片
- 按主题分类的引用库

---

### 模块 3: 爆款框架逆向工程

**Prompt**: `Framework-Extractor.md`

**流程**:
1. 找 3 条你喜欢的高表现内容
2. 让 AI 拆解：
   - 叙事结构（钩子→冲突→转折→解决）
   - 心理触发器（好奇心缺口/社会认同/损失厌恶）
   - 语言模式（短句/排比/绝对语）
3. 提取可复用框架模板

**输出**:
- 框架模板库（用 `[占位符]` 表示可填充部分）

---

### 模块 4: 两阶段生成系统

#### 阶段一：上下文采集 (Context Interview)

**Prompt**: `Context-Collector.md`

AI 像记者一样提问：
1. 这次创作的核心主题是什么？
2. 目标受众的痛点是什么？
3. 你的独特观点/反直觉观察是什么？
4. 有哪些素材可以支持？（笔记/引用/数据）
5. 使用哪个框架模板？

#### 阶段二：内容生成 (Content Generator)

**Prompt**: `Content-Generator.md`

基于采集的信息：
1. 将素材填充进框架模板
2. 生成 3 个不同风格的版本
3. 标注每个版本的心理触发点

**输出**:
- 版本 A: 直接有力型（短句、绝对语）
- 版本 B: 循循善诱型（故事、类比）
- 版本 C: 挑战型（反常识、悖论）

---

### 模块 5: 多平台转化规则

| 源内容 | 目标平台 | 转化规则 |
|--------|----------|----------|
| Newsletter 章节 | Twitter | 拆成 3-5 条推文，每条一个观点 |
| YouTube 脚本 | Twitter | 提取金句 + 数据，做成推文 |
| Twitter 爆款 | Newsletter | 扩展成完整论证 |
| Twitter 系列 | YouTube | 脚本大纲，补充案例 |

## 每日执行节奏

### 每日 2 小时创作块

```
09:00 - 09:10  回顾昨日数据，选出最佳想法
09:10 - 09:50  完成今日主内容（Newsletter 一章 / 视频脚本一段）
09:50 - 10:00  生成并分发 3 条社交媒体内容
10:00 - 10:30  素材整理（看视频/读书，用 AI 提取要点）
10:30 - 11:00  框架库维护（拆解 1 条爆款内容）
```

### 每周安排

- **周一**: 制定本周主题清单
- **周二-周四**: 日常创作节奏
- **周五**: 录制/制作本周视频内容
- **周六**: 复盘本周数据，更新框架库
- **周日**: 休息 + 灵感收集

## 元提示词：生成你的定制 Prompt

如果你需要为特定内容类型生成专属 Prompt，使用以下流程：

1. 找到 3 个该类型的优秀范例
2. 用 `03-framework-extractor.md` 拆解它们
3. 将拆解结果输入 `05-content-generator.md`
4. 得到定制化的两阶段生成 Prompt

---

## 核心原则

1. **验证优先创作** - 只扩展已经过验证的想法
2. **框架优于灵感** - 用验证过的结构填充新想法
3. **AI 是放大器** - 它扩展你的思考边界，而非替代思考
4. **系统化迭代** - 每周复盘，不断优化框架库
