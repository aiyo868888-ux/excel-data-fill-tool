## 📝 使用示例

### 示例1：基本使用

```bash
# 准备文件
你的文件夹/
├── 报表.xlsx           # 汇总报表
└── 送货商/             # 送货商文件夹
    ├── 万邦全品.xlsx
    └── 其他供应商.xlsx

# 运行（一行命令）
python 数据填充工具.py --report 报表.xlsx --supplier-folder ./送货商

# 结果
✅ 生成：报表_已填充_20260104_143020.xlsx
```

### 示例2：带密码的报表

```bash
python 数据填充工具.py \
  --report 报表.xlsx \
  --supplier-folder ./送货商 \
  --password 你的密码
```

### 示例3：指定输出文件名

```bash
python 数据填充工具.py \
  --report 报表.xlsx \
  --supplier-folder ./送货商 \
  --output 我的处理结果.xlsx
```

## ❓ 常见问题（3秒解决）

### Q1: 如何查看帮助？

```bash
python 数据填充工具.py --help
```

### Q2: 文件路径有空格怎么办？

使用引号：

```bash
python 数据填充工具.py --report "我的 报表.xlsx" --supplier-folder "我的 数据"
```

### Q3: 如何批量处理？

将所有送货商文件放在一个文件夹：

```bash
python 数据填充工具.py --report 报表.xlsx --supplier-folder ./送货商文件夹
```

### Q4: 处理失败怎么办？

1. 检查文件是否损坏
2. 确认密码是否正确
3. 查看错误信息
4. 联系技术支持
