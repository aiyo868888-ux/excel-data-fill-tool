# 送货商数据粘贴逻辑测试指南

## 测试目标

验证重构后的统一逻辑：
1. 清空目标列在所有1-31日工作表的数据
2. 只在送货商文件包含的日期填充数据
3. 其他日期保持空白

## 测试环境

- **服务器地址**: http://localhost:5000
- **测试文件**: 需要准备测试用的送货商Excel文件

## 测试用例

### 用例1：部分日期填充（如9、10、11日）

**准备步骤**：
1. 打开浏览器访问 http://localhost:5000
2. 上传报表文件（包含1-31日所有工作表）
3. 选择一个列范围按钮（如 AC-AH）
4. 上传只包含9、10、11日数据的送货商文件

**预期行为**：
- [ ] 弹出确认对话框：
  ```
  检测到 3 个日期的数据：9日、10日、11日

  即将执行以下操作：
  1. 已清空原有数据，将添加上传文件数据。
  2. 只填充检测到的 3 个日期。

  是否继续？
  ```
- [ ] 用户点击"确定"后开始填充
- [ ] 填充完成后显示：
  ```
  ✅ 填充完成！
  已清空原有数据，将添加上传文件数据。
  点击"下载报表"按钮下载文件
  ```

**验证结果**：
1. 下载报表文件
2. 打开Excel检查：
   - [ ] 工作表9日：AC-AH列有新数据
   - [ ] 工作表10日：AC-AH列有新数据
   - [ ] 工作表11日：AC-AH列有新数据
   - [ ] 其他工作表（1-8日、12-31日）：AC-AH列为空白
   - [ ] 数据格式正确（表头、数据行）

### 用例2：单个日期填充（如只有9日）

**准备步骤**：
1. 刷新页面，重新上传报表
2. 选择列范围按钮
3. 上传只包含9日数据的送货商文件

**预期行为**：
- [ ] 确认对话框显示"检测到 1 个日期的数据：9日"
- [ ] 填充完成后显示成功消息

**验证结果**：
- [ ] 工作表9日：有数据
- [ ] 其他工作表（1-8日、10-31日）：目标列为空白

### 用例3：全日期填充（1-31日都有）

**准备步骤**：
1. 上传包含1-31日所有日期的送货商文件

**预期行为**：
- [ ] 确认对话框显示"检测到 31 个日期的数据"
- [ ] 填充完成

**验证结果**：
- [ ] 所有1-31日工作表都有数据
- [ ] 数据内容与送货商文件一致

### 用例4：用户取消操作

**准备步骤**：
1. 上传送货商文件
2. 弹出确认对话框时点击"取消"

**预期行为**：
- [ ] 不执行填充操作
- [ ] 表格状态显示为"已取消"
- [ ] 不显示下载按钮

**验证结果**：
- [ ] 报表数据未被修改

### 用例5：重复上传同一列范围

**准备步骤**：
1. 第一次上传包含9、10、11日的文件
2. 下载并保存报表
3. 刷新页面，重新上传刚才下载的报表
4. 再次选择同一列范围
5. 上传包含12、13日的文件

**预期行为**：
- [ ] 确认对话框显示"检测到 2 个日期的数据：12日、13日"
- [ ] 填充完成后显示成功消息

**验证结果**：
- [ ] 工作表12日：有数据
- [ ] 工作表13日：有数据
- [ ] 工作表9、10、11日：目标列为空白（被清空）
- [ ] 其他工作表：目标列为空白
