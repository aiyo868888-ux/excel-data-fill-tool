# Simple Memory - 5 分钟上手指南

## 🎯 这个系统是做什么的？

Simple Memory 是一个**极简的记忆系统**，帮你记录项目中的关键决策和经验。

**核心场景：**
- ✅ 记录技术决策（为什么选择 A 而不是 B）
- ✅ 记录 bug 解决方案（这个bug以前是怎么修的？）
- ✅ 快速查找历史经验（避免重复踩坑）

---

## 🚀 立即开始（3 步）

### 1️⃣ 重启 VS Code

重启后，Simple Memory 会自动加载（已配置在 `.mcp.json`）

### 2️⃣ 在对话中直接使用

**记录内容：**
```
记录一下：我们决定用 PostgreSQL 而不是 MySQL，因为需要更好的 JSON 支持
```

**搜索历史：**
```
搜索一下关于数据库的历史记录
```

**查看最近记录：**
```
查看最近的记忆
```

### 3️⃣ 完成！

就这么简单。所有记录保存在 `.memory/memory.json`

## 📂 数据在哪？

```
项目根目录/
├── .memory/
│   └── memory.json          # 所有记忆数据
└── .memory-config.json      # 配置文件
```

随时可以查看、编辑、备份这个 JSON 文件。

---

## 🔧 高级配置（可选）

大多数时候不需要配置，但如果想自定义：

编辑 `.memory-config.json`：

```json
{
  "maxRecords": 1000,              // 最大保存多少条记录
  "categories": [                  // 自定义分类
    "decision",
    "bugfix",
    "feature",
    "refactor",
    "discovery"
  ]
}
```

## ❓ 常见问题

### Q: 会记录什么内容？
A: **只有你明确要求记录的内容**。不会自动记录隐私或敏感信息。

### Q: 数据会丢失吗？
A: 不会。数据保存在项目的 `.memory/memory.json`，属于 Git 仓库的一部分，可以提交备份。

### Q: 可以删除记录吗？
A: 可以直接编辑 `.memory/memory.json` 删除不需要的记录。

### Q: 支持其他编辑器吗？
A: 支持任何支持 MCP 的工具，包括 CLI、VS Code 等。
