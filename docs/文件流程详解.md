# 📊 Web应用文件流程详解

## 🎯 完整的数据流程图

### 流程概览

```
用户浏览器 (index.html)
        ↓
    [1] 上传报表文件
        ↓
    前端验证格式
        ↓
    fetch('/api/upload-report')
        ↓
后端 Flask (web_app.py)
        ↓
    保存到 uploads/report_xxx.xlsx
        ↓
    创建 DataFiller 对象
        ↓
    filler.load_report()
        ↓
    openpyxl 读取 Excel
        ↓
    提取: 日期列表 + 工作表列表 + 供应商配置
        ↓
    返回 JSON {dates, sheets, suppliersConfig, supplierData}
        ↓
前端接收数据
        ↓
    渲染界面:
      - 显示上传按钮（每个供应商一个）
      - 显示进度表格（日期 x 供应商）
      - 显示额外功能按钮
        ↓
    [2] 用户点击供应商上传按钮
        ↓
    触发 uploadSupplierFile(columnRange)
        ↓
    弹出文件选择对话框
        ↓
    用户选择送货商文件
        ↓
    前端监听 change 事件
        ↓
    fetch('/api/upload-suppliers')
        ↓
后端处理:
      - 保存文件
      - 读取送货商数据
      - 提取日期
        ↓
    返回 JSON {dates, file_info}
        ↓
    前端显示确认对话框
        ↓
    用户确认
        ↓
    fetch('/api/fill-supplier-data')
        ↓
后端执行填充:
      - filler.fill_data_smart()
      - 清空目标列
      - 填充新数据
      - 保存文件
        ↓
    返回 JSON {success, fillHistory, output_file}
        ↓
前端更新:
      - 更新 fillHistory
      - 重新渲染表格
      - 显示下载按钮
        ↓
    [3] 用户点击"下载报表"
        ↓
    window.location.href = '/api/download/xxx.xlsx'
        ↓
后端 send_file()
        ↓
浏览器下载文件
```

## 📋 详细步骤说明

### 步骤1: 初始化会话

```javascript
// 页面加载时自动执行
window.addEventListener('DOMContentLoaded', initSession)

↓

fetch('/api/session/create', {method: 'POST'})

↓

返回: {success: true, session_id: "xxx"}

↓

保存 sessionId = "xxx"

↓

所有后续请求都会在 headers 中添加:
X-Session-ID: "xxx"
```

**作用**: 会话管理，让服务器知道哪些请求属于同一个用户

### 步骤2: 上传报表文件

```javascript
// 用户选择文件

↓

formData.append('password', password)

↓

// 发送请求
fetch('/api/upload-report', {
  method: 'POST',
  headers: {'X-Session-ID': sessionId},
  body: formData
})

↓

// 后端处理
@app.route('/api/upload-report', methods=['POST'])
def upload_report():
    # 1. 接收文件
    file = request.files['report']

    # 2. 保存到 uploads/
    filepath = os.path.join(app.config['UPLOAD_FOLDER'], filename)
    file.save(filepath)

    # 3. 创建 DataFiller
    filler = DataFiller(filepath, password)

    # 4. 加载报表
    filler.load_report()

    # 5. 提取信息
    dates = filler.get_all_numeric_sheets()  # [1, 2, ..., 31]
    sheets = filler.wb.sheetnames
    supplierData = filler.count_supplier_data_in_columns(...)

    # 6. 返回数据
    return jsonify({
        success: True,
        dates: dates,
        sheets: sheets,
        suppliersConfig: suppliersConfig,
        supplierData: supplierData,
        message: "报表加载成功"
    })

↓

// 前端接收
const result = await response.json()

↓

// 保存到全局变量
suppliersConfig = result.suppliersConfig  # 供应商配置
fillHistory = result.supplierData        # 已填充数据
allDates = result.dates                   # 日期列表

↓

// 渲染界面
renderUploadButtons()   # 显示供应商上传按钮
renderProgressTable()   # 显示进度追踪表格
```

### 步骤3: 上传送货商文件

```javascript
// 用户点击供应商上传按钮
<button onclick="uploadSupplierFile('AC-AH')">
    📤 AC-AH
    <small>万邦蔬菜</small>
</button>

↓

// 记录当前列范围
currentColumnRange = 'AC-AH'

↓

// 弹出文件选择对话框
document.getElementById('supplierFileInput').click()

↓

// 用户选择文件
<input type="file" id="supplierFileInput" change="...">

↓

// 监听文件选择
document.getElementById('supplierFileInput').addEventListener('change', async function() {
    const file = this.files[0]

    // 更新表格状态为"处理中"
    updateTableStatus('AC-AH', 'processing')

    // 创建 FormData
    const formData = new FormData()
    formData.append('files', file)
    formData.append('column_range', 'AC-AH')

    // 【步骤1】上传文件
    const uploadResponse = await fetch('/api/upload-suppliers', {
        method: 'POST',
        headers: {'X-Session-ID': sessionId},
        body: formData
    })

    const uploadResult = await uploadResponse.json()
    // uploadResult = {
    //   success: true,
    //   dates: ['9', '10', '11'],
    //   file_info: {...}
    // }

    // 【步骤2】检查数据冲突
    const checkResponse = await fetch('/api/check-supplier-data', {
        method: 'POST',
        headers: {'Content-Type': 'application/json', 'X-Session-ID': sessionId},
        body: JSON.stringify({
            column_range: 'AC-AH',
            dates: uploadResult.dates
        })
    })

    const checkResult = await checkResponse.json()
    // checkResult = {
    //   success: true,
    //   conflict_dates: []
    // }

    // 【步骤3】显示确认对话框
    const confirmMsg = `
        检测到 3 个日期的数据：9日、10日、11日

        即将执行以下操作：
        1. 已清空原有数据，将添加上传文件数据。
        2. 只填充检测到的 3 个日期。

        是否继续？
    `

    if (!confirm(confirmMsg)) {
        // 用户取消
        return
    }

    // 【步骤4】执行填充
    const fillResponse = await fetch('/api/fill-supplier-data', {
        method: 'POST',
        headers: {'Content-Type': 'application/json', 'X-Session-ID': sessionId},
        body: JSON.stringify({
            column_range: 'AC-AH',
            dates: uploadResult.dates
        })
    })

    const fillResult = await fillResponse.json()
    // fillResult = {
    //   success: true,
    //   fillHistory: {...},
    //   output_file: '金融岛报表_已填充_xxx.xlsx'
    // }

    // 更新填充历史
    fillHistory = fillResult.fillHistory

    // 重新渲染表格（显示新填充的数据）
    renderProgressTable()

    // 显示下载按钮
    downloadBtn.href = `/api/download/${fillResult.output_file}`
    downloadBtn.style.display = 'inline-block'

    alert('✅ 填充完成！')
})
```

## 🔍 API 接口列表

### 会话管理

| 接口 | 方法 | 功能 |
|------|------|------|
| `/api/session/create` | POST | 创建新会话 |

### 文件上传

| 接口 | 方法 | 参数 | 返回值 |
|------|------|------|--------|
| `/api/upload-report` | POST | report, password | dates, suppliersConfig, supplierData |
| `/api/upload-suppliers` | POST | files, column_range | dates, file_info |

### 数据操作

| 接口 | 方法 | 参数 | 返回值 |
|------|------|------|--------|
| `/api/check-supplier-data` | POST | column_range, dates | conflict_dates |
| `/api/fill-supplier-data` | POST | column_range, dates | fillHistory, output_file |
| `/api/paste-handover` | POST | - | fillHistory, output_file |
| `/api/delete-columns` | POST | startColumn | output_file |
| `/api/fill-history` | DELETE | - | success |
| `/api/download/<filename>` | GET | - | 文件内容 |

## ⚡ 关键技术点

### 1. 文件上传
- 使用 `FormData` 对象
- 支持多文件上传
- 自动验证文件格式

### 2. 进度追踪
- 前端维护 `fillHistory` 对象
- 实时更新表格状态
- 显示处理中动画

### 3. 会话管理
- 每次页面加载创建新会话
- 所有请求携带 `X-Session-ID` 头
- 服务器端关联会话和数据

### 4. 数据同步
- 前端和后端共享 `fillHistory`
- 每次填充后更新历史
- 实时反映到UI

---

## 🎯 总结

这个Web应用实现了完整的Excel数据填充流程：

1. ✅ **上传报表** → 解析报表结构
2. ✅ **配置界面** → 自动生成供应商按钮
3. ✅ **上传送货商文件** → 逐个填充数据
4. ✅ **进度追踪** → 实时显示填充状态
5. ✅ **下载结果** → 获取填充后的文件

所有操作都在浏览器中完成，无需命令行交互！
