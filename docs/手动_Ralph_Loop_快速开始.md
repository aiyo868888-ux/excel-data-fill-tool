# 手动 Ralph Loop - 快速开始指南

## 🚀 立即开始（5 分钟上手）

### 核心原理

> **使用相同的任务描述，多次让 Claude 工作，每次都基于上次的结果改进**

---

## 📋 第一次尝试：简单计算器

### 任务描述（复制这段话）

```
创建一个简单的计算器应用：

1. 创建 calculator.py 文件
2. 实现加、减、乘、除四个函数
3. 创建 test_calculator.py 测试文件
4. 编写至少 5 个测试用例
5. 每次迭代后运行 pytest 验证功能

要求：
- 代码要清晰易懂
- 包含必要的注释
- 所有测试通过
```

### 操作步骤

**第 1 次迭代**：
1. 复制上面的任务描述
2. 粘贴到 Claude Code 对话框
3. 发送给 Claude
4. 等待 Claude 完成工作
5. 检查创建的文件

**第 2 次迭代**：
1. **再次复制相同的任务描述**（完全相同！）
2. 粘贴并发送
3. Claude 会看到已存在的文件
4. 基于上次结果继续改进

**第 3-10 次迭代**：
- 重复相同任务描述
- 每次都应该看到改进
- 直到所有测试通过且代码质量满意

```
       └─ 否 → 继续（输入相同任务）
```

```bash

# 第 1 次迭代后

git commit -m "Iteration 1: Basic structure"

# 第 2 次迭代后
git add .
git commit -m "Iteration 2: Added more tests"

# 查看进度
git log --oneline

# 对比两次迭代
git diff HEAD~1 HEAD
```

### 技巧 2：查看文件变化

```bash
# 查看最近修改的文件
ls -lt | head -10

# 查看特定文件的内容
cat calculator.py

# 使用 VSCode 打开查看
code calculator.py
```

```bash

# 运行特定测试

pytest test_calculator.py -vv

# 查看测试覆盖率
pytest test_calculator.py --cov=calculator --cov-report=term-missing
```

## ⚠️ 常见错误

### 错误 1：每次改变任务描述

❌ **错误做法**：
```
迭代 1：创建计算器
迭代 2：改进计算器
迭代 3：优化计算器代码
```

✅ **正确做法**：
```
迭代 1：创建计算器应用，包含测试
迭代 2：创建计算器应用，包含测试（相同！）
迭代 3：创建计算器应用，包含测试（相同！）
```

### 错误 2：不检查结果就继续

❌ **错误做法**：
- 发送任务
- 立即再次发送
- 不看 Claude 做了什么

✅ **正确做法**：
- 发送任务
- 等待完成
- 检查文件
- 运行测试
- 评估结果
- 然后再继续

### 错误 3：迭代太多或太少

❌ **错误做法**：
- 迭代 2 次就停止（可能没完成）
- 迭代 50 次（浪费时间）

✅ **正确做法**：
- 设置范围：10-20 次
- 根据完成标准判断
- 满意就停止
