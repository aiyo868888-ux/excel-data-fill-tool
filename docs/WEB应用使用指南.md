# 数据填充工具 - Web应用使用指南

## 📋 简介

数据填充工具Web应用是一个基于Flask的在线工具，可以自动将送货商Excel文件的数据填充到报表中，无需命令行操作。

## 🚀 快速开始

### 方法1: 使用启动脚本（推荐）

双击运行 `启动Web应用.bat`，服务器会自动启动。

### 方法2: 手动启动

```bash
python web_app.py
```

启动后，在浏览器中访问: **http://localhost:5000**

## ✨ 功能特点

### 1. 简洁的Web界面
- 📋 拖拽上传文件
- 🎨 现代化的UI设计
- 📊 实时进度显示
- ✅ 操作结果反馈

### 2. 核心功能
- **上传报表**: 支持密码保护的Excel文件
- **上传送货商文件**: 批量上传多个送货商文件
- **配置列范围**: 自定义数据填充的列范围（如Q-U列）
- **自动填充**: 一键完成数据填充
- **下载结果**: 填充完成后直接下载

### 3. 智能特性
- 自动检测日期工作表（1-31日）
- 支持多个送货商文件合并
- 保留原有格式和样式
- 错误提示和异常处理

## 📖 使用步骤

### 步骤1: 启动应用

```bash
# Windows
双击 启动Web应用.bat

# 或使用命令行
python web_app.py
```

看到以下信息表示启动成功：

```
==================================================
   数据填充工具 - Web应用
   访问地址: http://localhost:5000
==================================================
```

### 步骤2: 上传文件

1. **上传报表文件**
   - 点击"选择报表文件"或拖拽文件到上传区域
   - 如果报表有密码，输入密码
   - 系统会显示报表中的日期数量

2. **上传送货商文件**
   - 点击"选择送货商文件"或拖拽文件
   - 可以一次选择多个文件
   - 系统会显示每个文件的日期数量

### 步骤3: 配置列范围

- **起始列**: 选择数据填充的起始列（如Q列）
- **结束列**: 选择数据填充的结束列（如U列）

常见列范围：
- Q-U (5列): 名称、单位、数量、单价、总价
- R-V (5列): 同上
- AC-AH (6列): 名称、单位、数量、单价、总价、备注

### 步骤4: 开始填充

1. 点击"🚀 开始填充数据"按钮
2. 等待处理完成（进度条会显示进度）
3. 点击"📥 下载填充后的报表"

## 🔧 技术架构

### 后端
- **框架**: Flask (Python Web框架)
- **核心模块**: 数据填充工具 (`tests/数据填充工具.py`)
- **文件处理**: pandas, openpyxl, msoffcrypto

### 前端
- **HTML5**: 页面结构
- **CSS3**: 渐变背景、响应式布局
- **JavaScript (原生)**: 文件上传、API调用、进度显示

### API接口

| 接口 | 方法 | 功能 |
|------|------|------|
| `/` | GET | 主页 |
| `/api/upload-report` | POST | 上传报表文件 |
| `/api/upload-supplier` | POST | 上传送货商文件 |
| `/api/process` | POST | 处理数据填充 |
| `/api/download/<filename>` | GET | 下载结果文件 |
| `/api/preview-report` | POST | 预览报表内容 |

## ⚙️ 配置选项

### 端口配置

在 `web_app.py` 最后一行修改：

```python
app.run(host='0.0.0.0', port=5000, debug=True)
```

- `host='0.0.0.0'`: 允许局域网访问
- `port=5000`: 端口号
- `debug=True`: 开发模式，显示详细错误信息

### 文件大小限制

在 `web_app.py` 中修改：

```python
app.config['MAX_CONTENT_LENGTH'] = 50 * 1024 * 1024  # 50MB
```

## 🐛 常见问题

### 1. 端口被占用

**错误**: `Address already in use`

**解决**:
- 修改端口：`app.run(port=5001)`
- 或关闭占用5000端口的程序

### 2. 模块未找到

**错误**: `ModuleNotFoundError: No module named 'flask'`

**解决**:
```bash
pip install flask pandas openpyxl msoffcrypto
```

### 3. 文件上传失败

**可能原因**:
- 文件格式不支持（仅支持.xlsx和.xls）
- 文件大小超过限制（默认50MB）
- 报表密码错误

### 4. 数据填充失败

**可能原因**:
- 报表中没有对应日期的工作表
- 送货商文件格式不正确
- 列范围设置错误

**解决**: 查看浏览器控制台（F12）的错误信息
