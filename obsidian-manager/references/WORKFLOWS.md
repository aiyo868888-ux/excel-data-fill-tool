# Obsidian Workflows

## Daily Note Workflow

**1. Create daily note:**
- Use daily note template
- Date in filename: `2026-01-21.md`
- Date in frontmatter and title

**2. Structure:**
- Focus section (top 3 priorities)
- Notes section (brain dump)
- Completed section (track wins)
- Ideas section (capture thoughts)
- References section (link to related notes)

**3. End of day:**
- Move completed items to Completed section
- Review ideas section
- Create follow-up notes if needed
- Link back from project notes

## Zettelkasten Workflow

**1. Capture idea:**
- Create note with atomic idea
- One concept per note
- Clear, descriptive title

**2. Link notes:**
- Link to related notes (at least 2-3)
- Use descriptive link text
- Create bidirectional links

**3. Review and refine:**
- Regular review of orphan notes
- Update connections as knowledge grows
- Merge duplicate concepts

**4. Example structure:**
```markdown
# The Feynman Technique

## Core Idea
Best way to learn is to teach it simply

## Related Notes
- [[Active Learning]]
- [[Knowledge Retention]]
- [[Explanatory Gap]]

## Sources
- Feynman, Richard. "Surely You're Joking, Mr. Feynman!"
```

## Project Management Workflow

**1. Create project note:**
- Use project template
- Set status and deadline
- Define objectives

**2. Break down tasks:**
- Create task list with checkboxes
- Link tasks to sub-notes if complex
- Set priorities (use tags like #high #medium #low)

**3. Track progress:**
- Update status in frontmatter
- Mark completed tasks with `- [x]`
- Add progress updates

**4. Link related resources:**
- Reference notes
- Meeting notes
- Research materials

**5. Archive when complete:**
- Change status to `completed`
- Move to archive folder
- Create retrospective note

## Concept Mapping Workflow

**1. Identify core concept:**
- Create main concept note
- Define key principles

**2. Map relationships:**
- Link to parent concept (broader)
- Link to child concepts (narrower)
- Link to related concepts (lateral)

**3. Use dataview:**
- Add dataview query to auto-display relationships
- Use tags to filter related notes

**4. Visual representation:**
- Consider creating Canvas for complex concepts
- Use embedded blocks for repeated elements

## Research Workflow

**1. Source note:**
- Create note for each source
- Full citation in frontmatter
- Key quotes with block IDs
- Personal notes

**2. Literature note:**
- Summary of source
- Main arguments
- Methodology
- Findings

**3. Permanent note:**
- Atomic ideas from sources
- Your own synthesis
- Link to source notes
- Link to related permanent notes

**4. Example:**
```markdown
---
type: source
authors: "Kahneman, D."
year: 2011
title: "Thinking, Fast and Slow"
publisher: "Farrar, Straus and Giroux"
---

# Thinking, Fast and Slow

## Key Quotes
> "A reliable way to make people believe in falsehoods is frequent repetition, because familiarity is not easily distinguishable from truth."^repetition-fallacy

## Notes
- Two systems: Fast (System 1) and Slow (System 2)
- Cognitive biases affect decision-making
```

## Meeting Notes Workflow

**1. Preparation:**
- Create meeting note from template
- Add agenda beforehand
- Link to project notes

**2. During meeting:**
- Capture discussion points
- Note action items with owners
- Mark decisions clearly

**3. Follow-up:**
- Extract action items to tasks
- Update project notes with decisions
- Schedule next meeting if needed
- Share summary with attendees

## Review Workflow

**Weekly review:**
1. Review all daily notes from past week
2. Extract completed tasks to project notes
3. Follow up on open action items
4. Update project statuses
5. Plan next week

**Monthly review:**
1. Review all project notes
2. Assess progress toward goals
3. Archive completed projects
4. Identify areas for improvement
5. Update templates if needed

**Quarterly review:**
1. Review overall knowledge base
2. Identify gaps in understanding
3. Reorganize structure if needed
4. Update linking strategy
5. Clean up orphan notes
