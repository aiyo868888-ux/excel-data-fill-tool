## 完整音频生成流程

### 第一步：音频脚本改编

**使用工具**：`06-audio-adapter.md`

**操作**：
- 将长文/视频脚本改编为音频脚本
- 去除视觉描述
- 增加停顿标记
- 添加语气提示
- 口语化改写

**输出**：音频脚本（含录制建议）

---

### 第二步：准备 TTSMaker 文本

**使用工具**：`07-audio-generator.md`

**操作**：
- 清除所有标记（[语气]、[停顿]、时间轴等）
- 优化标点符号（控制停顿）
- 保留核心内容
- 检查字数（是否需要分段）

**输出**：TTSMaker 专用文本（纯净文本）

---

### 第三步：使用 TTSMaker 生成音频

**操作步骤**：

1. **打开网站**  
   访问：https://ttsmaker.com

2. **粘贴文本**  
   复制 TTSMaker 专用文本，粘贴到文本框

3. **选择声音**  
   推荐：
   - Xiaoxiao（女声，温和自然）
   - Yunyang（男声，沉稳）

4. **调节语速**  
   推荐：0.85x - 0.9x（比正常慢 10-15%）

5. **点击生成**  
   点击"转换为语音"，等待 1-3 分钟

6. **下载音频**  
   生成完成后点击"下载"，保存为 MP3

7. **分段拼接**（如需要）  
   使用 Audacity 拼接多段音频

---

### 第四步：后期处理（可选）

**使用工具**：Audacity（免费）

**操作**：
1. 导入生成的音频
2. 降噪处理（如有杂音）
3. 音量标准化（-16 LUFS）
4. 添加背景音乐（-20 dB）
5. 添加淡入淡出效果
6. 导出最终音频（192 kbps MP3）

## 使用建议

### 推荐设置

**声音选择**：
- **女声**（Xiaoxiao）：温和、亲切，适合故事叙述、个人成长类
- **男声**（Yunyang）：稳重、权威，适合专业内容、商业分析类

**语速设置**：
- **0.8x**：适合复杂内容，需要更多思考时间
- **0.9x**：推荐，平衡流畅度和理解度
- **1.0x**：正常语速，适合简单内容

**音质优化**：
- 选择"高质量"选项（如有）
- 下载后用 Audacity 标准化音量
- 添加轻微的混响效果（可选）

## 分段策略

### 何时需要分段

**字数判断**：
- **< 8000 字**：无需分段，一次生成
- **8000-15000 字**：建议分 2 段
- **> 15000 字**：建议分 3 段或更多

### 分段原则

1. 按内容章节分段（不要在句子中间切断）
2. 每段尽量长度相近
3. 分段点选择自然停顿处

### 拼接方法

使用 Audacity：
1. 文件 → 导入 → 音频（导入第 1 段）
2. 文件 → 导入 → 音频（导入第 2 段）
3. 调整段落之间的间隔（建议 1-2 秒）
4. 文件 → 导出 → 导出为 MP3

## 后期处理详细教程

### 使用 Audacity（免费）

**下载地址**：https://www.audacityteam.org/

### 基础处理流程

**1. 导入音频**
```
文件 → 打开 → 选择生成的 MP3
```

**2. 降噪处理**（如有杂音）
```
选择一段静音区域
效果 → 降噪 → 获取噪音配置文件
选择全部音频
效果 → 降噪 → 确定
```

**3. 音量标准化**
```
选择全部音频
效果 → 标准化
设置为 -3.0 dB
```

**4. 添加背景音乐**（可选）
```
文件 → 导入 → 音频（选择背景音乐）
调整音乐音量到 -20 dB
在开头和结尾添加淡入淡出
```

**5. 添加淡入淡出**
```
选择开头 2 秒 → 效果 → 淡入
选择结尾 2 秒 → 效果 → 淡出
```

**6. 导出最终音频**
```
文件 → 导出 → 导出为 MP3
比特率：192 kbps（播客标准）
保存
```

## 常见问题

### Q1: 生成的音频太机械怎么办？

**A**: 
1. 优化文本：增加口语化表达
2. 调整语速：稍微放慢（0.85x）
3. 添加背景音乐：掩盖机械感
4. 考虑真人录制：如果预算允许

### Q2: 字数超过限制怎么办？

**A**: 
1. 分段生成（推荐）
2. 删减次要内容
3. 使用付费版（如需要）

### Q3: 如何添加背景音乐？

**A**: 
1. 使用 Audacity 导入音频和音乐
2. 调整音乐音量到 -20 dB
3. 在开头和结尾添加淡入淡出
4. 导出最终音频

### Q4: 生成的音频可以商用吗？

**A**: 
- TTSMaker 免费版通常允许个人使用
- 商用建议查看官网使用条款
- 或使用付费 TTS 服务（如 ElevenLabs、Azure Speech）
