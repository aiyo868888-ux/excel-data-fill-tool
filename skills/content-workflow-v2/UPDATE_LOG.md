## 音频改编核心原则

### 1. 去除视觉依赖
❌ "如图所示，73% 的知识工作者..."  
✅ "有个数据你可能想不到：**73%** —— 对，超过七成的知识工作者..."

### 2. 增加停顿标记
```
**[停顿 2 秒]**
AI 会不会取代我？
**[停顿]**
```

### 3. 语气变化提示
```
**[语气：轻松、对话式]**
嘿，欢迎回来。

**[语气：严肃]**
这些时刻，需要的不是更聪明的分析，而是承担后果的勇气。
```

### 4. 对话式语言
- 使用"你"、"我"增强亲切感
- 避免书面语和长句
- 像和朋友聊天一样

### 5. 音乐提示
```
**[开场音乐]** (0:00-0:15)
**[轻柔的背景音乐，逐渐淡出]**

**[结尾音乐]**
**[轻柔的结束音乐渐入，持续 10 秒后淡出]**
```

## 输出内容

### 音频脚本包含：

1. **完整脚本**
   - 时间轴标注（0:00-15:30）
   - 停顿标记（2秒/3秒）
   - 语气提示（轻松/严肃/思考/强调）
   - 音乐提示（开场/转场/结尾）

2. **录制建议**
   - 语速控制（比正常对话慢 20%）
   - 停顿执行（2秒 = 深呼吸一次）
   - 语气变化（叙事/思考/强调/结尾）
   - 重录建议（金句多录 3-5 遍）

3. **后期处理建议**
   - 音频处理（降噪、标准化、EQ、压缩）
   - 背景音乐（类型、音量控制 -20dB）
   - 章节标记（时间戳、方便跳转）
   - 节目简介（标题、简介、时长、适合场景）

## 技术细节

### 音频改编的关键差异

| 维度 | 视频脚本 | 音频脚本 |
|------|----------|----------|
| 视觉元素 | 有画面提示 | 纯语言描述 |
| 节奏 | 较快（有视觉辅助） | 较慢（给思考时间） |
| 重复 | 较少（可回看） | 较多（防止走神） |
| 语言 | 可用书面语 | 必须口语化 |
| 停顿 | 较少 | 大量停顿标记 |
| 时长 | 10 分钟 | 12-15 分钟（+20%） |
