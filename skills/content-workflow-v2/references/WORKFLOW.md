# Content Workflow - Complete Reference

> 基于 Dan Koe 方法论的内容生产工作流完整参考文档

## 系统架构

```
想法收集 ──► 想法验证 ──► 素材整理 ──► 框架拆解 ──► 两阶段生成 ──► 多平台分发
   │            │           │           │              │              │
   └─────── 想法库 ─────┘           │           │              │              │
                                 └─── 素材库 ──┘              │              │
                                                            └── 框架库 ─────┘
```

## 核心模块详解

### 模块 1: 想法捕获与验证

**Prompt**: `assets/prompts/01-thought-capturer.md`

**使用场景**:
- 每日有新想法时
- 不确定是否值得投入时间扩展时
- 需要快速测试想法时

**工作流程**:
1. 快速记录想法（Twitter/备忘录，280字限制）
2. 使用 Prompt 评估扩展潜力
3. 标记可扩展类型：[推文] [长文] [视频] [混合]

**输出**:
- 共鸣度评分 (1-5)
- 独特性评分 (1-5)
- 测试标题建议
- 下一步行动建议

---

### 模块 2: 素材整理浓缩

**Prompt**: `assets/prompts/02-material-organizer.md`

**输入类型**:
- YouTube 视频 URL
- 文章链接
- 书籍笔记
- 之前的内容

**输出格式**:
```
【主题】一句话总结

【核心论点】
1. 论点 1
2. 论点 2
3. 论点 3

【关键数据】
- 数据 1: 来源
- 数据 2: 来源

【金句摘录】
> "引用 1"
> "引用 2"

【可引用场景】
- 适合话题
- 可关联观点
```

**浓缩效率**: 3-6 小时视频 → 1000 字要点

---

### 模块 3: 爆款框架逆向工程

**Prompt**: `assets/prompts/03-framework-extractor.md`

**流程**:

1. **选择爆款内容**
   - 找 3 条同类型的高表现内容
   - 可以是自己或别人的

2. **结构拆解**
   - 钩子: 如何吸引注意力？
   - 冲突: 提出什么问题？
   - 转折: 哪里发生转向？
   - 解决: 给出什么答案？
   - 升华: 如何强化印象？

3. **心理触发器分析**
   - 好奇心缺口
   - 社会认同（"被说中了"）
   - 损失厌恶
   - 独家感（"秘密"）

4. **框架模板提取**
   ```
   [钩子] [占位符描述]
   +
   [冲突] [占位符描述]
   +
   [转折] [占位符描述]
   +
   [解决] [占位符描述]
   +
   [升华] [占位符描述]
   ```

**输出**: 可复用的框架模板库

---

### 模块 4: 两阶段生成系统

#### 阶段一: 上下文采集

**Prompt**: `assets/prompts/04-context-collector.md`

AI 像记者一样依次提问：

1. **核心主题**: 这次要表达的观点？
2. **目标受众**: 给谁看？他们面临什么痛点？
3. **独特角度**: 与大多数人看法有何不同？
4. **支撑素材**: 有哪些个人经历/数据/金句？
5. **框架选择**: 使用哪个结构模板？
6. **内容形式**: 推文/长文/视频脚本？

**重要**: 必须收集完所有信息后才能进入生成阶段

#### 阶段二: 内容生成

**Prompt**: `assets/prompts/05-content-generator.md`

基于采集的信息，生成 3 个不同版本：

| 版本 | 风格特点 | 适用场景 |
|------|----------|----------|
| 版本 A | 直接有力型（短句、绝对语） | 喜欢硬核论证 |
| 版本 B | 故事共鸣型（有代入感） | 需要情感共鸣 |
| 版本 C | 挑战反常识型（制造张力） | 想引发讨论 |

**每个版本包含**:
- 完整内容
- 风格特点说明
- 使用的心理触发器
- 适用场景建议

### 模块 5: 多平台转化规则

| 源内容 | 目标平台 | 转化规则 |
|--------|----------|----------|
| Newsletter 章节 | Twitter | 拆成 3-5 条推文，每条一个观点 |
| YouTube 脚本 | Twitter | 提取金句 + 数据，做成推文 |
| Twitter 爆款 | Newsletter | 扩展成完整论证 |
| Twitter 系列 | YouTube | 脚本大纲 + 案例补充 |

## 每日执行节奏

### 每日 2 小时创作块

```
09:00 - 09:10  回顾昨日数据，选出最佳想法
09:10 - 09:50  完成今日主内容（Newsletter 一章 / 视频脚本一段）
09:50 - 10:00  生成并分发 3 条社交媒体内容
10:00 - 10:30  素材整理（看视频/读书，用 AI 提取要点）
10:30 - 11:00  框架库维护（拆解 1 条爆款内容）
```

### 每周安排

| 时间 | 安排 |
|------|------|
| 周一 | 制定本周主题清单 |
| 周二-周四 | 日常创作节奏 |
| 周五 | 录制/制作本周视频内容 |
| 周六 | 复盘本周数据，更新框架库 |
| 周日 | 休息 + 灵感收集 |

## 核心原则

1. **验证优先创作** - 只扩展已经过验证的想法
2. **框架优于灵感** - 用验证过的结构填充新想法
3. **AI 是放大器** - 它扩展你的思考边界，而非替代思考
4. **系统化迭代** - 每周复盘，不断优化框架库

## 常见使用场景

### 场景 1: 从零开始创作

1. 用 `01-thought-capturer.md` 评估想法
2. 用 `02-material-organizer.md` 整理素材
3. 用 `03-framework-extractor.md` 选择/创建框架
4. 用 `04-context-collector.md` 采集上下文
5. 用 `05-content-generator.md` 生成内容

### 场景 2: 优化已有内容

1. 用 `03-framework-extractor.md` 拆解自己或别人的爆款
2. 将框架应用到新想法
3. 用 `05-content-generator.md` 生成新版本

### 场景 3: 批量生产社交媒体内容

1. 准备一个 Newsletter 章节
2. 用多平台转化规则拆成 5-7 条推文
3. 每条独立发布测试反应
4. 表现好的扩展成长文或视频

## 元提示词：生成定制 Prompt

流程：
1. 找 3 条该类型的优秀范例
2. 用 `03-framework-extractor.md` 拆解
3. 将拆解结果输入 `05-content-generator.md`
4. 得到定制化的两阶段生成 Prompt

适用场景：
- 特定领域内容（科技/金融/健康）
- 特定平台风格（小红书/Twitter/公众号）
- 特定内容形式（教程/观点/故事）
