# 配置优化模式

## 常见问题模式

### 1. 重复规则

**检测**：
```bash
grep -n "保持简洁" CLAUDE.md | wc -l
```

**修复**：
- 保留最完整的描述
- 其他位置引用主描述
- 添加链接：`遵循 [输出控制](#output_verbosity) 规则`

### 2. 冲突规则

**示例**：
- "极简原则" vs "≥90% 测试覆盖率"

**修复**：
添加冲突解决规则：
```markdown
### 核心原则
- **冲突解决**：极简 > 完整测试，实用 > 形式主义
```

### 3. 模糊指令

**模糊**：
```
执行必要的测试
```

**明确**：
```
验证关键场景覆盖（正常路径、边界值、错误处理）
```

### 4. 缺失异常处理

**缺失**：
```
读取 memory.md
```

**完善**：
```
读取 memory.md，不存在则跳过
```

## 优化优先级

1. **高优先级（立即修复）**：
   - 配置冲突
   - 重复规则 ≥3 处

2. **中优先级（本次修复）**：
   - 重复规则 1-2 处
   - 模糊指令
   - 缺失异常处理

3. **低优先级（逐步优化）**：
   - 文件过长
   - 链接失效
   - 历史数据归档

## 归档模式

### 按时间归档

```
memory.md (热数据，<100 行)
  ├── 最近 30 天
  └── 快速索引
       ↓
memory-system-feedback.md (温数据)
  └── 完整历史
       ↓
memory-archive/ (冷数据)
  ├── memory-2024.md
  └── memory-2023.md
```

### 按主题归档

```
memory.md (主文件)
  ├── 用户信息
  ├── 系统反馈
  └── 项目记录
       ↓
memory-system-feedback.md
  └── 系统反馈完整历史
       ↓
memory-projects.md
  └── 项目记录完整历史
```

## 安全模式

### 备份策略

```bash
# 按日期备份
.backup/system-optimizer-20250122/

# 保留策略
- 保留 7 天
- 自动清理过期备份
```

### 回滚流程

```bash
# 快速回滚
cp .backup/system-optimizer-20250122/CLAUDE.md CLAUDE.md
cp .backup/system-optimizer-20250122/memory.md memory.md

# 验证回滚
cat CLAUDE.md | head -20
```
